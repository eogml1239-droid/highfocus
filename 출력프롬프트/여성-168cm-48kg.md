> **용도** 메인 룩북컷, 브랜드 무드컷
> **전제** System instructions에 `AI-모델컷-프롬프트-나노바나나.md` v3.0이 로드된 상태
> **모델** Gemini 3 Pro Image (Nano Banana Pro) · Temperature 0.6~0.8 · Thinking High · Media resolution High

**사용 순서**
1. 4번 표에서 의상 실측에 해당하는 핏 값을 미리 찾아둔다
2. 1번(한국어) 또는 2번(영문) 프롬프트를 복사해 `[   ]` 슬롯을 채운다

4. 실행 → 텍스트 보고가 먼저 나오는지 확인 → 이미지 확인

## 3. 슬롯 작성 요령

| 슬롯 | 쓰는 방식 | 나쁜 예 → 좋은 예 |
|---|---|---|
| 상의 | 형태 + 색 + 소재 순 | "니트" → "아이보리 크루넥 울 니트, 밑단·소매 리브" |
| 하의 | 형태 + 색 + 소재 + 기장 | "스커트" → "베이지 8프리츠 폴리 우븐 미니 스커트" |
| 신발 | 종류 + 색 + 소재 + 굽 | "부츠" → "블랙 가죽 라이딩 롱부츠, 굽 3cm" |
| 소재 | 신축성 여부를 반드시 명기 | "울" → "울 니트(신축성 있음)" |

**주의:** 의상 사진에 치수 표기·워터마크·사이즈표가 찍혀 있으면 지우고 첨부하세요. 이미지 안의 숫자는 재현 대상으로 해석돼 결과물에 그려져 나올 수 있습니다.

## 6. 이 스펙 전용 주의사항

**BMI 17은 마른 편입니다.** 오버사이즈 상품에서 옷이 실제보다 더 크고 여유 있게 보입니다. 핏이 중요한 상품은 `여성-163cm-52kg.md` 비교컷을 함께 게시하세요.

**모델이 기본 편향으로 되돌아갑니다.** 생성 과정에서 체형이 슬쩍 더 통통하거나 다리가 더 길어지는 일이 흔합니다. 결과물에서 어깨너비와 허리 라인을 먼저 확인하세요.

**7.8등신은 상한선입니다.** 이보다 늘어나면 비현실적으로 보입니다. 다리가 과하게 길게 나오면 카메라 높이를 100cm로 명시했는지, 렌즈가 150mm인지 확인하세요. 낮은 앵글이나 짧은 초점거리가 원인입니다.

**긴 헤어는 림 라이트에서 판정 요소입니다.** 머리카락 윤곽이 뭉쳐 덩어리로 나오면 AI 티가 납니다. 후처리에서 몇 가닥을 얼굴 쪽으로 빼세요.
