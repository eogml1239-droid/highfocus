## 3. 슬롯 작성 요령

| 슬롯 | 쓰는 방식 | 나쁜 예 → 좋은 예 |
|---|---|---|
| 상의 | 형태 + 색 + 소재 순 | "셔츠" → "화이트 옥스포드 코튼 레귤러 칼라 셔츠" |
| 하의 | 형태 + 색 + 소재 + 실루엣 | "바지" → "차콜 울 블렌드 와이드 슬랙스, 원턱" |
| 신발 | 종류 + 색 + 소재 + 굽 | "구두" → "블랙 가죽 더비 슈즈, 굽 2.5cm" |
| 소재 | 신축성 여부 명기 | "코튼" → "코튼 100%(신축성 없음)" |

**남성복 특유의 항목:** 바지는 허리단면 외에 **허벅지단면과 밑단단면**을 함께 주세요. 이 두 값이 슬림·스트레이트·와이드를 결정하고, 밑단이 신발 위에서 고이는 정도를 좌우합니다.

## 6. 이 스펙 전용 주의사항

**어깨가 과장되는 경향이 있습니다.** 남성 모델 프롬프트에서 가장 흔한 실패입니다. 45cm는 실제로 평균보다 약간 넓은 정도이고, 보디빌더 실루엣이 아닙니다. 결과물에서 허리/어깨 비율이 1.71 근처인지 확인하세요. 1.5 이하로 나오면 과장된 겁니다.

**남성 피부는 여성보다 질감이 거칠어야 합니다.** 같은 프롬프트로 생성하면 모델이 여성 피부 기준으로 매끄럽게 만듭니다. 영문판에 코·볼의 모공을 명시한 이유입니다.

**바지 밑단 처리가 판정 요소입니다.** 밑단이 신발 위에서 고이는 가로 주름(break)이 없으면 즉시 CGI로 읽힙니다. 4.6 표의 인심 값에 따라 주름 개수까지 지정하세요.

**수염 관리를 명시해야 합니다.** 지정하지 않으면 컷마다 구레나룻 길이나 수염 유무가 달라집니다.

**손이 크게 나와야 합니다.** 여성 스펙과 같은 손 크기로 나오면 체격이 어색해집니다. 영문판에 남성 손 특성을 별도로 넣었습니다.

## 7. 출력 확인 체크리스트

```
[ ] 텍스트 보고가 이미지보다 먼저 나왔는가
[ ] 허리/어깨 비율이 1.71 근처인가 (과장된 V 테이퍼 아님)
[ ] 복근 윤곽이 희미한 정도인가 (선명하면 과장)
[ ] 얼굴·헤어·구레나룻이 이전 컷과 동일한가
[ ] 신발 바닥 접지 그림자가 있는가
[ ] 그림자 방향이 키 라이트와 반대인가
[ ] 피부에 모공이 보이는가 (코·볼 확인)
[ ] 손가락 5개, 손이 가려지지 않았는가
[ ] 얼굴이 프레임 안에 완전히 있고 초점이 맞았는가
[ ] 바지 밑단에 신발 위 가로 주름이 있는가
[ ] 가죽 신발 발목에 주름이 있는가
[ ] 첨부 사진의 의상과 100% 일치하는가
[ ] 이미지에 숫자·텍스트가 그려지지 않았는가
```

**후처리:** 부록 A 5단계(접지 그림자 보강 → 피부 질감 복원 → 미세 비대칭 → 렌즈 특성 → 그레인 통일) 순서로 진행합니다. 남성 피부는 2번 단계의 노이즈 강도를 여성보다 조금 높게(Soft Light 8~12%) 잡으세요.
