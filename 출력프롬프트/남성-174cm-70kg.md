# 출력 프롬프트 — 남성 174cm / 70kg (SPEC-B-M)

> **용도** 핏 비교컷, 사이즈 참고컷, 평균 체형 착용컷
> **전제** System instructions에 `AI-모델컷-프롬프트-나노바나나.md` v3.0이 로드된 상태
> **모델** Gemini 3 Pro Image (Nano Banana Pro) · Temperature 0.6~0.8 · Thinking High · Media resolution High

**사용 순서**
1. 4번 표에서 의상 실측에 해당하는 핏 값을 미리 찾아둔다
2. 1번(한국어) 또는 2번(영문) 프롬프트를 복사해 `[   ]` 슬롯을 채운다
3. 의상 사진을 `+` 로 첨부한다. **사진에 치수 텍스트가 있으면 지우고 올린다**
4. 실행 → 텍스트 보고가 먼저 나오는지 확인 → 이미지 확인

**이 파일의 핵심:** SPEC-A-M(178/72, BMI 22.7)과 BMI가 23.1로 거의 같습니다. 체중으로는 구분되지 않으므로 **체지방률·근육량·허리/어깨 비율**로 차이를 만들어야 합니다. 관련 서술을 줄이면 두 스펙이 같은 사람처럼 나옵니다.

## 6. 이 스펙 전용 주의사항

**가장 흔한 실패는 운동 체형으로 되돌아가는 것입니다.** BMI가 SPEC-A-M과 거의 같아서, 체지방률과 근육량 서술을 빼면 모델이 두 스펙을 같게 처리합니다. 체형 시각 서술 8줄을 통째로 유지하세요.

**확인 포인트 3개:** 어깨끝이 둥글게 마무리됐는지(삼각근 융기 없음), 복근 윤곽이 완전히 없는지, 측면에서 허리가 두꺼운지. 이 세 곳으로 A/B가 갈립니다.

**허리/어깨 비율 1.86이 기준선입니다.** 결과물이 1.7 이하로 나오면 A 스펙으로 끌려간 겁니다. 정면컷에서 어깨끝과 허리 옆선을 눈으로 비교하세요.

**7.0등신입니다.** SPEC-A-M(7.4등신)보다 다리가 짧고 상체가 길어야 정상입니다. 두 스펙의 비율이 같아 보이면 스펙이 적용되지 않은 것입니다.

**30대 초반 설정이므로 눈가 표정선을 넣었습니다.** 20대와 동일하게 매끈하면 나이대 설정이 무의미해지고, 오히려 AI 티가 납니다.

**얼굴은 SPEC-A-M과 달라야 합니다.** 같은 얼굴에 체형만 바꾸면 즉시 합성으로 읽힙니다.

## 7. 출력 확인 체크리스트

```
[ ] 텍스트 보고가 이미지보다 먼저 나왔는가
[ ] 어깨끝이 둥글게 마무리됐는가 (삼각근 융기 없음)
[ ] 복근 윤곽이 전혀 없는가
[ ] 허리/어깨 비율이 1.86 근처인가 (직사각형 실루엣)
[ ] 7.0등신으로 SPEC-A-M보다 다리가 짧은가
[ ] 얼굴이 SPEC-A-M과 다른 인물인가
[ ] 눈가에 옅은 표정선이 있는가 (30대 초반)
[ ] 신발 바닥 접지 그림자가 있는가
[ ] 그림자 방향이 키 라이트와 반대인가
[ ] 피부에 모공이 보이는가 (코·볼 확인)
[ ] 손가락 5개, 손이 가려지지 않았는가
[ ] 얼굴이 프레임 안에 완전히 있고 초점이 맞았는가
[ ] 허리 옆선·밴드에 텐션 주름이 있는가
[ ] 바지 밑단에 신발 위 가로 주름이 있는가
[ ] 비교컷이면 두 컷의 배경·조명·포즈·프레이밍이 동일한가
[ ] 이미지에 숫자·텍스트가 그려지지 않았는가
```

**후처리:** 부록 A 5단계(접지 그림자 보강 → 피부 질감 복원 → 미세 비대칭 → 렌즈 특성 → 그레인 통일) 순서로 진행합니다. 남성 피부는 2번 단계의 노이즈 강도를 여성보다 조금 높게(Soft Light 8~12%) 잡으세요. 비교컷은 두 장에 **동일한 강도**로 적용합니다.
