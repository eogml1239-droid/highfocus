# 포즈 진행 예시

여성A(168cm/48kg) + 곰돌이 자수 가디건 기준. 턴이 갈수록 짧아지는 게 정상이다.

```
턴1   [포즈1 프롬프트 전체] + 가디건 사진 첨부
      → 결과 확인. 만족하면 그 이미지를 따로 저장한다.

턴2   포즈2. LOCK 전부 유지.
      인물·얼굴·헤어·체형·의상·원단 텍스처·배경·조명·접지 그림자 모두 동일.
      포즈만 교체: 3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.
      한 손은 허리, 반대 팔은 내려 손을 노출. 어깨 솔기와 옆선이 보이게.

턴3   포즈3. LOCK 유지.
      완전 측면 90도. 팔을 몸통에서 살짝 떼어 옆선 노출.
      시선은 정면(측면 기준 앞쪽). 총장과 원단 두께가 보이게.

턴4   포즈4. LOCK 유지.
      후면. 고개만 살짝 왼쪽으로 돌려 얼굴 윤곽이 보이게.
      양팔 자연스럽게 내림. 등판 봉제선과 밑단 라인이 보이게.

턴5   포즈5. LOCK 유지.
      정면. 단추를 풀어 걸친 상태. 한 손으로 앞자락을 가볍게 잡음.
      시선은 렌즈로. 손가락과 원단 접촉면에 눌린 주름이 보이게.

턴6   포즈6. LOCK 유지.
      정면. 한쪽 다리를 앞으로 내밀고 체중은 뒤쪽 다리에.
      시선은 렌즈로. 하의 밑단과 신발 연결부가 보이게.
```

## 상품 페이지 기본 4컷만 필요할 때

턴1~4까지가 상품 페이지 최소 구성이다. 정면·3/4·측면·후면.

## 디테일컷으로 넘어갈 때

전신 포즈가 끝난 뒤 같은 세션에서 이어간다.

```
턴7   LOCK 유지. 렌즈만 HC 120mm f/4로 변경, 촬영 거리 약 3m.
      가슴 위부터 허리까지 프레이밍. 얼굴은 프레임 안에 포함하고 초점 유지.
      자수 위치, 단추 간격, 목 리브 폭이 식별되게.
```

원단 접사(짜임·안감·라벨)는 생성하지 않는다. 실사로 촬영한다.
