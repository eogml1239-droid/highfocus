# 다음 포즈 프롬프트

직전 컷이 마음에 들었을 때, 그 인물·의상을 그대로 두고 포즈만 바꿔 다음 컷을 받는 프롬프트.

**핵심 원칙** — 짧게 쓴다. 길게 쓰면 인물이 바뀐다. 재서술은 모델에게 "다시 해석하라"는 신호로 작동한다.

---

## 1. 기본형 — 같은 세션 연속 (이걸 기본으로 쓴다)

```
포즈2. LOCK 전부 유지.
인물·얼굴·헤어·체형·의상·원단 텍스처·배경·조명·접지 그림자 모두 동일.
포즈만 교체: 3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.
```

마지막 줄의 포즈만 바꿔가며 재사용한다. 포즈 번호는 순서대로 올린다.

**하지 않는 것**
- 의상 사진 재첨부 (같은 세션에서는 불필요. 옷을 다시 해석해 디테일이 달라진다)
- 배경·조명·카메라 재서술
- 한 턴에 두 개 이상의 포즈 요구

---

## 2. 강화형 — 직전 결과 이미지를 첨부

인물 흔들림이 걱정될 때. 생성이 아니라 **편집**에 가까워져 동일성이 훨씬 잘 잡히고 원단 짜임까지 따라온다.

```
첨부한 이미지의 인물과 의상을 그대로 유지하고 포즈만 바꿔줘.
얼굴, 헤어, 체형, 원단 텍스처, 배경, 조명, 발밑 그림자 동일.
포즈2: 3/4 측면 45도, 시선은 렌즈로.
```

**트레이드오프** — 원본을 강하게 참조해서 포즈 변경 폭이 작아진다. 아래 기준으로 나눠 쓴다.

| 상황 | 방법 |
|---|---|
| 각도를 크게 바꿀 때 (정면 → 후면) | 기본형. 이미지 첨부하지 않는다 |
| 미세 조정 (팔 위치, 시선, 손 동작) | 강화형. 직전 이미지 첨부 |
| 인물이 이미 흔들리기 시작했을 때 | 강화형. 마음에 들었던 컷을 첨부 |

---

## 3. 새 세션에서 이어갈 때

세션이 끊겼으면 LOCK을 다시 넣는다. 단 포즈1 프롬프트 전체를 쓰지 않고 LOCK 블록만 넣는다.

```
[해당 스펙 폴더 포즈시리즈.md 의 LOCK 블록 전체 붙여넣기]

━ 포즈2 ━
3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.
한 손은 허리, 반대 팔은 자연스럽게 내려 손을 노출.
```

여기에 **마음에 들었던 포즈1 이미지를 함께 첨부**한다. 텍스트 LOCK만으로는 얼굴이 조금 달라질 수 있다.

---

## 4. 포즈 지시 문장 작성법

포즈 문장은 세 요소로 쓴다. 하나라도 빠지면 모델이 임의로 채운다.

```
[몸 방향] + [팔·손 위치] + [보여줄 핏 요소]
```

예시

```
3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.          ← 몸 방향
한 손은 허리, 반대 팔은 내려 손을 완전히 노출.       ← 팔·손
어깨 솔기와 옆선이 가려지지 않게.                   ← 핏 요소
```

**시선을 반드시 지정한다.** 지정하지 않으면 얼굴 각도가 매번 달라지고, 그게 인물이 바뀐 것처럼 보이는 가장 큰 원인이다.

---

## 5. 설정 전제

```
Temperature 0.6   (0.8 이상이면 인물이 자주 흔들린다)
Thinking High
Media resolution High
Grounding OFF
Output length 최대값
```

같은 상품의 포즈 1~8은 **한 세션에서** 전부 뽑는다. 세션을 닫으면 3번 절차로 복귀해야 한다.
