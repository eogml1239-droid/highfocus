# 실물 이미지 디테일컷 재구성

기존 상품 실물 사진 한 장 → 각도·배치를 바꾼 여러 장의 디테일컷.

## 이 스킬의 단 하나의 규칙

```
바뀌는 것 : 카메라 각도, 옷을 놓는 방식, 조명 방향, 배경, 크롭
불변인 것 : 원단 짜임, 색, 봉제선, 단추, 라벨, 실루엣, 기장 비율
```

**원단과 색이 바뀌면 실패다.** 디테일컷은 구매자가 원단을 판단하는 유일한 근거다. 여기서 실물과 달라지면 반품 사유가 되고, 페이지 전체 신뢰가 무너진다.

## 파일

```
재구성프롬프트.md      복붙용 프롬프트 (기본형 · 클로즈업형 · 시리즈형)
각도배치카탈로그.md    배치 10종 × 카메라 앵글 6종 조합표
검증과주의.md          실물 일치 검증 체크리스트 + 권리 확인
```

## 순서

```
1. 원본 실물 사진 준비 (치수 표기·워터마크가 있으면 제거)
2. 재구성프롬프트.md 의 기본형 실행
3. 각도배치카탈로그.md 에서 다음 조합 선택해 같은 세션에서 이어 생성
4. 검증과주의.md 체크리스트로 원본과 대조
```

## 먼저 확인할 것

원본 이미지의 사용 권리를 확인한다. 직접 촬영했거나 공급처에서 사용 허락을 받은 이미지여야 한다. 타 셀러가 촬영한 이미지를 변형해 쓰는 것은 각도를 바꿨어도 저작권 문제가 남는다.

## 중복 이미지 회피 효과에 대해

각도·배경·조명을 바꾸면 이미지 파일 자체는 달라지고 단순 해시 기반 중복 판정은 피할 수 있다. 다만 같은 상품이라는 사실은 바뀌지 않으므로 완전한 고유성은 실제 촬영으로만 확보된다. 이 스킬은 **디테일컷 보강 수단**이지 촬영 대체 수단이 아니다.
