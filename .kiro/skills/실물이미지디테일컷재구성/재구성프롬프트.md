# 재구성 프롬프트

## 1. 기본형 — 각도·배치 변경

원본 실물 사진을 `+`로 첨부하고 아래를 붙여넣는다.

```
첨부한 상품 실물 사진을 재촬영하듯 각도와 배치만 바꿔 새 이미지를 생성한다.

━ 절대 불변 (원본과 100% 동일) ━
원단 조직과 짜임 구조, 표면 결, 보풀·기모 상태
색상 — 색조·채도·명도 모두 원본과 동일. 톤 보정 금지
봉제선 위치와 스티치 색, 땀 간격
단추 개수·소재·색, 지퍼 형태, 라벨 위치와 내용
실루엣, 기장 비율, 어깨너비 비율, 디테일 개수
프린트·자수의 위치·크기·색

━ 변경할 것 ━
옷을 놓는 방식: [배치 선택]
카메라 앵글: [앵글 선택]
조명: 측면 그레이징 라이트를 주광으로. 원단 결이 빛을 스치며 드러나게.
      필 라이트로 암부를 살짝 열어 디테일 유지. 색온도 5400K 중립
배경: 매끈한 무채색 면. 옷 색과 명도 차이를 두어 실루엣이 분리되게
접지: 옷이 놓인 면에 닿는 지점의 코어 섀도우 + 외곽으로 부드럽게 확산

━ 촬영 스펙 ━
미디엄 포맷 100MP, 100mm 매크로 렌즈, f/6.3, ISO 100
초점은 원단 표면에 정확히. 짜임 한 올이 식별될 것
광학 특성: 자연스러운 포커스 롤오프, 옅은 코너 비네팅, 고운 그레인
과채도·필터 룩·CGI 느낌 금지

━ 금지 ━
원단 종류 변경, 색 보정, 디테일 추가·삭제, 실루엣 왜곡,
이미지에 텍스트·숫자·워터마크 렌더링, 없던 주름 창작
```

`[배치 선택]`과 `[앵글 선택]`은 `각도배치카탈로그.md`에서 가져온다.

## 2. 클로즈업형 — 특정 부위 확대

```
첨부한 상품 실물 사진에서 [부위]만 확대한 디테일컷을 생성한다.

불변: 원단 짜임, 색, 봉제선, 스티치 색과 땀 간격, 하드웨어 형태.
      원본에 없는 요소를 추가하지 않는다.

프레이밍: [부위]가 화면의 70%를 차지하게. 주변 원단이 조금 보여 맥락이 남게
카메라: 100mm 매크로, f/8, 초점은 [부위] 표면
조명: 측면 그레이징 라이트. 입체 요소(스티치·단추·리브)에 미세한 그림자가 생기게
배경: 초점에서 벗어나 부드럽게 흐려진 원단 면
```

`[부위]` 예시 — 칼라 / 넥 리브 / 커프스 / 밑단 리브 / 단추와 앞단 / 포켓 / 자수 / 라벨 / 지퍼 / 어깨 솔기 / 안감 / 밑단 프린지

## 3. 시리즈형 — 같은 세션에서 이어 생성

기본형으로 첫 컷을 받은 뒤, 2번째부터는 짧게 쓴다.

```
같은 상품, 같은 원단, 같은 색, 같은 조명 설정 유지.
배치와 앵글만 교체: [배치] / [앵글]
```

**의상 사진을 매번 다시 첨부하지 않는다.** 재첨부하면 옷을 다시 해석해서 원단 표현이 미세하게 달라진다.

단, 원단이나 색이 흐트러지기 시작하면 원본 사진을 다시 첨부하고 아래로 복귀한다.

```
첨부한 원본이 기준이다. 직전 생성물은 버리고 이 원단·색으로 복귀.
배치와 앵글만 [배치] / [앵글] 로.
```

## 4. 설정

```
모델 Gemini 3 Pro Image (Nano Banana Pro)
Temperature 0.4   ← 재구성은 창작이 아니다. 낮게 잡는다
Thinking High
Media resolution High   ← 원본 원단 판독 정확도에 직결
Grounding OFF
Output length 최대값
```

포즈 시리즈(0.6)보다 낮게 잡는 이유는 원본 충실도가 최우선이기 때문이다.
