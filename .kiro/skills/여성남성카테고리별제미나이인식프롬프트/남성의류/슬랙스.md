# 남성 슬랙스

**본질** — 턱 유무와 밑단 폭, 그리고 센터 크리스. 이 셋이 정장용과 캐주얼을 가른다.

## 추출 프롬프트

```
첨부한 남성 슬랙스 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 실루엣: 스트레이트/와이드/테이퍼드/슬림
2. 턱·플리츠: 노턱/원턱/투턱 + 턱 방향
3. 센터 크리스: 프레스 라인 유무와 선명도
4. 밑단 폭: 좁음/보통/넓음 + 발등을 덮는 정도
5. 밑단 마감: 정단/턴업(더블) + 턴업 폭
6. 기장: 밑단이 닿는 위치 + 신발 위 고임 주름 개수
7. 허리: 밴드 폭 + 벨트 루프 + 밴딩 여부(없음/부분/전체)
8. 원단 인상: 광택 + 두께 + 형태 유지력(빳빳/드레이프) + 결(트로피컬·헤링본 느낌)
9. 포켓: 사이드(사선/세로) + 백 포켓 형태
10. 컬러: 색명 + 톤 + 패턴(체크·스트라이프는 간격까지)
11. 용도 판정: 정장 세트업 / 비즈니스캐주얼 / 캐주얼 + 근거 한 줄
12. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **턴업(밑단 접음) 마감을 놓친다.** 클래식 라인의 핵심 단서다. 5번 유지.
- 센터 크리스를 "주름"으로 뭉갠다. 3번에서 따로 받는다.
- 사이드 포켓의 사선·세로 구분을 빼먹는다. 정장용은 사선이 많다.
- 11번을 넣으면 카테고리 분류와 검색 태그가 한 번에 정리된다.
