# 남성 니트 · 스웨터

**본질** — 게이지와 넥라인. 남성 니트는 여기에 어깨 구조가 더해져 체형 인상이 갈린다.

## 추출 프롬프트

```
첨부한 남성 니트 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 실루엣: 레귤러/오버핏/슬림 + 기장
2. 넥라인: 크루/브이/모크/터틀/하프집업 + 깊이
3. 게이지: 하이(촘촘)/미들/로우(굵은 조직)
4. 조직: 플레인/케이블/피셔맨/와플/배색
5. 어깨: 셋인/드롭/래글런 + 솔기 위치
6. 소매: 기장 + 소매통 여유
7. 리브: 목·소매·밑단 리브 폭
8. 두께감: 겹침 그림자와 실 굵기로 판단되는 범위만
9. 컬러: 색명 + 톤 + 채도 + 배색 패턴 유무
10. 드레이프: 몸에 붙는 정도 + 밑단 낙하 방향
11. 표면: 보풀·기모·광택 유무
12. 판정: 계절 / 어울리는 상황(오피스·데일리) / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **케이블과 피셔맨을 혼용한다.** 무늬 폭과 반복 간격을 묻으면 구분된다.
- 하프집업을 모크넥으로 답한다. 지퍼 유무를 2번에서 명시하게 한다.
- 소재 혼용률을 추측한다. "불명" 강제 필수.
- 오버핏을 드롭숄더와 동일시한다. 5번을 따로 둔다.
