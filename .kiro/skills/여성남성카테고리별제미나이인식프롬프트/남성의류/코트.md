# 남성 코트

**본질** — 총장과 라펠 구조. 어깨에서 밑단까지 떨어지는 직선이 흐트러지면 상품 가치가 떨어져 보인다.

## 추출 프롬프트

```
첨부한 남성 코트 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 싱글/더블/체스터필드/발마칸/트렌치/발마칸/더플 중 판단되는 것
2. 총장: 숏/미들/롱/맥시 + 밑단이 닿는 신체 위치
3. 실루엣: 스트레이트/A라인/오버 박시 + 허리 절개 유무
4. 어깨: 정위치/드롭/래글런 + 패드감
5. 칼라·라펠: 노치드/피크드/스탠드/후드 + 라펠 폭 + 고지 라인 높이
6. 여밈: 단추 개수·배열 + 히든 플라켓 여부 + 벨트 유무
7. 소재 인상: 표면 결(울·모직 느낌) + 기모 유무 + 두께
8. 드레이프: 형태 유지 / 흐름 + 걸을 때 벌어지는 정도
9. 포켓: 형태(플랩/웰트/사선) + 위치
10. 뒤 트임: 없음/센터벤트/사이드벤트
11. 소매: 기장 + 소매 단추 유무
12. 안감: 판단 가능 여부 명시 후 가능하면 유무
13. 컬러: 색명 + 톤 + 패턴(헤링본·글렌체크는 간격까지)
14. 판정: 계절(초겨울/한겨울) / 어울리는 상황(정장 위·캐주얼) / 무드 각 한 줄

출력은 1~14 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **고지 라인(라펠 접합 높이)을 놓친다.** 클래식 코트의 시대감을 결정하는 요소다.
- 소재를 "캐시미어"로 단정한다. 7번을 인상으로 제한한다.
- 벤트(뒤 트임) 종류를 빼먹는다. 정장 위에 걸칠 수 있는지 판단 근거가 된다.
- 헤링본·글렌체크의 간격을 무시한다. 패턴 스케일이 상품 인상을 좌우한다.
