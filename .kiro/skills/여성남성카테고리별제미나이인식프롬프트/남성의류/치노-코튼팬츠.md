# 남성 치노 · 코튼팬츠

**본질** — 트윌 결의 선명도와 워싱감. 신품 느낌이냐 빈티지냐가 여기서 갈린다.

## 추출 프롬프트

```
첨부한 남성 치노/코튼팬츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 실루엣: 스트레이트/테이퍼드/와이드/슬림/카고
2. 허벅지 여유: 몸에 붙음/보통/여유 있음
3. 밑단 폭: 좁음/보통/넓음 + 발등 덮는 정도
4. 기장: 밑단이 닿는 위치 + 고임 주름 개수
5. 턱: 노턱/원턱/투턱
6. 허리: 벨트 루프 + 밴딩 여부 + 드로스트링 유무
7. 원단 결: 트윌 사선 결의 선명도(뚜렷/보통/평활)
8. 워싱·가공: 없음(신품감)/워싱/빈티지 가공 + 색 빠짐 위치
9. 포켓: 사이드 형태 + 백 포켓(플랩·웰트) + 카고 포켓이면 크기와 위치
10. 두께감: 주름 잡히는 방식으로 판단되는 범위만
11. 컬러: 색명 + 톤 + 채도 (베이지·카키·올리브는 톤 구분 중요)
12. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **베이지·카키·올리브를 뭉갠다.** 치노에서 색 톤은 구매 결정 요인 1순위다. 11번에서 톤을 강제한다.
- 트윌 결을 놓쳐 "코튼 팬츠"로만 답한다. 7번이 치노 판별의 핵심이다.
- 카고 포켓 유무로 카테고리가 바뀌는데 이를 디테일로만 처리한다. 1번에 카고를 포함한 이유다.
- 워싱 없는 신품감과 워싱 가공을 구분하지 않는다. 8번 유지.
