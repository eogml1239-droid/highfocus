# 여성 자켓

**본질** — 기장과 어깨 구조. 여기에 소재 종류(트위드·레더·데님·울)가 얹혀 인상이 완성된다.

## 추출 프롬프트

```
첨부한 여성 자켓 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 트위드/레더/데님/블레이저/블루종/사파리/패딩자켓 중 판단되는 것
2. 기장: 크롭/세미크롭/허리선/힙 + 밑단이 닿는 위치
3. 어깨: 정위치/드롭/패드 삽입 여부 + 솔기 위치
4. 칼라: 노칼라(라운드)/테일러드/셔츠칼라/스탠드 + 라펠 폭
5. 여밈: 지퍼/단추 + 개수 + 하드웨어 색·재질 인상
6. 포켓: 개수 + 형태(플랩/웰트/패치)
7. 소재 인상: 표면 결 + 광택(무광/은광/유광) + 두께
8. 조직·질감: 트위드면 짜임 굵기, 레더면 표면 결, 데님이면 워싱
9. 밑단·소매 마감: 정단/프린지/리브 밴드/커프스
10. 디테일: 체인 트리밍, 스티치 색, 배색 라인, 소매 버튼
11. 안감: 판단 가능 여부 명시 후 가능하면 유무
12. 컬러: 색명 + 톤 + 채도
13. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **합성피혁을 천연가죽으로 단정한다.** 7번을 "인상"으로 제한하고, 소재 단정은 사용자 정보로만 채운다.
- 트위드 짜임 굵기를 빼먹는다. 굵은 트위드와 촘촘한 트위드는 가격대가 다르게 읽힌다.
- 라펠 폭을 무시한다. 블레이저는 라펠 폭이 시대감을 결정한다.
- 프린지 마감을 "밑단 처리"로 뭉갠다. 9번에서 따로 받는다.
