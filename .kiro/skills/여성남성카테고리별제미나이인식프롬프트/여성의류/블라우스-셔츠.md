# 여성 블라우스 · 셔츠

**본질** — 칼라 형태와 원단의 광택·흐름. 이 둘이 오피스냐 데일리냐를 가른다.

## 추출 프롬프트

```
첨부한 여성 블라우스/셔츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 칼라: 레귤러/와이드스프레드/버튼다운/차이나/보타이/노칼라 + 칼라 크기
2. 여밈: 앞단 단추 개수 + 히든 플라켓 여부 + 단추 소재·색
3. 핏: 오버/레귤러/슬림 + 허리 절개나 다트 유무
4. 기장: 밑단이 닿는 위치 + 앞뒤 기장차 유무
5. 소매: 기장 + 커프스 형태(싱글/더블/밴딩) + 퍼프·셔링 유무
6. 원단 인상: 광택(무광/은광/새틴) + 구김감 + 두께
7. 드레이프: 몸에 붙는지 / 떨어지는지 + 주름이 생기는 방식
8. 비침: 판단 가능 여부 명시 후 가능하면 정도
9. 디테일: 요크 절개, 프릴, 파이핑, 자수 위치
10. 컬러: 색명 + 톤 + 채도 + 패턴(스트라이프·체크는 간격까지)
11. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **새틴과 실크를 혼용해 답한다.** 소재를 단정하지 말고 6번처럼 "광택 인상"으로만 받는다.
- 스트라이프·체크의 간격과 폭을 빼먹는다. 10번에 간격을 명시하게 한다.
- 퍼프 소매를 일반 소매로 처리한다. 5번에서 따로 묻는다.
- 블라우스 비침은 구매 문의가 가장 많은 항목이다. 8번을 반드시 유지한다.
