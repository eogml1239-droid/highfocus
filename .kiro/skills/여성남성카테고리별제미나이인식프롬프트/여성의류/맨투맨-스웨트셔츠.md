# 여성 맨투맨 · 스웨트셔츠

**본질** — 안감 기모 유무와 기장이 계절과 용도를 결정한다.

## 추출 프롬프트

```
첨부한 여성 맨투맨 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 기장: 크롭/레귤러/롱 + 밑단이 닿는 신체 위치
2. 핏: 오버핏/레귤러/슬림 + 어깨 솔기 위치
3. 넥: 라운드 넥 리브 폭 + 삼각 거셋 유무
4. 소매: 셋인/드롭/래글런 + 소매 리브 폭
5. 밑단: 리브 밴드 / 절단 / 스트링 조임
6. 안감: 기모/쭈리(후라이스)/판단 불가 중 하나 + 근거
7. 표면: 보풀·워싱·빈티지 가공 유무
8. 프린트·자수: 위치(중앙/좌측 가슴/등판) + 크기 + 색
9. 컬러: 색명 + 톤 + 채도
10. 두께감: 주름 잡히는 방식으로 판단되는 범위만
11. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 기모와 쭈리를 사진만으로 단정한다. 6번에서 "판단 불가" 선택지를 반드시 남겨둔다.
- 프린트 크기를 빼먹어 상품명이 부실해진다. 8번에 크기를 명시하게 한다.
- 드롭숄더를 오버핏과 같은 말로 처리한다. 어깨 솔기 위치를 따로 묻는다.
