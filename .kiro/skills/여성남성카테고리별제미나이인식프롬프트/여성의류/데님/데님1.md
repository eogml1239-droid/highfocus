# 여성 데님 — 최종 프롬프트

실제 생성 테스트(2026-09-21, 여성A 6컷) 결과 반영.

```
✅ 인물 동일성 유지는 성공한다
❌ 워싱 페이딩 위치가 컷마다 이동한다      ← 핵심 문제
❌ 신발이 컷마다 바뀐다
❌ 손으로 옷을 잡는 포즈는 손가락이 뭉개진다
❌ 포토샵 톤 보정이 접지 그림자와 데님 색을 죽인다
```

순서는 셋입니다.

```
1단계  원본 사진에서 데님 정보 뽑기
2단계  정면 기준컷 1장 만들기
3단계  기준컷을 첨부해 나머지 포즈 이어가기
```

# 1단계 · 원본 사진에서 정보 뽑기

원본 데님 사진을 첨부하고 아래를 붙여넣으세요.

```
첨부한 여성 데님 사진을 보고 아래 항목을 채워줘.
사진으로 알 수 없는 건 "불명"이라고 쓰고 절대 추측하지 마.
각 항목 한 줄씩, 번호 리스트로만 답해.

1. 허리 높이 : 하이 / 미드 / 로우 (배꼽 기준 위아래 어디인지)
2. 실루엣 : 스키니 / 슬림 / 스트레이트 / 부츠컷 / 플레어 / 와이드
3. 퍼짐 시작 지점 : 무릎 위 / 무릎 / 무릎 아래 / 퍼지지 않음
4. 기장 : 복사뼈 위 몇 cm인지, 또는 신발 위에 고이는지
5. 밑단 마감 : 정단 / 컷오프 / 트임
6. 색 : 라이트 / 미드 / 다크 인디고 / 블랙 / 에크루 + 밝기 단계
7. 워싱으로 밝아진 위치 : 아래 네 곳을 각각 "있음/없음 + 세기"로 답해
   - 허벅지 앞면 중앙
   - 무릎 위
   - 엉덩이 뒷면 중앙
   - 밑단 안쪽
   그 외 위치에 있으면 위치를 적어줘
   ※ 주름 때문에 생긴 그림자는 워싱이 아니다. 구분해서 답해
8. 사타구니 주름선(휘스커) : 좌우 개수와 각도
9. 무릎 뒤 주름선 : 있음/없음 + 진하기
10. 데미지(찢어진 부분) : 있음/없음 + 위치
11. 원단 사선 결 : 왼쪽 위로 / 오른쪽 위로 + 결이 뚜렷한지
12. 박음질 실 색 : 오렌지 / 황색 / 같은 색 + 뒷주머니 박음질 모양
13. 리벳과 단추 : 개수와 위치 + 금속 색
14. 허리 처리 : 밴딩 없음 / 부분 밴딩 / 전체 밴딩 + 벨트 고리
15. 두께감 : 얇음 / 보통 / 도톰 (주름 잡히는 모양으로 판단)
16. 신축성 : 불명 (사진으로 판별 불가)
17. 어울리는 계절 / 상황 / 무드 : 각 한 줄
```

**답을 저장해 두세요.** 2단계에서 그대로 씁니다.

# 2단계 · 정면 기준컷 만들기

정면부터 만듭니다. 테스트에서 정면컷의 워싱이 가장 정상적으로 나왔습니다.

새 세션을 열고 원본 데님 사진을 첨부한 뒤, `▶` 자리에 1단계 답을 채워 넣으세요.

```
첨부한 데님을 착용한 전신 피팅컷. 정면 기준컷.

■ 모델 (절대 안 바뀜)
한국 여성 20대 중반, 168cm / 48kg
어깨 37 · 가슴 80 · 허리 60 · 엉덩이 86 · 팔길이 56 · 인심 78 · 발 240mm
7.8등신. 쇄골 뚜렷, 손목발목 얇음, 근육 융기 없음
얼굴 : 세로로 살짝 긴 계란형, 좁고 끝이 둥근 턱선,
       차분한 아몬드 눈에 옅은 쌍꺼풀, 직선 콧대와 작은 코끝,
       얇은 입술, 뉴트럴 아이보리 쿨톤
헤어 : 흑갈색, 어깨 아래 20cm, 자연 C컬, 가르마 왼쪽으로 살짝

■ 데님 (절대 안 바뀜)
색 : ▶ 1단계 6번 답. 진한 상태 그대로. 밝게 만들지 마라
워싱으로 밝아진 곳 : ▶ 1단계 7번 답에서 "있음"인 곳만 적기
                    적힌 곳 외에는 만들지 마라
엉덩이 옆면·힙 측면에 사각형 밝은 얼룩을 만들지 마라
휘스커 : ▶ 1단계 8번 답
원단 사선 결 : ▶ 1단계 11번 답. 표면에서 보일 것. 문질러 없애지 마라
박음질 실 색 : ▶ 1단계 12번 답
리벳·단추 : ▶ 1단계 13번 답
실루엣 : ▶ 1단계 1번 + 2번 + 3번 답
기장 : ▶ 1단계 4번 답
데님은 두꺼운 원단이다. 얇은 천처럼 흐르게 만들지 마라

■ 신발 (절대 안 바뀜 — 모든 컷 동일)
▶ 예시: 블랙 가죽 앵클부츠, 굽 3cm
로퍼나 더비로 바꾸지 마라

■ 상의
화이트 반팔 티셔츠. 밑단은 데님 허리 위에 걸치게

■ 촬영
Hasselblad H6D-100c, 150mm f/4.5, ISO 100
거리 5.5m, 카메라 높이 100cm
배경 : 뮤트 그레이 벽, 부드럽게 흐림
조명 : 3점. 45도 상단 소프트박스 + 필 + 후면 림, 5400K
발밑 : 신발이 바닥에 닿는 지점에 진한 그림자, 밖으로 부드럽게 퍼짐

■ 피부
팔과 손에 모공, 팔꿈치 주름, 손등 힘줄이 보일 것

■ 포즈
```

# 3단계 · 나머지 포즈

**기준컷 이미지를 `+`로 첨부하고** 아래를 쓰세요. 텍스트만으로는 워싱이 이동합니다.

```
첨부한 이미지가 기준이다.
데님 색, 밝기, 워싱 위치, 원단 결, 박음질 실 색을 그대로 복제해라.
인물, 얼굴, 헤어, 체형, 신발, 상의, 배경, 조명, 발밑 그림자도 똑같이.

워싱은 원단에 물들어 있는 것이다. 포즈가 바뀌어도 움직이지 않는다.
새로 생긴 주름 그림자를 워싱으로 만들지 마라.

포즈만 바꿔줘 : [아래에서 하나 고르기]
```

### 포즈 목록

```
3/4 측면 45도로 몸을 돌리고 시선은 렌즈로
완전 측면 90도, 양팔은 자연스럽게 내림
후면, 고개만 살짝 돌림 (뒷주머니와 밑단 보이게)
한쪽 다리 앞으로 내밀고 체중은 뒤쪽 다리에
걷는 한 순간, 앞발이 바닥에 닿는 순간
```

### 후면컷에만 한 줄 추가

```
엉덩이 워싱은 좌우 대칭으로, 세기는 허벅지보다 약하게.
```

# 문제 해결

| 이런 증상 | 이 문장 추가 |
|---|---|
| 워싱이 다른 곳으로 이동 | `워싱은 허벅지 앞면 중앙과 무릎 위에만 있다` |
| 힙 옆에 밝은 얼룩 생김 | `엉덩이 옆면에 사각형 밝은 패치를 만들지 마라` |
| 색이 밝아짐 | `조명이 같으니 색도 같다. 색 보정 금지` |
| 원단 결이 사라짐 | `원단 사선 결이 표면에서 보일 것` |
| 신발이 바뀜 | 신발 문장을 다시 붙여넣기 |
| 손이 뭉개짐 | 옷 잡는 포즈를 쓰지 않는다 |
| 얼굴이 흐림 | `얼굴은 초점이 맞을 것` 추가 |
| 워싱이 사라져 생지처럼 됨 | 기준컷을 다시 첨부해 재생성 |

3번 이상 실패하면 새 세션을 열고 기준컷을 첨부해 다시 시작하세요.

# 포토샵 (지금 방식이 품질을 떨어뜨립니다)

테스트에서 확인된 것 — **원본이 후처리본보다 좋았습니다.**

```
절대 하지 말 것
✗ 전체 밝기·노출 올리기     → 접지 그림자가 사라진다
✗ 콘트라스트 낮추기          → 원단 결이 뭉개진다
✗ 채도 낮추기                → 데님이 그레이로 변한다 (상품 색상 왜곡)
✗ 접지 그림자 그려 넣기      → 이미 있다. 건드리지 말 것

할 것 (이것만)
1. 피부 영역만 마스크 → Noise 추가 → Soft Light 6~8%
   ※ 옷에는 절대 적용하지 않는다
2. 머리카락 몇 가닥을 얼굴 쪽으로 빼기
3. Camera Raw → 비네팅 -8
4. 전체에 동일 강도 그레인 (마지막 단계)
```

데님 색은 원본 기준으로 잠그세요. 스포이드로 허벅지 같은 지점의 RGB를 원본과 비교하면 눈으로 놓치는 차이가 잡힙니다.

# Gemini가 자주 틀리는 것 (1단계 추출용)

- **부츠컷과 플레어를 섞는다.** 퍼짐 시작 지점을 따로 묻는 3번이 구분선이다.
- **주름 그림자를 워싱으로 답한다.** 7번의 단서 조항이 이를 막는다.
- 워싱 페이딩을 "데미지"로 답한다. 색 빠짐과 손상을 분리해 묻는다.
- 신축성을 임의로 "스판 함유"라고 쓴다. 16번에서 차단한다.
- 하이웨이스트를 미드로 낮게 잡는다. 배꼽 기준을 명시하면 교정된다.
