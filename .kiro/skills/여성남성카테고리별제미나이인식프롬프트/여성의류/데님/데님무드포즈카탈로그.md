# 데님 무드 포즈 카탈로그 — 포즈7~26

바디라인을 강조하는 에디토리얼 무드 포즈 20개. 데님3(연청) · 데님4(다크 인디고) · 데님5(빈티지 미디엄) 공용.

```
전제  기준컷(포즈1)이 완성돼 있고, 같은 세션이 살아 있어야 한다
사용  아래 블록을 "컷2 이후" 프롬프트의 [포즈 지시] 자리에 그대로 붙여넣는다
번호  기존 카탈로그가 포즈6까지이므로 7번부터 이어진다
```

## 붙여넣는 틀

```
포즈N. 모든 LOCK 유지.
인물·얼굴·헤어·체형·데님 색·워싱 위치·상의·신발·배경·조명·접지 그림자 동일.
워싱은 원단에 물들어 있는 것이라 포즈가 바뀌어도 이동하지 않는다.
노출과 배경 밝기는 기준컷과 동일. 소품이나 포즈 때문에 밝게 보정하지 마라.
포즈만 교체 : ▶ 여기에 아래 블록 하나를 붙여넣는다
```

## 먼저 읽을 것 — 무드 포즈의 4대 함정

```
① 골반을 비틀면 워싱 페이딩이 따라 움직인 것처럼 보인다
   → 페이딩 고정 문장을 매 컷 유지한다. 특히 데님5

② 손이 몸에 닿는 포즈가 많아 손가락이 뭉개진다
   → 손이 닿는 위치를 "손등이 보이게" 또는 "손가락을 펴서"로 지정한다

③ 앉기·기대기 포즈는 발이 바닥에서 떨어져 접지 그림자 규칙이 깨진다
   → 해당 포즈에는 전용 그림자 문장을 같이 넣는다 (각 항목에 표기)

④ 소품이 프레임에 들어오면 전체 노출이 올라간다   ← 실제로 확인된 문제
   밝은 큐브·스툴·벽면이 화면을 차지하면 모델이 노출을 재계산한다.
   결과적으로 데님 청색기와 세피아 노랑기가 같이 빠져 뿌옇게 나온다.
   색이 틀어진 게 아니라 노출이 올라가서 색이 빠진 것이다
   → 소품 포즈에는 노출 고정 문장을 반드시 같이 넣는다
   → 해당 포즈 : 11 · 14 · 18 · 20 · 21 · 22
```

## 소품 포즈 전용 · 노출 고정 문장

포즈 11 · 14 · 18 · 20 · 21 · 22 에는 아래 두 줄을 포즈 지시 뒤에 덧붙입니다.

```
소품은 배경보다 밝지도 어둡지도 않은 뮤트 그레이 무광이다.
소품이 프레임에 들어와도 전체 노출·대비·채도를 기준컷과 똑같이 유지하고,
배경 벽의 밝기도 바꾸지 마라. 밝게 보정하지 마라.
```

이 두 줄을 빼면 후처리에서 노출을 되돌려야 합니다. 생성 단계에서 막는 게 훨씬 쌉니다.

# A. 스탠딩 · 라인 강조 (포즈7~12)

### 포즈7 · 크로스 레그

```
정면을 향한 채 오른발을 왼발 앞으로 교차해 딛고, 체중은 뒤쪽 왼다리에.
골반을 왼쪽으로 살짝 밀어 허리에서 힙으로 이어지는 곡선이 드러나게.
양팔은 몸통에서 떼어 내리고 손등이 보이게 손가락을 편다.
교차한 다리가 한 줄로 길게 이어지는 라인과 밑단 겹침이 보일 것.
```

보여주는 것 : 다리 길이, 부츠컷 밑단이 겹치는 라인
주의 : 앞발 신발이 뒤 신발을 완전히 가리지 않게

### 포즈8 · 하이힙 컨트라포스토

```
정면 직립. 골반을 오른쪽으로 크게 밀고 어깨는 반대쪽으로 기울여
몸통에 완만한 S라인을 만든다. 체중은 오른 다리.
왼손은 허벅지 옆에 가볍게 붙이고 오른팔은 내려 손을 노출.
허리선과 힙 곡선의 대비, 허벅지 워싱이 정면으로 보일 것.
```

보여주는 것 : 허리-힙 비율, 하이웨이스트 라인
주의 : 기울기가 과하면 7.8등신이 무너진다. `카메라 높이 100cm 유지` 추가

### 포즈9 · 애치드 백

```
정면에서 몸을 15도 돌리고 허리를 아주 살짝 젖혀 힙 라인을 세운다.
턱은 내리지 않고 시선은 렌즈로. 한 손은 허리 뒤 벨트 라인에 손등이 보이게,
반대 팔은 자연스럽게 내린다.
허리 밴드와 힙 상단의 원단 텐션이 보일 것.
```

보여주는 것 : 허리 밴드 피팅, 힙 원단 여유분
주의 : 젖힘이 과하면 자세가 부자연스러워진다. "아주 살짝"을 지운다면 결과가 무너진다

### 포즈10 · 원 핸드 인 백포켓

```
몸을 3/4 후면으로 돌리고 고개만 어깨 위로 돌려 시선은 렌즈로.
오른손 손끝만 뒷주머니에 살짝 걸치고 손등과 손목은 완전히 노출.
왼팔은 내려 몸통에서 떼어 둔다.
뒷주머니 위치와 힙 라인, 등판 요크 절개선이 보일 것.
```

보여주는 것 : 뒷주머니 디자인, 힙 핏
주의 : 손을 주머니에 깊게 넣으면 손목이 뭉개진다. "손끝만"이 핵심

### 포즈11 · 숄더 어게인스트 월

```
왼쪽 어깨를 뮤트 그레이 벽에 가볍게 붙이고 골반은 벽에서 떼어 앞으로 보낸다.
몸은 3/4 측면, 시선은 렌즈로. 양팔은 내려 손을 노출.
왼 무릎은 곧게, 오른 무릎은 살짝 굽혀 다리에 각을 만든다.
옆선 솔기와 허벅지에서 밑단까지 이어지는 실루엣이 보일 것.
접지 그림자는 벽 쪽으로 좁아지고 바깥으로 부드럽게 퍼진다.
```

보여주는 것 : 옆선, 부츠컷 퍼짐 각
주의 : 벽 색이 바뀔 수 있다. `배경은 뮤트 그레이 유지` 추가

### 포즈12 · 백 아치 룩백

```
완전 후면. 양발을 어깨너비보다 좁게 모으고 체중을 오른 다리에 실어
힙을 오른쪽으로 살짝 올린다. 고개만 왼 어깨 위로 돌려 시선은 렌즈로.
양팔은 몸통에서 떼어 내리고 손등이 보이게.
힙 워싱의 좌우 대칭, 뒷주머니 간격, 밑단 뒷면이 보일 것.
```

보여주는 것 : 후면 워싱, 뒷주머니, 등판 봉제선
주의 : 데님5는 후면 세피아 페이딩 문장을 반드시 함께 넣는다

# B. 다리 라인 집중 (포즈13~17)

### 포즈13 · 롱 스트라이드 워킹

```
렌즈를 향해 걸어오는 한 순간. 보폭을 크게 벌려 앞발이 바닥에 닿는 순간을 포착.
뒤쪽 다리의 부츠컷 밑단은 관성으로 뒤로 밀려 있다.
양팔은 걸음에 맞춰 자연스럽게 흔들리고 손은 펴진 상태.
시선은 렌즈로. 앞 허벅지의 워싱과 밑단의 퍼짐이 동시에 보일 것.
앞발 접지 지점에만 코어 섀도우, 뒷발은 뜬 상태라 그림자가 옅다.
```

보여주는 것 : 밑단 관성, 착용감, 원단 무게
주의 : 모션 블러가 생기면 `전신 초점 유지, 모션 블러 없음` 추가

### 포즈14 · 스텝업

```
왼발을 무릎 높이보다 낮은 그레이 큐브 블록 위에 올리고 체중은 오른 다리에.
몸은 정면에서 20도 돌리고 시선은 렌즈로.
왼손은 올린 무릎 위에 손가락을 펴서 얹고 오른팔은 내린다.
굽힌 무릎의 원단 접힘, 무릎 위 워싱, 밑단이 신발에 닿는 모습이 보일 것.
오른발 접지 지점과 블록 아래에 각각 코어 섀도우.
블록은 배경보다 밝지도 어둡지도 않은 뮤트 그레이 무광이다.
블록이 프레임에 들어와도 전체 노출·대비·채도를 기준컷과 똑같이 유지하고,
배경 벽의 밝기도 바꾸지 마라. 밝게 보정하지 마라.
```

보여주는 것 : 무릎 원단 거동, 신축성
주의 : **노출이 가장 잘 올라가는 포즈다.** 블록이 화면 하단을 크게 차지해서
      결과물이 뿌옇게 나오면 이 컷부터 다시 뽑는다

### 포즈15 · 백 크로스 스텝

```
몸을 3/4 측면으로 돌리고 뒷발을 앞발 반대쪽으로 교차해 뒤로 딛는다.
체중은 앞발. 상체는 정면으로 살짝 열고 시선은 렌즈로.
양팔은 내려 손을 노출하고 한쪽 손목은 살짝 바깥으로 꺾는다.
허벅지 안쪽 라인과 교차한 두 밑단의 층이 보일 것.
```

보여주는 것 : 인심 라인, 밑단 레이어
주의 : 두 신발이 겹쳐 하나로 뭉칠 수 있다. `두 신발이 각각 식별될 것` 추가

### 포즈16 · 원 레그 포워드 포인트

```
정면 직립에서 오른 다리를 앞으로 곧게 내밀고 발끝을 살짝 바깥으로 돌린다.
체중은 뒤쪽 왼 다리. 골반은 왼쪽으로 밀고 시선은 렌즈로.
왼손은 허리에 손등이 보이게, 오른팔은 내린다.
내민 다리의 허벅지 워싱과 무릎 아래 퍼짐 각도가 정면으로 보일 것.
내민 발은 바닥에 닿아 있고 두 발 모두 접지 그림자가 있다.
```

보여주는 것 : 부츠컷 퍼짐 각도, 앞면 워싱
주의 : 내민 다리가 과도하게 길어지기 쉽다. `7.8등신 유지` 추가

### 포즈17 · 니 인 · 토 아웃

```
정면 직립. 두 무릎을 안쪽으로 살짝 모으고 발끝은 바깥으로 벌린다.
체중은 양발에 고르게. 어깨는 편안히 내리고 시선은 렌즈로.
양팔은 몸통에서 떼어 내리고 손등이 보이게.
허벅지 앞면이 정면으로 펴져 워싱 면적이 가장 넓게 보일 것.
```

보여주는 것 : 허벅지 워싱 전체, 허벅지 밀착 핏
주의 : 워싱이 핵심인 데님5의 대표컷으로 쓸 수 있다

# C. 기대기 · 앉기 (포즈18~22)

### 포즈18 · 스툴 하프싯

```
뮤트 그레이 무광 스툴 끝에 엉덩이를 살짝만 걸치고 상체는 세운다.
왼 다리는 앞으로 곧게 뻗어 발바닥이 바닥에 닿고, 오른 다리는 굽혀 발을 바닥에.
몸은 3/4 측면, 시선은 렌즈로. 양손은 스툴 앞쪽 끝을 손가락을 펴서 짚는다.
뻗은 다리의 무릎 아래 퍼짐과 인심 라인이 보일 것.
두 신발의 접지 지점과 스툴 다리 아래에 각각 코어 섀도우.
스툴은 배경보다 밝지도 어둡지도 않은 뮤트 그레이 무광이다.
스툴이 프레임에 들어와도 전체 노출·대비·채도를 기준컷과 똑같이 유지하고,
배경 벽의 밝기도 바꾸지 마라. 밝게 보정하지 마라.
```

보여주는 것 : 앉았을 때 허리 밴드 거동, 총장
주의 : 앉으면 허리 밴드가 접힌다. `허리 밴드가 파이거나 벌어지지 않게` 추가.
      노출이 올라가기 쉬운 포즈다

### 포즈19 · 니일링 원 니

```
왼 무릎을 바닥에 대고 오른 다리는 세워 발바닥을 바닥에.
상체는 곧게 세우고 정면에서 25도 돌려 시선은 렌즈로.
오른손은 세운 무릎 위에 손가락을 펴서 얹고 왼팔은 내린다.
세운 다리의 허벅지 앞면과 무릎 원단 접힘이 보일 것.
무릎이 바닥에 닿는 지점과 오른발 접지 지점에 코어 섀도우.
```

보여주는 것 : 무릎 접힘 주름, 허벅지 워싱
주의 : 무릎 접힘 그림자를 워싱으로 착각한다. `접힘 그림자를 워싱으로 만들지 마라` 필수

### 포즈20 · 플로어 시팅 · 원 니 업

```
바닥에 앉아 왼 다리는 앞으로 뻗고 오른 무릎을 세운다.
상체는 곧게 세워 정면에서 30도 돌리고 시선은 렌즈로.
왼손은 바닥을 손가락을 펴서 짚고 오른팔은 세운 무릎을 감싸지 않고 옆에 내린다.
뻗은 다리의 밑단과 세운 무릎의 원단 텐션이 보일 것.
바닥에 닿은 엉덩이와 다리 아래에 넓고 부드러운 접지 섀도우.
```

보여주는 것 : 원단 두께, 무릎 텐션
주의 : 무릎을 팔로 감싸면 손가락이 뭉개진다. 감싸지 않게 명시

### 포즈21 · 월 리클라인

```
등 전체를 벽에 붙이고 서서 오른 무릎을 굽혀 발바닥을 벽에 붙인다.
왼 다리는 곧게 세워 체중을 받는다. 몸은 정면, 시선은 렌즈로.
양팔은 벽에 붙인 채 몸통에서 떼어 내리고 손등이 보이게.
굽힌 다리의 허벅지 워싱과 곧은 다리의 전체 라인이 대비되어 보일 것.
왼발 접지 지점에 코어 섀도우, 벽과 몸 사이에 얇은 컨택 섀도우.
```

보여주는 것 : 허벅지 워싱, 스트레치 거동
주의 : 벽에 닿은 발 위치가 자주 틀린다. 틀리면 포즈16으로 대체

### 포즈22 · 사이드 시팅

```
바닥에 측면으로 앉아 두 다리를 같은 방향으로 겹쳐 옆으로 접는다.
상체는 비틀어 정면을 향하고 시선은 렌즈로.
오른손은 바닥을 손가락을 펴서 짚고 왼손은 허벅지 옆에 가볍게 둔다.
겹친 다리의 밑단 층과 힙 라인이 함께 보일 것.
```
