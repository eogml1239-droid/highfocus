```

```

새로 생긴 주름 그림자를 워싱으로 만들지 마라.
노출과 배경 밝기는 기준컷과 동일. 소품이나 포즈 때문에 밝게 보정하지 마라.
포즈만 교체 : 3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.

마지막 줄의 포즈만 바꿔가며 재사용합니다.

```

포즈6  걷는 한 순간, 앞발이 바닥에 닿는 순간         → 부츠컷 밑단 관성

✗ 컬러 밸런스로 노랑기 빼기   → 워싱의 세피아 톤이 상품 특징이다. 빼면 다른 상품
✗ 콘트라스트 낮추기           → 크로스해치 결이 뭉개진다
✗ 얼룩 제거·힐링 브러시       → 페이딩을 오염으로 착각한 수정. 절대 금지
✗ 접지 그림자 그려 넣기       → 이미 있다

할 것
1. 피부 영역만 마스크 → Noise → Soft Light 6~8% (옷에는 미적용)
2. 머리카락 몇 가닥을 얼굴 쪽으로 빼기
3. Camera Raw → 비네팅 -8
4. 전체에 동일 강도 그레인 (마지막 단계)
```

색 검수는 스포이드로 두 지점을 봅니다. **허벅지 페이딩 중심(세피아 톤)** 과 **무릎 아래 진한 면(베이스 블루)**, 두 지점의 RGB를 원본 행거샷과 비교하세요. 이 상품은 한 지점만 보면 차이를 놓칩니다.

# 참고

- 상의와 신발을 LOCK에 넣은 이유는 이전 테스트에서 컷마다 신발이 바뀌었기 때문이다.
- 스타일링을 바꾸려면 상의 LOCK과 신발 LOCK만 교체하고 나머지는 그대로 둔다.
- **컬러웨이별 세션 분리는 필수.** 연청(데님3) · 다크 인디고(데님4) · 이 빈티지 미디엄(데님5)을 한 세션에서 섞으면 색이 서로 끌려간다. 특히 이 상품의 세피아 톤은 다른 컬러웨이로 번지기 쉽다.
- 워싱이 강한 상품이라 페이딩을 약하게 넣으면 밋밋한 일반 청바지로 보인다. 데님4(딥워시)와 반대 방향으로 조절한다.
