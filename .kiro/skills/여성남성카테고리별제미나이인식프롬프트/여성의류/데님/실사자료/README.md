# 실사자료 — 색 기준 측정용 원본

여기에 **실사 사진만** 넣는다. AI 생성물은 넣지 않는다.
측정 결과는 `..\색기준-실사자료대장.md` 에 기록한다.

## 파일명 규칙

```
[품목번호]_[색상]_[출처]_[범위].jpg

05_빈티지미디엄_리뷰착샷_무릎위.jpg
05_블랙_리뷰착샷_전신.jpg
05_연청_실물촬영_전신.jpg
```

출처는 `리뷰착샷` `공장사진` `실물촬영` 중 하나로 쓴다.
같은 색상이 여러 장이면 뒤에 `_1` `_2` 를 붙인다.

## 넣을 때 주의

```
✓ 원본 해상도 그대로. 리사이즈나 압축을 다시 하지 않는다  ← 색이 변한다
✓ 필터·자동보정을 적용하지 않은 상태
✓ 얼굴은 잘라내도 된다. 옷 영역만 있으면 측정된다
✗ 스크린샷으로 다시 찍지 않는다                          ← 화면 색역이 섞인다
✗ 카톡·인스타로 재전송한 파일은 피한다                    ← 재압축으로 색이 뭉개진다
```

지그재그 리뷰에서 원본을 내릴 수 있으면 그걸 쓴다.

```
                  주 기준 : ..._52442  (패치비중 65.4%, R−B +8.3, 대비 1.80)
                  보조    : ..._45900  (패치비중 46.7%, R−B +8.2, 대비 1.71)
                  폐기    : 1.jpeg 2.jpeg 3.jpeg (패치비중 88~97% = 피부·벽 혼입)

⬜ 연청           미확보
⬜ 다크 인디고     미확보
```

블랙 컬러웨이는 존재하지 않는 것으로 확인됐다(상품컷 3색). 대기 목록에서 제외.

## 파일이 들어오면 측정 순서

```
1. 프레임 안 중성색(흰 벽·문·바닥)으로 화이트밸런스 보정값 산출
2. 하의 영역을 공간으로 한정 (허리밴드 아래 ~ 밑단)
3. 그 영역을 웜/쿨 두 군집으로 분리
     세피아 패치  R − B > +2
     청색 베이스  B − R > +4
4. 각 군집의 평균 RGB → 패치 대비, 세피아 R−B
5. 정면 수직 컷이면 무릎 폭·밑단 폭 픽셀 측정 → 배수
```

**3번을 건너뛰면 안 된다.** 청색 우세 픽셀만 골라 데님 영역으로 삼으면
세피아 패치가 마스크에서 빠져 R−B가 음수로 나오고, 색상 판정을 완전히 틀린다.
실제로 두 번 오판한 지점이다. 자세한 것은 `..\색기준-실사자료대장.md` 의 측정 방법 절을 본다.

패치 비중이 85%를 넘으면 측정 실패로 간주하고 그 파일은 비율 판정에서 제외한다.
