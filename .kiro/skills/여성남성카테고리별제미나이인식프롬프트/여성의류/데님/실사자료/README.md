# 실사자료 — 색 기준 측정용 원본

여기에 **실사 사진만** 넣는다. AI 생성물은 넣지 않는다.
측정 결과는 `..\색기준-실사자료대장.md` 에 기록한다.

## 파일명 규칙

```
[품목번호]_[색상]_[출처]_[범위].jpg

05_빈티지미디엄_리뷰착샷_무릎위.jpg
05_블랙_리뷰착샷_전신.jpg
05_연청_실물촬영_전신.jpg
```

출처는 `리뷰착샷` `공장사진` `실물촬영` 중 하나로 쓴다.
같은 색상이 여러 장이면 뒤에 `_1` `_2` 를 붙인다.

## 넣을 때 주의

```
✓ 원본 해상도 그대로. 리사이즈나 압축을 다시 하지 않는다  ← 색이 변한다
✓ 필터·자동보정을 적용하지 않은 상태
✓ 얼굴은 잘라내도 된다. 옷 영역만 있으면 측정된다
✗ 스크린샷으로 다시 찍지 않는다                          ← 화면 색역이 섞인다
✗ 카톡·인스타로 재전송한 파일은 피한다                    ← 재압축으로 색이 뭉개진다
```

지그재그 리뷰에서 원본을 내릴 수 있으면 그걸 쓴다.

## 지금 대기 중

```
□ 05_빈티지미디엄_리뷰착샷_무릎위_1.jpg
□ 05_빈티지미디엄_리뷰착샷_무릎위_2.jpg
□ 05_블랙_리뷰착샷_전신.jpg
```

파일이 들어오면 측정 순서는 이렇다.

```
1. 블랙 전신샷 하이라이트 RGB → 조명 보정값
2. 같은 보정값을 빈티지 2장에 적용
3. 빈티지 페이딩 중심 + 솔기 2지점 측정 → 워싱 대비, 세피아 R−B
4. 블랙 전신샷에서 무릎 폭·밑단 폭 픽셀 측정 → 배수
```

두 사진이 같은 장소·같은 조명에서 찍혔는지 먼저 확인해야 1~2번이 성립한다.
다르면 각 사진에서 중성색을 따로 찾는다.
