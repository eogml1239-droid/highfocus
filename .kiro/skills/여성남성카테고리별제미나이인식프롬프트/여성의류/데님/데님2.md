`데님.md`와 **같은 제품, 색상만 다른 버전.** 실루엣·패턴·부속은 동일하고 워싱 컬러와 페이딩 세기만 바뀝니다.

| 항목 | 데님.md | 데님2.md |
|---|---|---|

## 확인된 정보 (사진 기준)

첨부 사진 2장(거울 셀카, 상반신~허벅지)에서 읽어낸 것입니다.

```
1. 허리 높이 : 미드 (허리선이 배꼽 근처. 상의가 덮어 정확한 판단은 제한적)

4. 기장 : 불명 (밑단 안 보임)
5. 밑단 마감 : 불명
6. 색 : 라이트 블루. 밝기 단계 = 밝음. 청색기 유지, 회색기 없음
7. 워싱으로 밝아진 위치
   - 허벅지 앞면 중앙 : 있음 / 세기 강함 (세로 띠가 선명)
   - 무릎 위 : 있음 / 세기 보통
   - 엉덩이 뒷면 중앙 : 불명 (후면 사진 없음)
   - 밑단 안쪽 : 불명
8. 휘스커 : 사타구니 좌우에 짧은 가로 주름선 각 2~3개, 완만한 각도. 선명함
9. 무릎 뒤 주름선 : 불명
10. 데미지 : 없음 (보이는 범위에서)
11. 원단 사선 결 : 불명 (사진 해상도 부족)
12. 박음질 실 색 : 앞단과 프론트 포켓 라인에 황색~연오렌지 스티치.
                  뒷주머니 모양은 불명
13. 리벳과 단추 : 앞 단추 1개, 실버 톤 금속. 리벳 위치는 불명확

15. 두께감 : 보통

17. 계절 / 상황 / 무드 : 사계절 / 데일리 · 가벼운 약속 / 밝고 편안한
```

**주의 2가지**

- 거울 셀카라 실내 조명과 거울 반사로 색이 왜곡돼 있습니다. **스튜디오 원본으로 색을 다시 확인하세요.** 이 상태로 생성하면 실물보다 회색기가 낄 수 있습니다.
- 무릎 아래 정보가 전혀 없습니다. `불명` 항목은 `데님.md`의 값(부츠컷, 퍼짐 시작 무릎 아래 등)을 그대로 쓰면 됩니다. 같은 제품이니까요.

# 문제 해결 (라이트 워싱 전용 항목 포함)

| 이런 증상 | 이 문장 추가 |
|---|---|
| **색이 어두워짐 (가장 흔함)** | `라이트 블루 유지. 다크 인디고로 만들지 마라` |
| **회색기가 낌** | `청색기를 유지하고 회색기를 넣지 마라` |
| **워싱이 사라져 밋밋해짐** | `색이 밝으므로 페이딩 대비를 뚜렷하게` |
| 워싱이 다른 곳으로 이동 | `워싱은 허벅지 앞면 중앙과 무릎 위에만 있다` |
| 힙 옆에 밝은 얼룩 생김 | `엉덩이 옆면에 사각형 밝은 패치를 만들지 마라` |
| 원단 결이 사라짐 | `원단 사선 결이 표면에서 보일 것` |
| 신발이 바뀜 | 신발 문장을 다시 붙여넣기 |
| 손이 뭉개짐 | 옷 잡는 포즈를 쓰지 않는다 |

라이트 워싱은 **어두워지는 방향으로 흔들립니다.** 다크 인디고 버전이 학습 데이터에 더 많아서입니다. 색 관련 문장을 빼지 마세요.

# 포토샵

```
절대 하지 말 것
✗ 전체 밝기·노출 올리기     → 접지 그림자가 사라진다
✗ 콘트라스트 낮추기          → 원단 결과 워싱 대비가 뭉개진다
✗ 채도 낮추기                → 라이트 블루가 회색으로 변한다
✗ 접지 그림자 그려 넣기      → 이미 있다. 건드리지 말 것

할 것 (이것만)
1. 피부 영역만 마스크 → Noise 추가 → Soft Light 6~8%
   ※ 옷에는 절대 적용하지 않는다
2. 머리카락 몇 가닥을 얼굴 쪽으로 빼기
3. Camera Raw → 비네팅 -8
4. 전체에 동일 강도 그레인 (마지막 단계)
```

라이트 워싱은 채도 손실이 특히 눈에 띕니다. 허벅지 지점 RGB를 원본과 대조하세요.
