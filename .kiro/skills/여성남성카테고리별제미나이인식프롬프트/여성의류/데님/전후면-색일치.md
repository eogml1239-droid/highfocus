# 전면컷 · 후면컷 색 일치

품목 05 작업의 **3번째 단계.** 기준컷(전면)이 나온 뒤 후면컷을 뽑을 때
두 컷의 데님 색과 워싱 세기가 어긋나는 문제를 잡는다.

```
전제  전면 기준컷이 검수를 통과해 저장돼 있어야 한다
목표  전면과 후면의 청색 베이스 밝기 차이 ±8 이내, 세피아 R−B 차이 ±2 이내
```

---

## 왜 후면이 어긋나는가 — 원인 셋

### ① 림 라이트가 후면에서 키 라이트로 바뀐다 (가장 큰 원인)

촬영 LOCK에 `림은 후면 스트립` 이 들어 있다. 전면컷에서는 이 조명이 인물 윤곽만
살리는 보조광이지만, **모델이 돌아서면 그 조명이 데님 전체를 정면으로 때린다.**

```
결과  후면 데님이 전면보다 밝게 뜬다
      → 세피아 패치가 밝아져 흰색 쪽으로 빠진다 (R−B 소실)
      → 청색 베이스도 함께 밝아져 패치 대비가 무너진다
```

후면컷에서는 **림 스트립을 낮춘다**고 명시해야 한다. 이 한 줄이 없으면 매번 밝아진다.

### ② "정면보다 면적이 넓다"를 "더 밝게"로 해석한다

`데님5.md` 의 후면 LOCK은 `정면보다 면적이 넓고 세기는 비슷하다` 로 적혀 있다.
Gemini는 면적이 넓다는 지시를 세기 상향으로 함께 적용한다.
**면적과 세기를 분리해서 못 박아야 한다.**

### ③ 정량 기준이 없다

`세기는 비슷하다` 는 검증 불가능한 서술이다. 숫자를 주면 흔들림이 줄고,
무엇보다 **검수에서 통과/불통을 판정할 수 있다.**

## 목표 수치 — 빈티지 미디엄 (데님5)

`색기준-실사자료대장.md` 의 확정 색 기준에서 가져온 값이다.

| 항목 | 목표 | 허용 |
|---|---|---|
| 세피아 R−B | **+8.3** | +6 ~ +11 |
| 패치 대비 (세피아÷베이스 밝기) | **1.7 ~ 1.8** | 1.6 이상 |
| 세피아 패치 HEX | `#A29F9A` | — |
| 청색 베이스 HEX | `#4F5B64` | 밝기 lum 85~100 |
| **전면 대비 후면 베이스 밝기 차** | **0** | **±8** |

마지막 행이 이 단계의 합격 기준이다.

## 후면컷 프롬프트 — `데님5.md` 포즈4 문장을 이것으로 교체한다

전면 기준컷을 **첨부한 상태에서** 같은 세션에 붙여넣는다.

```
포즈4 · 후면. 모든 LOCK 유지.
첨부한 전면 기준컷이 색 기준이다. 데님의 밝기와 채도를 그 이미지와 동일하게 맞춘다.

■ 조명 보정 — 후면컷에만 적용
후면 림 스트립을 2스톱 낮춘다. 등과 엉덩이에 하이라이트를 만들지 마라.
모델이 돌아섰다고 해서 데님을 밝게 하지 마라.
노출은 전면 기준컷과 동일하다. 후면이라고 밝히지 마라.

■ 후면 페이딩 — 면적과 세기를 분리한다
면적 : 뒷주머니 바로 아래부터 허벅지 뒷면 위쪽까지 가로로 넓게.
       엉덩이 중앙이 가장 밝고 바깥으로 갈수록 옅어진다. 좌우 대칭.
세기 : 전면 허벅지 페이딩과 **같은 세기**다. 면적이 넓다고 더 밝게 하지 마라.
       세피아 톤의 머스터드·베이지 기운을 전면과 동일하게 유지한다.
하한 : 세피아는 허벅지 뒷면 위쪽에서 멈춘다.
       무릎 아래로 내려오지 않는다. 무릎 아래부터 밑단까지는
       페이딩 없이 청색 베이스로 진하게 남는다.

■ 후면 디테일
뒷주머니는 각진 오각형, 좌우 간격 넓게. 허리 밴드 아래 완만한 V자 요크 절개선.
크로스해치 결이 엉덩이와 허벅지 뒷면에서 보일 것.
사이드 솔기와 인심 라인은 진하게 남는다.

■ 포즈
후면 직립. 고개만 왼쪽으로 살짝 돌려 옆얼굴 실루엣이 보이게 한다.
양팔은 몸통에서 살짝 떼어 내리고 손을 완전히 노출.
엉덩이와 허벅지 뒷면이 가려지지 않게 한다.

■ 금지
등·엉덩이 하이라이트, 후면 노출 상향, 세피아를 무릎 아래로 확장,
세피아를 흰색으로 탈색, 페이딩을 얼룩·오염처럼 그리기,
뒷주머니 위치 변경, 이미지에 글자·워터마크
```

## 검수 — 스포이드 2지점 × 2컷

전면컷과 후면컷을 **나란히 열고** 각각 두 지점을 찍는다. 눈으로 비교하지 않는다.
이 품목은 눈으로 보면 통과시켜 버린다.

```
전면컷  ① 허벅지 앞면 페이딩 중심     → R, G, B 기록
        ② 무릎 아래 진한 면            → R, G, B 기록
후면컷  ③ 엉덩이 중앙 페이딩           → R, G, B 기록
        ④ 무릎 아래 진한 면            → R, G, B 기록
```

| 검사 | 계산 | 합격선 |
|---|---|---|
| 후면 세피아가 살아있나 | ③의 R − B | +6 ~ +11 |
| 후면 대비가 유지되나 | ③밝기 ÷ ④밝기 | 1.6 이상 |
| **전후면 색이 맞나** | **②밝기 − ④밝기** | **절댓값 8 이내** |
| 전후면 세피아 방향이 맞나 | (①R−B) − (③R−B) | 절댓값 2 이내 |

밝기 = `0.299R + 0.587G + 0.114B`

세 번째 행이 이 단계의 본질이다. **②와 ④는 같은 원단의 같은 부위**(무릎 아래
베이스 색)이므로 전면·후면에서 같은 값이 나와야 한다. 여기서 8을 넘으면
색이 어긋난 것이고, 고객은 두 사진을 보고 다른 상품이라고 느낀다.

## 후처리에서 절대 하지 말 것

전후면 색이 어긋났을 때 **포토샵으로 맞추려 하지 않는다.**

```
✗ 후면컷 밝기를 내려서 전면에 맞추기
  → 세피아 패치가 같이 어두워져 R−B 를 잃는다. 대비도 함께 무너진다
✗ 커브·레벨로 부분 보정
  → 크로스해치 결이 뭉개진다
```

어긋나면 **다시 생성한다.** 위 증상별 문장을 추가해서 재생성하는 편이 항상 빠르다.

세피아가 옆면 중앙에 생기지 않는지를 본다. `데님5.md` 의 측면컷 추가 문장을 쓴다.

확정 색 기준으로 바꾼다. 두 색상은 아직 실사 자료가 없어 기준이 비어 있으므로,
전면 기준컷 자체를 기준으로 삼고 `전후면 베이스 밝기 차 ±8` 만 적용한다.
