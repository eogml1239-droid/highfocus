# 여성 니트 · 스웨터

**본질** — 구매 결정은 조직(게이지)과 넥라인에서 갈린다. 같은 색이라도 게이지가 바뀌면 다른 옷이 된다.

## 추출 프롬프트

```
첨부한 여성 니트 사진에서 아래만 추출해. 사진으로 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목은 한 줄, 판단 근거를 괄호로 짧게 붙여.

1. 실루엣: 크롭/레귤러/롱 + 오버핏/레귤러/슬림
2. 넥라인: 크루/브이/보트/터틀/모크/오프숄더 + 깊이
3. 게이지: 하이(촘촘)/미들/로우(굵은 조직)
4. 조직: 플레인/케이블/와플/링클/배색 + 방향
5. 소매: 셋인/드롭/래글런 + 기장
6. 리브: 목·소매·밑단 리브 폭과 조임 정도
7. 두께감: 겹침 그림자와 실 굵기로 판단되는 범위만
8. 비침: 판단 가능 여부 명시 후 가능하면 정도
9. 컬러: 색명 + 톤(밝은/가라앉은) + 채도
10. 드레이프: 몸에 붙는 정도 + 밑단 낙하 방향
11. 표면: 보풀·기모·광택 유무
12. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~12 번호 리스트만. 서술 문단 금지.
```

## Gemini가 자주 틀리는 것

- **게이지를 뭉개서 "니트 소재"로만 답한다.** 위 3번을 세 단계로 고정해 강제한다.
- 모크넥을 터틀넥으로 답한다. 접힘 유무를 묻는 게 안전하다.
- 소재 혼용률(울 100% 등)을 추측해 넣는다. "불명" 강제가 필수다.
- 밑단 리브가 짧으면 크롭으로 오판한다. 허리선 기준으로 다시 물으면 교정된다.
