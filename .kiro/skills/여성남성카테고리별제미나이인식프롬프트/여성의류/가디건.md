# 여성 가디건

**본질** — 단추 여미기 방식과 기장이 활용 범위를 정한다. 열었을 때와 닫았을 때 두 가지 옷이 된다.

## 추출 프롬프트

```
첨부한 여성 가디건 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 기장: 크롭/허리선/힙/롱 + 밑단이 닿는 신체 위치
2. 여밈: 단추 개수 + 단추 소재·색 + 간격(촘촘/넓음)
3. 넥라인: 라운드/브이/노칼라/숄칼라 + 깊이
4. 핏: 슬림/레귤러/오버 + 어깨 솔기 위치
5. 게이지: 하이/미들/로우 + 조직(플레인/케이블/배색)
6. 두께감: 단독 착용용 / 이너용 / 아우터용 중 어디에 가까운지
7. 포켓: 유무 + 형태(패치/웰트/절개)
8. 포인트: 자수·패치·배색 라인 위치와 크기
9. 컬러: 색명 + 톤 + 채도 (사진에 여러 색이면 전부)
10. 닫았을 때 인상 / 열었을 때 인상 각 한 줄
11. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 단추 개수를 세지 않고 "여러 개"로 답한다. 숫자를 명시하게 만든다.
- 자수·패치의 **위치**를 빼먹는다. 좌측 가슴인지 중앙인지가 상품명에 들어가므로 10번 항목이 중요하다.
- 얇은 가디건을 니트로 분류한다. 여밈 유무를 먼저 확인시키면 해결된다.
