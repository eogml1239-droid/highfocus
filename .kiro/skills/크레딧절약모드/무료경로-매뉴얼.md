# 무료 경로 매뉴얼

크레딧 0으로 돌릴 수 있는 작업 목록과 실행 방법.

## 왜 이게 가능한가

지금까지 만든 스킬 8개, 파일 79개는 전부 **완성된 프롬프트와 체크리스트**다. Kiro가 새로 생각해서 만들어야 하는 게 아니라, 이미 파일에 적혀 있다. 열어서 복사하면 끝이다.

Kiro 안에서 부르면 그 턴만큼 크레딧이 나가고, 파일을 직접 열어 복사하면 0이다. **결과물은 같다.**

---

## 1. 룩북/피팅컷 생성 — 크레딧 0

### 쓸 파일

| 목적 | 파일 |
|---|---|
| 모델별 포즈 프롬프트 | `모델별피팅포즈시리즈/여성A-168cm-48kg/포즈시리즈.md` (남성A·남성B·여성B 동일 구조) |
| 포즈 이어서 뽑기 | `모델별피팅포즈시리즈/다음포즈이어생성/다음포즈프롬프트.md` |
| 같은 인물에 옷만 바꾸기 | `다음포즈이어생성/인물유지의상교체.md` |
| **데님 전체 (전용 폴더)** | `여성남성카테고리별제미나이인식프롬프트/여성의류/데님/` |
| 인물 흔들림 복구 | `다음포즈이어생성/인물흔들림복구.md` |
| 카테고리별 인식 프롬프트 | `여성남성카테고리별제미나이인식프롬프트/여성의류/*.md`, `남성의류/*.md` |

### 순서

```
1. 해당 md 파일을 VS Code에서 열기
2. 프롬프트 블록 복사
3. Gemini 웹(또는 쓰던 이미지 생성 도구)에 사진 첨부 + 프롬프트 붙여넣기
4. 결과 저장
```

카테고리 프롬프트와 포즈 프롬프트를 **같이 붙여넣어야** 의도대로 나온다. 옷 인식 → 포즈 순서.

### Kiro를 불러야 하는 경우만

- 결과가 계속 어긋나서 프롬프트 자체를 고쳐야 할 때
- 없는 카테고리 프롬프트를 새로 만들어야 할 때

둘 다 **자산화 작업**이라 한 번 쓰면 이후 계속 무료가 된다. 이때는 써도 된다.

## 2. 후보정(실사화) — 크레딧 0, 이미 완전 자립

`모델별피팅포즈시리즈/작업순서-체크리스트.md`는 포토샵 조작 순서와 수치가 전부 적힌 완결 문서다. Kiro가 개입할 여지가 없다.

```
□ 작업순서-체크리스트.md 를 왼쪽 화면에 열어두기
□ 위에서 아래로 그대로 따라가기
□ 검수 항목까지 통과시키기
```

`CameraRaw실사화레시피.md`, `워터마크제거와용량축소.md`도 같은 성격이다.

**절대 Kiro에게 다시 묻지 말 것:** 수치가 몇이었는지, 순서가 어떻게 되는지. 파일에 다 있다. 물으면 크레딧만 나간다.

## 3. SNS 게시글 — 크레딧 0

### 방법: 무료 AI에 스킬을 그대로 이식한다

```
1. 아래 두 파일 전체를 복사
     .kiro/skills/SNS셀러말투홍보글작성/SKILL.md
     .kiro/skills/SNS셀러말투홍보글작성/platform-guidelines.md

2. 무료 AI(Gemini 웹, ChatGPT 무료 등)에 붙여넣고 첫 메시지로:
     "아래 규칙을 그대로 지켜서 홍보글을 써. 규칙 밖으로 나가지 마."
     (붙여넣은 내용)

3. 다음 메시지에 사진 첨부 + "이 사진으로 A 경험형 / B 디테일형 / C 상황제안형 3개"

4. 결과를 sns-out/YYYY-MM-DD/ 아래에 직접 저장
```

하루치를 한 번에 돌릴 거면 `하루치SNS게시글일괄생산/SKILL.md`와 `references/` 3개 파일도 같이 붙여넣는다. 발행 슬롯 배분까지 그 파일에 들어 있다.

### 이미 만든 게시글 재활용

`sns-out/2026-09-21/`에 어제치 15개가 있다. 상품이 겹치면 **새로 만들지 말고** 날짜와 문장 몇 개만 손으로 고쳐 쓴다. 단, 같은 플랫폼에 같은 문장을 다시 올리면 안 된다. 플랫폼을 바꿔 돌린다.

## Kiro 크레딧을 써야 하는 것 (대체 불가)

| 작업 | 이유 |
|---|---|
| HIGHFOCUS Worker 코드 수정 | 실제 파일을 고치고 빌드·테스트를 돌려야 한다 |
| 배포·롤백 | `.safe-deploy` 절차와 wrangler 실행이 필요하다 |
| 사이트 장애 대응 | 최우선. 비상 예비에서 쓴다 |
| 새 스킬·규칙 만들기 | 한 번 쓰면 이후 무료 경로가 된다 |
