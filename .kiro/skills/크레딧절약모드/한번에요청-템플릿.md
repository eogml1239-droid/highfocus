# 한 번에 요청 템플릿

되묻기를 없애는 것이 목적이다. 빈칸을 채워 붙여넣는다. 해당 없는 줄은 지운다.

---

## 기본 양식

```
[작업]
(무엇을 원하는지 한 문장)

[대상 파일]
(# 로 붙이거나 경로를 적는다. 내가 찾아다니지 않게)

[이미 정해진 것]
- 상품명:
- 모델:
- 플랫폼:
- 그 외 고정값:

[판단은 알아서]
위에 안 적은 건 물어보지 말고 합리적으로 정해서 진행해. 가정은 끝에 한 줄로 적어줘.

[원하는 결과 형태]
(파일로 저장 / 채팅에 코드블록 / 한 줄 답)

[하지 말 것]
되묻기, 요약, 추가 개선 제안
```

---

## 상황별 완성 예시

### 사이트 코드 수정 (Kiro 전용 경로)

```
[작업]
상품 상세 페이지에서 품절 상품에 "SOLD OUT" 배지를 띄워줘.

[대상 파일]
#src/api/index.ts #public/index.html

[이미 정해진 것]
- 배지 위치: 썸네일 좌측 상단
- 색: 검정 배경 흰 글씨

[판단은 알아서]
위에 안 적은 건 물어보지 말고 진행해. 가정은 끝에 한 줄로.

[원하는 결과 형태]
파일 수정하고 빌드까지 확인. 배포는 하지 마.

[하지 말 것]
되묻기, 요약, 리팩터링
```

### 기존 파일에 항목 추가 (저가 경로)

```
[작업]
여성의류 카테고리에 "베스트" 인식 프롬프트 파일 추가해줘.

[대상 파일]
#.kiro/skills/여성남성카테고리별제미나이인식프롬프트/여성의류/가디건.md
이 파일 형식 그대로 맞춰서.

[원하는 결과 형태]
같은 폴더에 베스트.md 생성

[하지 말 것]
되묻기, 다른 카테고리까지 손대기
```

### 잔량 갱신 (저가 경로)

```
크레딧 47 남았어. 절약모드 예산 표만 다시 계산해줘. 설명은 생략.
```
