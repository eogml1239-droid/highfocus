# 플랫폼별 섀도우밴 예방 가이드라인

일반적으로 알려진 각 플랫폼의 스팸/광고성 콘텐츠 판별 신호를 기반으로 정리한 작성 규칙이다. 플랫폼 알고리즘은 공개되지 않고 계속 바뀌므로, 이 규칙은 "위험을 낮추는 습관"이며 100% 방지를 보장하지 않는다.

---

## 인스타그램

- **해시태그**: 3~8개 정도로 제한. 게시물 내용과 무관한 인기 해시태그(#선팔 #맞팔 #좋아요 등) 남용 금지. 캡션 안에 자연스럽게 섞거나 첫 댓글로 분리.
- **반복 문구**: "DM 주세요", "링크 클릭" 같은 문구를 매 게시물 동일하게 쓰지 않는다.
- **외부 링크**: 캡션 본문에 URL을 직접 쓰지 않고 "프로필 링크 확인해주세요" 정도로 자연스럽게 유도.
- **게시 빈도**: 짧은 간격(몇 분 단위)으로 연속 업로드 금지. 하루 1~3건 정도로 분산.
- **팔로우/언팔로우 반복, 대량 좋아요/댓글 자동화 흔적** 금지 (밴 위험 신호).
- **말투**: 정보성 콘텐츠처럼 자연스럽게 (본 스킬의 셀러 말투 템플릿 적용). 광고 냄새 나는 CTA("지금 구매!") 대신 경험 공유형 문장 사용.

## 트위터(X)

- **링크 포함 트윗**: 노출이 줄어드는 경향이 있다고 알려져 있음. 링크는 스레드의 첫 트윗이 아니라 답글(첫 댓글)에 넣거나, 이미지/텍스트 중심으로 먼저 관심을 끈 후 링크를 뒤에 배치.
- **해시태그**: 1~2개로 최소화. 과도한 해시태그는 스팸 신호로 인식되는 경우가 많음.
- **반복/도배성 멘션, 동일 텍스트 여러 계정 게시** 금지.
- **짧고 자연스러운 문장** 위주로 작성하고, 스레드(연속 트윗) 형태로 나눠서 대화처럼 풀어내는 것이 홍보 느낌을 줄이는 데 도움됨.

## 핀터레스트

- **핀 설명(디스크립션)**: 키워드를 억지로 나열하지 않고 자연스러운 문장으로 작성. 키워드 스터핑(keyword stuffing)은 스팸 신호로 잡힘.
- **링크**: 핀이 연결되는 랜딩 페이지가 핀 내용과 실제로 일치해야 함 (불일치 시 스팸 판정 위험).
- **동일 이미지·동일 설명 반복 리핀** 금지. 매 핀마다 이미지/설명을 조금씩 다르게.
- **과도한 자동 생성/저품질 반복 게시** 금지. 게시 속도를 사람이 하는 수준으로 유지.
- **말투**: 정보/영감을 주는 톤("이런 스타일 어떠세요", "이렇게 활용해보세요") 위주로, 직접적인 판매 문구는 최소화.

## 페이스북

- **외부 링크가 포함된 게시물은 도달률이 낮아지는 경향**이 있다고 알려져 있음. 링크는 댓글로 옮기거나, 텍스트/이미지 중심 게시물로 먼저 관심을 끄는 방식 고려.
- **"참여 유도" 문구 금지 (Engagement Bait)**: "좋아요 누르면 할인", "댓글 남기면 추첨" 같은 명시적 참여 유도는 페이스북 정책상 페널티 대상.
- **동일 콘텐츠를 여러 그룹/페이지에 동시 대량 게시** 금지.
- **말투**: 페이지 구독자와 대화하듯, 일상 공유 + 자연스러운 제품 언급 구조 유지.

## 스레드 (Threads)

- 인스타그램과 연동된 서비스라 유사한 원칙 적용.
- **해시태그 기능이 제한적이므로 키워드는 본문 문장 안에 자연스럽게 녹여야 함.**
- **링크 포함 게시물도 노출이 줄어들 수 있다고 알려져 있어**, 링크보다는 대화/반응 유도형 텍스트 위주로 작성하고 링크는 답글이나 프로필 유도로 처리.
- **연속 대량 게시, 동일 텍스트 반복 금지.**
- **말투**: 트위터보다 조금 더 편안하고 일상적인 톤 (짧은 잡담 + 제품 자연스럽게 언급).

## 공통 체크리스트 (게시 전 확인)

- [ ] 이 플랫폼에서 권장하는 해시태그 개수를 넘지 않았는가
- [ ] 본문에 URL을 과도하게 노출하지 않았는가 (필요하면 댓글/바이오로 이동)
- [ ] "구매", "할인", "최저가" 등의 단어가 부자연스럽게 반복되지 않는가
- [ ] 다른 플랫폼에 올릴 글과 완전히 동일한 문장이 아닌가 (표현을 다르게 리라이팅했는가)
- [ ] 셀러 말투(질문형 시작 → 경험 공유 → 담백한 제품 설명 → 짧은 마무리)를 따르고 있는가
- [ ] 느낌표/이모지 남발 없이 자연스러운 톤인가
