# 하루치 SNS 게시글 일괄 생산 스킬

## 이 스킬이 하는 일

```
사진 1장  →  게시글 3개 (같은 옷, 서로 다른 느낌)
사진 5장  →  게시글 15개
```

하루 5개 플랫폼 × 3회 = 15회 업로드를 **한 번의 작업으로** 준비한다.

말투와 섀도우밴 규칙은 **`SNS셀러말투홍보글작성` 스킬을 그대로 따른다.** 작업 시작 전에 아래 두 파일을 반드시 읽는다.

- `.kiro/skills/SNS셀러말투홍보글작성/SKILL.md` — 셀러 말투 프로필 (브랜드·셀러 이름 사용 금지 규칙 포함)
- `.kiro/skills/SNS셀러말투홍보글작성/platform-guidelines.md` — 플랫폼별 섀도우밴 규칙

## 실행 절차

### 1단계 — 사진 분석

첨부된 사진을 **한 장씩 순서대로** 분석한다. 체크리스트는 `references/garment-analysis.md`를 따른다.

각 사진마다 아래 형식으로 분석 결과를 먼저 보여준다.

```
[사진 1]
· 아이템    : 오버사이즈 크롭 니트 + 와이드 데님
· 핏/실루엣  : 상의는 짧고 넉넉, 하의는 일자로 곧게 떨어지는 실루엣
· 컬러      : 아이보리 / 연한 인디고
· 소재감     : 도톰한 짜임, 데님은 워싱 없이 진한 톤
· 디테일     : 소매 끝 시보리, 밑단 절개
· 계절감     : 초가을 ~ 초겨울
· 어울리는 상황: 데일리, 카페, 가벼운 나들이
· 무드      : 편안하면서 정돈된 느낌
```

**사진에서 확인할 수 없는 정보는 절대 추측해서 쓰지 않는다.** (정확한 소재 혼용률, 가격, 사이즈 스펙, 세탁 방법 등) 게시글에 필요하면 사용자에게 묻고, 답을 받기 전까지는 `[상품명]`, `[가격]` 같은 placeholder로 비워둔다.

### 2단계 — 부족한 정보 확인

사진 분석만으로 게시글을 쓸 수 있으면 바로 3단계로 간다. 아래 정보가 없으면 **한 번에 모아서** 묻는다. 매 사진마다 따로 묻지 않는다.

- 상품명 (사진 순서대로)
- 입고/업데이트 날짜
- 강조하고 싶은 포인트가 따로 있는지

사용자가 "알아서 해줘"라고 하면 placeholder를 넣은 채로 진행하고, 나중에 채우면 된다고 안내한다.

### 3단계 — 사진 1장당 게시글 3종 작성

같은 옷이지만 **진입점이 다른** 게시글 3개를 만든다. 톤 정의는 `references/tone-variants.md`.

| 변형 | 톤 | 시작 방식 |
|---|---|---|
| A | 경험형 | 셀러 자신의 고민·경험에서 출발해 옷으로 연결 |
| B | 디테일형 | 입었을 때의 감각, 핏, 소재감을 담백하게 풀어냄 |
| C | 상황제안형 | "어디에 입고 갈까"를 질문으로 던지고 코디를 제안 |

세 개가 **같은 문장을 돌려쓰지 않도록** 한다. 문장 구조, 첫 문장, 마무리를 모두 다르게 만든다. 이건 섀도우밴 예방의 핵심이다.

### 4단계 — 발행 슬롯 배분

만든 게시글을 플랫폼과 시간대에 배분한다. 배분 규칙은 `references/distribution.md`.

기본 원칙 두 가지만 기억한다.

- **같은 사진의 A/B/C를 같은 플랫폼에 몰지 않는다.** 같은 옷이 한 계정 타임라인에 연달아 3번 뜨면 도배로 보인다.
- **같은 계정 업로드 간격은 최소 4시간.**

### 5단계 — 출력

아래 형식으로 내보낸다. 복사해서 바로 붙여넣을 수 있게 게시글 본문은 코드블록에 넣는다.

````
## 사진 1 — [상품명]

### A. 경험형 → 인스타그램 / 오전 8시

```
(게시글 본문)

#해시태그 #세트
```

### B. 디테일형 → 스레드 / 오후 1시

```
(게시글 본문)
```

### C. 상황제안형 → 핀터레스트 / 오후 9시

```
(게시글 본문)
```
````

마지막에 **하루 발행 표**를 한 장으로 정리해 붙인다.

| 시간 | 플랫폼 | 사진 | 변형 |
|---|---|---|---|
| 08:00 | 인스타그램 | 1 | A |
| 09:00 | 스레드 | 2 | B |
| ... | | | |

사용자가 파일로 저장을 원하면 `sns-out/YYYY-MM-DD/` 아래에 플랫폼별 마크다운으로 쓴다.

## 반드시 지키는 것

1. **사실이 아닌 정보를 만들지 않는다.** 소재, 가격, 사이즈, 원산지는 사용자가 준 것만 쓴다.
2. **AI 냄새 제거.** `SNS셀러말투홍보글작성`의 금지 목록(과장 카피, 느낌표 남발, 기계적 대칭 구조, 이모지 도배)을 그대로 적용한다.
3. **세 변형이 서로 다른 글이어야 한다.** 단어 몇 개 바꾼 수준이면 실패다.
4. **플랫폼 글자수와 해시태그 개수를 지킨다.** 인스타 3~8개, X 1~2개, 스레드는 본문에 녹임.
5. **본문에 URL 직접 노출 최소화.** 프로필 링크 유도로 처리한다.
6. **사진 장수 × 3 = 게시글 수.** 사진이 5장이면 15개를 다 만든다. 중간에 줄이지 않는다.
7. 사진 장수가 많아 출력이 길어지면 **사진 단위로 나눠서** 순차 출력한다. 요청 개수를 줄이는 걸로 대응하지 않는다.
