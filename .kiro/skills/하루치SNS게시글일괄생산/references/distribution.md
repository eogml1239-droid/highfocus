# 발행 슬롯 배분 그리드

## 기본 전제

- 플랫폼 5개: 인스타그램(IG), 스레드(TH), 트위터/X(X), 핀터레스트(PT), 페이스북(FB)
- 각 플랫폼 하루 3회 → 총 15슬롯
- 사진 5장 × 변형 3종 = 게시글 15개 → 슬롯과 1:1로 맞는다

## 두 가지 배분 규칙

**규칙 1 — 같은 사진의 A/B/C는 서로 다른 플랫폼으로 보낸다.**
같은 옷이 한 계정에 하루 세 번 뜨면 도배로 보인다. 플랫폼을 흩어야 한다.

**규칙 2 — 한 플랫폼에는 서로 다른 사진 3개가 들어간다.**
타임라인이 다양해 보이고, 중복 콘텐츠 신호를 피할 수 있다.

## 표준 그리드 (사진 5장 기준)

톤과 플랫폼 성격의 궁합까지 반영한 배치다.

| 시간 | 인스타그램 | 스레드 | X | 핀터레스트 | 페이스북 |
|---|---|---|---|---|---|
| 08:00 | 1-A | 2-A | 3-B | 4-C | 5-B |
| 13:00 | 5-C | 1-B | 2-B | 3-C | 4-A |
| 21:00 | 4-B | 3-A | 1-C | 5-A | 2-C |

`3-B` = 사진 3의 B변형(디테일형)

검증하면 이렇다.

- 사진 1: IG(A) / TH(B) / X(C) — 세 플랫폼으로 흩어짐 ✓
- 인스타그램: 사진 1, 5, 4 — 서로 다른 옷 ✓

## 톤과 플랫폼 궁합

배치를 바꿀 때 참고한다.

| 플랫폼 | 잘 맞는 톤 | 이유 |
|---|---|---|
| 인스타그램 | A 경험형, B 디테일형 | 캡션을 끝까지 읽는 비중이 높다 |
| 스레드 | A 경험형, C 상황제안형 | 대화·반응 유도형이 강하다 |
| X | C 상황제안형(짧게), B 디테일형 | 짧게 끊어야 한다. 긴 경험담은 안 맞는다 |
| 핀터레스트 | C 상황제안형 | 코디 제안·영감 콘텐츠가 핀 성격과 맞는다 |
| 페이스북 | A 경험형, B 디테일형 | 구독자와 대화하는 긴 글이 통한다 |

X에 배정된 글은 **반드시 짧게 다시 줄인다.** 다른 플랫폼 길이 그대로 쓰지 않는다.

## 시간대

한국 시간 기준. 같은 계정 업로드 간격 **최소 4시간**을 확보한 배치다.

| 회차 | 시간 | 특징 |
|---|---|---|
| 1회 | 08:00 ~ 09:00 | 출근길. 스크롤 시간 짧으니 첫 문장이 승부 |
| 2회 | 12:30 ~ 13:30 | 점심시간. 체류가 길다. 정보형이 잘 읽힌다 |
| 3회 | 20:00 ~ 22:00 | 반응률이 가장 높은 구간. 힘 준 게시글을 여기 배치 |

핀터레스트는 저녁~밤 시간대 반응이 특히 좋으니 C변형을 21시에 두는 걸 기본으로 한다.

## 사진 장수가 5장이 아닐 때

| 사진 | 게시글 | 처리 |
|---|---|---|
| 1장 | 3개 | 3개 다 다른 플랫폼으로. 나머지 플랫폼은 쉬는 날로 두거나 사용자에게 알린다 |
| 2장 | 6개 | 플랫폼당 1~2개. 간격을 넓게 잡는다 |
| 3장 | 9개 | 5플랫폼 중 4개는 2회, 1개는 1회 |
| 5장 | 15개 | 표준 그리드 그대로 |
| 6장 이상 | 18개+ | **하루에 다 올리지 말고 이틀로 나눈다.** 한 계정 하루 4회 이상은 도배 위험 |

## 해시태그 로테이션

같은 해시태그 세트를 하루에 반복하면 스팸 신호가 된다.

- 해시태그는 **아이템·계절·상황 태그로만** 구성한다. 게시글마다 조합을 다르게 한다.
- **브랜드 태그나 셀러 계정명 태그를 만들지 않는다.**
- 인스타그램 3~8개, X 1~2개, 핀터레스트는 설명문에 자연스럽게 녹임, 스레드는 해시태그 대신 본문 키워드로 처리
- **같은 날 두 게시글에 완전히 동일한 태그 조합을 쓰지 않는다.**
