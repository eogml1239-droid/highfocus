# 의류 착용 사진 분석 체크리스트

게시글을 쓰기 전에 사진에서 읽어낼 수 있는 것만 추린다. **읽어낼 수 없는 건 비워둔다.**

## 읽어낼 수 있는 것 (사진만으로 판단 가능)

| 항목 | 무엇을 보는가 |
|---|---|
| 아이템 종류 | 니트, 셔츠, 원피스, 팬츠, 자켓, 스커트 등 |
| 핏 / 실루엣 | 오버사이즈·레귤러·슬림, 크롭 여부, 밑단이 떨어지는 방향, 허리 라인 |
| 컬러 | 주 색상과 보조 색상. 톤(밝은/가라앉은), 채도 |
| 소재감 | 짜임의 굵기, 광택 유무, 구김감, 두께가 주는 인상 |
| 디테일 | 단추, 포켓, 절개, 시보리, 지퍼, 프릴, 자수, 패턴 |
| 스타일링 | 함께 착용한 아이템, 신발, 액세서리, 레이어드 방식 |
| 계절감 | 두께와 소재에서 오는 체감 계절 |
| 어울리는 상황 | 데일리, 출근, 데이트, 여행, 하객, 운동 등 |
| 무드 | 단정한, 편안한, 시크한, 사랑스러운, 활동적인 |
| 촬영 배경 | 실내/야외, 분위기 — 게시글 도입부 소재로 쓸 수 있다 |

## 절대 추측하지 않는 것

사진으로는 확인이 불가능한 항목이다. 사용자가 알려주지 않았다면 `[   ]` placeholder로 남긴다.

- 정확한 상품명
- 가격, 할인율
- 소재 혼용률 (예: "면 100%")
- 사이즈 스펙 (총장, 어깨너비, 허리 단면)
- 신축성, 비침 정도, 안감 유무
- 세탁 방법
- 원산지, 제조사
- 재고 수량, 입고 날짜

이 항목을 추측해서 쓰면 허위 표시가 된다. 의류는 표시광고 관련 분쟁이 잦은 품목이라 특히 조심한다.

## 표현으로 옮길 때

분석 결과를 스펙 나열로 쓰지 않는다. **입었을 때의 감각**으로 번역한다.

| 분석 | 나쁜 표현 | 좋은 표현 |
|---|---|---|
| 오버사이즈 크롭 니트 | "오버사이즈 크롭 핏입니다" | "품은 넉넉한데 기장이 짧아서 하의가 뭐든 다리가 길어 보여요" |
| 도톰한 짜임 | "두께감 있는 소재" | "생각보다 도톰해서 안에 얇은 티 하나만 입어도 든든하더라구요" |
| 허리 라인 절개 | "허리 절개 디테일" | "허리 라인을 은근하게 잡아줘서 편한데도 정돈돼 보여요" |

## 여러 사진을 볼 때

- 사진 순서를 사용자가 첨부한 순서 그대로 유지한다. 임의로 재배열하지 않는다.
- 같은 옷을 다른 각도에서 찍은 사진이 섞여 있으면, **하나의 상품으로 묶어서** 게시글 3개를 만든다. 사진 장수가 아니라 상품 개수가 기준이다. 이 경우 사용자에게 "사진 2·3은 같은 옷으로 보여서 하나로 묶었습니다"라고 알린다.
- 판단이 애매하면 묻는다.
