# 카테고리별 Gemini 인식 프롬프트 뼈대

상품 사진 → Gemini → 구조화된 속성. 카테고리마다 **결정적 속성이 다르므로** 뼈대를 나눠 쓴다.

## 사용법

1. 상품 카테고리에 맞는 파일을 연다
2. `추출 프롬프트` 코드블록을 복사해 Gemini에 붙이고 사진을 첨부한다
3. 출력된 속성표를 상세페이지·SNS 게시글·검색 태그에 재활용한다

## 폴더

```
여성남성카테고리별제미나이인식프롬프트/
├─ 여성의류/
│   니트-스웨터 · 맨투맨-스웨트셔츠 · 가디건 · 티셔츠 · 블라우스-셔츠
│   원피스 · 스커트 · 데님 · 슬랙스 · 자켓 · 코트 · 패딩 · 트레이닝-세트업
└─ 남성의류/
    니트-스웨터 · 맨투맨-스웨트셔츠 · 가디건 · 티셔츠 · 와이셔츠 · 캐주얼셔츠
    데님 · 슬랙스 · 치노-코튼팬츠 · 자켓-블루종 · 코트 · 패딩
```

`스웨터`는 편물 풀오버라 `니트-스웨터` 파일 하나로 통합했다. 기모 안감의 맨투맨 계열은 별도 파일이다.

## 모든 카테고리에 공통 적용되는 3원칙

프롬프트 뼈대에 이미 반영돼 있다. 직접 프롬프트를 쓸 때도 지킨다.

**1. 확인 불가 항목은 "불명"으로 강제한다.**
소재 혼용률, 신축성, 세탁법, 원산지, 가격, 사이즈 실측은 사진으로 판별되지 않는다. 추측하면 허위 표시가 된다.

**2. 판단 근거를 같이 내게 한다.**
"두께: 도톰 (겹침 그림자 깊이로 판단)" 형태. 근거를 요구하면 환각이 크게 줄어든다.

**3. 출력 형식을 번호 리스트 한 줄씩으로 고정한다.**
문단으로 받으면 항목이 누락되고 재사용이 어렵다.

## 출력을 판매 문구로 바꿀 때

추출된 속성은 스펙이다. 그대로 쓰지 않고 `SNS셀러말투홍보글작성` 스킬의 "입었을 때 감각" 번역 규칙을 거친다.
