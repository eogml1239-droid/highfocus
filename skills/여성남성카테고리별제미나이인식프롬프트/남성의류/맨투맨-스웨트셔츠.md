# 남성 맨투맨 · 스웨트셔츠

**본질** — 안감 상태와 리브 조임. 기모 유무가 계절을, 리브 상태가 품질감을 결정한다.

## 추출 프롬프트

```
첨부한 남성 맨투맨 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 크루넥/후디/하프집업 + 후드면 스트링 유무
2. 기장: 밑단이 닿는 신체 위치
3. 핏: 오버핏/레귤러/슬림 + 어깨 솔기 위치
4. 넥: 리브 폭 + 삼각 거셋 유무 + 리브 늘어짐 상태
5. 소매: 셋인/드롭/래글런 + 소매 리브 폭
6. 밑단: 리브 밴드 폭 + 절단 마감 여부
7. 안감: 기모/쭈리(후라이스)/판단 불가 중 하나 + 근거
8. 표면: 보풀·워싱·빈티지 가공 유무 + 필링 상태
9. 프린트·자수: 위치(중앙/좌측 가슴/등판/소매) + 크기 + 색
10. 두께감: 주름 잡히는 방식으로 판단되는 범위만
11. 컬러: 색명 + 톤 + 채도
12. 판정: 계절 / 어울리는 상황 / 단독·이너 중 어느 쪽 / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **기모를 사진만으로 단정한다.** 7번의 "판단 불가" 선택지를 반드시 남긴다.
- 삼각 거셋(목 아래 V자 보강)을 놓친다. 클래식 스웨트셔츠 판별 단서다.
- 프린트 크기와 위치를 뭉갠다. 9번에서 둘 다 받는다.
- 리브 늘어짐 상태를 보지 않는다. 4번이 품질감 판단에 직결된다.
