# 남성 가디건

**본질** — 게이지와 여밈. 얇은 게이지는 이너, 굵은 게이지는 아우터로 쓰이므로 용도가 갈린다.

## 추출 프롬프트

```
첨부한 남성 가디건 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 기장: 레귤러/롱 + 밑단이 닿는 신체 위치
2. 여밈: 단추 개수 + 단추 소재·색 + 지퍼 타입이면 명시
3. 넥라인: 브이/라운드/숄칼라/스탠드 + 깊이
4. 핏: 오버핏/레귤러/슬림 + 어깨 솔기 위치
5. 게이지: 하이/미들/로우 + 조직(플레인/케이블/배색)
6. 용도 판정: 이너용 / 단독용 / 아우터용 + 근거 한 줄
7. 포켓: 유무 + 형태(패치/웰트)
8. 리브: 목·소매·밑단 리브 폭
9. 두께감: 겹침 그림자와 실 굵기로 판단되는 범위만
10. 컬러: 색명 + 톤 + 채도 + 배색 라인 위치
11. 판정: 계절 / 어울리는 상황(오피스·데일리) / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 6번을 빼면 이너용 얇은 가디건과 아우터용 두꺼운 가디건이 같은 설명으로 나온다.
- 숄칼라를 라운드로 답한다. 칼라가 목을 감싸며 앞으로 내려오는지 확인시킨다.
- 배색 라인의 **위치**를 빼먹는다. 목·밑단·소매 어디인지가 상품명에 들어간다.
- 소재 혼용률 추측 차단 필수.
