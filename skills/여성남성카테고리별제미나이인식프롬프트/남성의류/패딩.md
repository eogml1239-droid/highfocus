# 남성 패딩

**본질** — 볼륨과 누빔 간격. 충전재는 사진으로 알 수 없으므로 절대 추측시키지 않는다.

## 추출 프롬프트

```
첨부한 남성 패딩 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
충전재 종류(구스·덕·솜), 충전량, 필파워는 사진 판별 불가이므로 반드시 "불명"으로 쓴다.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 총장: 숏/힙/미들/롱/벤치 + 밑단이 닿는 신체 위치
2. 실루엣: 박시/스트레이트/허리 조임 + 볼륨(슬림/미디엄/헤비)
3. 누빔: 가로/세로/다이아/블록 + 퀼팅 간격 + 무봉제(본딩) 여부
4. 여밈: 지퍼 + 스냅 플라켓 유무 + 지퍼 슬라이더 색
5. 후드: 없음/일체형/탈착형 + 퍼 트리밍 유무·탈착 여부
6. 칼라: 스탠드/후드 일체 + 높이 + 턱까지 덮는지
7. 소매: 소매 끝 처리(리브·밴딩·벨크로) + 소매통
8. 포켓: 개수 + 형태 + 위치 + 내부 포켓 확인 가능 여부
9. 표면: 광택(무광/은광/유광) + 원단 인상 + 발수 코팅은 불명 처리
10. 조임: 허리·밑단 스트링 유무
11. 충전재·충전량·필파워: 불명 (사진 판별 불가)
12. 컬러: 색명 + 톤 + 채도 + 배색 블록 유무
13. 판정: 계절(초겨울/한겨울/혹한) / 어울리는 상황 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **필파워와 충전재를 숫자까지 지어낸다.** 패딩 최대 리스크다. 11번을 고정 항목으로 박아둔다.
- 보온 등급을 임의 판단한다. 볼륨과 총장에서 오는 인상까지만 받는다.
- 무봉제 패딩을 일반 퀼팅으로 답한다. 3번에서 따로 묻는다.
- 후드·퍼의 탈착 여부는 문의가 가장 많다. 5번 유지.
