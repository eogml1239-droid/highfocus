# 남성 와이셔츠 (드레스셔츠)

**본질** — 칼라 벌어짐 각도와 원단 조직. 넥타이가 들어가느냐로 용도가 갈린다.

## 추출 프롬프트

```
첨부한 남성 와이셔츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 칼라: 레귤러/세미와이드/와이드스프레드/버튼다운/윙 + 벌어짐 각도
2. 칼라 심지: 빳빳함 정도(하드/소프트) + 칼라 밴드 높이
3. 여밈: 앞단 플라켓 형태(일반/히든/프렌치) + 단추 개수·색
4. 핏: 클래식/레귤러/슬림 + 허리 다트 유무
5. 소매: 기장 + 커프스(싱글/더블/커프스 링크) + 소매 단추 개수
6. 요크: 일체형/스플릿 + 절개 방식
7. 원단 조직: 브로드/옥스포드/트윌/피케 + 결이 보이는 정도
8. 광택·두께: 무광/은광 + 두께 인상
9. 포켓: 유무 + 위치
10. 밑단: 라운드/스트레이트 + 앞뒤 기장차
11. 컬러: 색명 + 톤 + 패턴(스트라이프·체크는 간격과 폭까지)
12. 넥타이 적합성: 가능/애매/부적합 + 근거 한 줄
13. 판정: 계절 / 어울리는 상황(정장·비즈니스캐주얼) / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **칼라 종류를 "일반 칼라"로 뭉갠다.** 벌어짐 각도를 함께 묻는 1번이 해결책이다.
- 옥스포드와 브로드를 구분하지 않는다. 7번에서 결의 보임 정도를 묻는다.
- 더블 커프스를 놓친다. 정장용 판단의 핵심이므로 5번 유지.
- 12번은 상품 분류(정장 셔츠 vs 캐주얼 셔츠)를 자동으로 정리해준다.
