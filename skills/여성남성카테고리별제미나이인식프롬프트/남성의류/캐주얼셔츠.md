# 남성 캐주얼셔츠

**본질** — 원단 두께와 칼라 소프트함. 와이셔츠와 갈리는 지점이 여기다.

## 추출 프롬프트

```
첨부한 남성 캐주얼셔츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 옥스포드/플란넬/데님/샴브레이/린넨/오버셔츠 중 판단되는 것
2. 칼라: 버튼다운/레귤러/차이나/오픈 + 심지 소프트 정도
3. 핏: 오버핏/레귤러/슬림 + 어깨 솔기 위치
4. 기장: 밑단이 닿는 위치 + 밑단 형태(라운드/스트레이트)
5. 여밈: 단추 개수 + 단추 소재·색 + 플라켓 형태
6. 소매: 기장 + 커프스 단추 개수 + 롤업 탭 유무
7. 포켓: 개수 + 형태(패치/플랩/웰트) + 위치
8. 원단 두께: 얇음/보통/도톰 + 아우터로 걸칠 수 있는지 판단
9. 표면: 기모·워싱·구김감 유무
10. 컬러: 색명 + 톤 + 패턴(체크는 격자 크기와 색 구성까지)
11. 판정: 계절 / 어울리는 상황 / 단독·레이어드 중 어느 쪽 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **오버셔츠(셔켓)를 일반 셔츠로 답한다.** 8번에서 아우터 가능성을 직접 묻는다.
- 체크 패턴을 "체크"로만 답한다. 격자 크기와 색 구성이 상품명에 들어간다.
- 플란넬의 기모를 놓친다. 9번 유지.
- 소재를 "린넨 100%"로 단정한다. 1번은 "판단되는 것"까지, 혼용률은 불명.
