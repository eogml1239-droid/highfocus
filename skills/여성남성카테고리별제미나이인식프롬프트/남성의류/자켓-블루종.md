# 남성 자켓 · 블루종

**본질** — 기장과 밑단 처리. 밑단이 밴드로 끊기는지 여부가 실루엣 전체를 바꾼다.

## 추출 프롬프트

```
첨부한 남성 자켓/블루종 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 블루종/MA-1/코치/트러커/레더/블레이저/사파리/셔켓 중 판단되는 것
2. 기장: 크롭/허리선/힙 + 밑단이 닿는 위치
3. 밑단 처리: 리브 밴드/드로스트링/정단 + 밴드 폭
4. 어깨: 정위치/드롭/래글런 + 솔기 위치
5. 칼라: 셔츠칼라/스탠드/후드/테일러드 + 높이나 라펠 폭
6. 여밈: 지퍼/스냅/단추 + 개수 + 하드웨어 색·재질 인상
7. 소재 인상: 표면 결 + 광택(무광/은광/유광) + 두께
8. 표면 세부: 레더면 결·주름, 나일론면 광택, 데님면 워싱, 코튼면 워싱감
9. 포켓: 개수 + 형태(플랩/웰트/지퍼/패치) + 위치
10. 소매: 커프스 처리(리브·스냅·벨크로) + 소매통
11. 안감: 판단 가능 여부 명시 후 가능하면 유무
12. 컬러: 색명 + 톤 + 채도 + 배색 유무
13. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **합성피혁을 천연가죽으로 단정한다.** 7·8번을 "인상"으로 제한하고 소재 단정은 사용자 정보로만 채운다.
- 밑단 리브 폭을 놓쳐 기장 판단이 틀어진다. 3번을 2번 바로 뒤에 둔 이유다.
- MA-1과 일반 블루종을 구분하지 않는다. 소매 지퍼 포켓 유무를 9번에서 확인시킨다.
- 셔켓(오버셔츠)을 자켓으로 뭉갠다. 원단 두께를 함께 물어 판별한다.
