# 남성 데님

**본질** — 허벅지 여유와 밑단 폭. 이 두 수치가 실루엣 이름을 결정한다.

## 추출 프롬프트

```
첨부한 남성 데님 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 실루엣: 스키니/슬림/슬림스트레이트/스트레이트/테이퍼드/와이드/배기
2. 허벅지 여유: 몸에 붙음/보통/여유 있음
3. 밑단 폭: 좁음/보통/넓음 + 발등을 덮는 정도
4. 밑위: 짧음/보통/깊음
5. 기장: 밑단이 닿는 위치 + 신발 위 고임 주름 개수
6. 워싱: 컬러(라이트/미드/다크 인디고·블랙·생지) + 명도 단계
7. 페이딩 위치: 아래 랜드마크별로 유무와 세기를 각각 답한다
   허벅지 앞면 중앙 / 무릎 위 / 엉덩이 뒷면 중앙 / 밑단 안쪽 / 그 외(위치 명시)
   ※ 포즈 주름의 그림자와 염색 페이딩을 구분해서 답할 것
8. 가공: 휘스커(개수·각도) · 나팅(위치·밀도) · 데미지 · 페인팅 유무
9. 트윌 결: 사선 방향(좌상향/우상향) + 결 선명도(뚜렷/보통/평활)
10. 스티치: 색 톤 + 땀 간격 + 백 포켓 스티치 패턴 형태
11. 하드웨어: 리벳·버튼 개수와 위치 + 금속 톤 + 셀비지 유무
12. 포켓: 백 포켓 크기 + 코인 포켓 유무
13. 허리: 벨트 루프 + 버튼플라이/지퍼플라이
14. 두께감·경직도: 주름 잡히는 방식으로 판단되는 범위만
15. 신축성: 판단 가능 여부 명시 (대부분 "불명")
16. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~16 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **테이퍼드와 슬림을 섞는다.** 2번(허벅지)과 3번(밑단)을 분리해 물으면 자동으로 구분된다.
- 생지(로우) 데님을 다크 인디고로 답한다. 페이딩 유무를 함께 묻는 7번이 단서다.
- 버튼플라이를 놓친다. 빈티지 라인 판단 근거다.
- 백 포켓 스티치 패턴은 브랜드 인상을 만드는 요소다. 10번 유지.
- **주름 그림자를 페이딩으로 답한다.** 7번의 단서 조항이 이를 막는다.

## 포즈 시리즈 연계

이 파일의 7·8·9·10·11번 출력은 **그대로 DENIM-LOCK에 옮겨 쓴다.**

```
여성남성카테고리별제미나이인식프롬프트/여성의류/데님/데님색상텍스처고정.md
```

데님은 포즈가 바뀔 때 모델이 페이딩을 새 포즈에 맞춰 재배치한다. 페이딩 위치를 신체 랜드마크로 먼저 확정해야 한다. 추측으로 채우면 처음부터 다른 제품이 된다.
