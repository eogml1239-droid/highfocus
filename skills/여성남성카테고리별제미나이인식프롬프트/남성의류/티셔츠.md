# 남성 티셔츠

**본질** — 목 리브 상태와 어깨선, 원단 두께. 단순한 옷이라 이 셋에서 품질감이 판단된다.

## 추출 프롬프트

```
첨부한 남성 티셔츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 기장: 크롭/레귤러/롱 + 밑단이 닿는 신체 위치
2. 핏: 오버핏/레귤러/슬림 + 몸선이 드러나는 정도
3. 넥라인: 라운드/브이/헨리/모크 + 깊이 + 리브 폭
4. 목 리브 상태: 늘어짐 없이 서 있는지 / 눌려 있는지
5. 소매: 반팔/긴팔 + 셋인/드롭 + 소매통 + 소매 기장
6. 어깨: 솔기가 어깨끝점 기준 어디에 오는지
7. 조직: 싱글/헤비웨이트/쭈리/피케/슬럽 + 결 방향
8. 두께감: 겹침 그림자로 판단되는 범위만
9. 비침: 판단 가능 여부 명시 후 가능하면 정도
10. 프린트·레터링: 위치 + 크기 + 색 (없으면 "무지")
11. 컬러: 색명 + 톤 + 채도
12. 밑단·소매 마감: 정단/롤업/절단 + 스티치 단·쌍 여부
13. 판정: 계절 / 어울리는 상황 / 단독·이너 중 어느 쪽 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 무지 티셔츠에서 무의미한 답("깔끔한 디자인")을 낸다. 4번·7번·12번이 실질 정보를 만든다.
- **헤비웨이트 원단을 일반 싱글로 답한다.** 남성 티셔츠 가격대를 좌우하는 요소다.
- 목 리브 늘어짐 상태를 보지 않는다. 4번을 따로 둔 이유다.
- 흰 티 비침을 "없음"으로 단정한다. 9번으로 차단한다.
