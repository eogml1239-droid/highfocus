# 여성 스커트

**본질** — 총장과 퍼짐 방식. 주름 스커트면 플리츠 종류가 상품명을 좌우한다.

## 추출 프롬프트

```
첨부한 여성 스커트 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 총장: 미니/미디/롱 + 밑단이 닿는 위치(무릎 위 몇 cm 등)
2. 실루엣: A라인/H라인/플레어/펜슬/랩/티어드/벌룬
3. 주름: 없음/플리츠/셔링 + 플리츠면 종류(나이프·박스·인버티드) + 개수
4. 허리: 밴드 폭 + 하이/미드 + 조임 방식(지퍼·밴딩·스트링·버클)
5. 밑단 퍼짐: 수직 낙하 / 퍼짐 시작 지점 / 퍼짐 정도
6. 트임: 위치(프론트·사이드·백) + 높이
7. 원단 인상: 광택 + 두께 + 형태 유지력(빳빳/부드러움)
8. 안감·비침: 판단 가능 여부 명시 후 가능하면 정도
9. 디테일: 절개선, 포켓, 버튼, 프린지 마감
10. 컬러: 색명 + 톤 + 채도 + 패턴
11. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **플리츠 종류를 뭉갠다.** 나이프(한 방향)·박스(맞물림)·인버티드(안쪽 접힘)는 육안 구분이 되므로 3번에서 강제한다.
- 플리츠 개수를 세지 않는다. 상품명에 들어가는 정보다.
- 랩 스커트의 트임을 일반 트임으로 처리한다. 6번에서 위치를 묻는다.
- 안감 유무 추측이 반품 사유가 된다. 8번 유지.
