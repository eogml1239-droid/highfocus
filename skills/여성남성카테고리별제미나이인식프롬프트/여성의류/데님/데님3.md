행거샷이 완성된 상태에서, 그 데님을 **여성모델 168cm / 48kg**에게 입힌 룩북컷을 일관성 있게 뽑는 프롬프트.

```
전제  연청 컬러웨이 행거샷 정면·후면 2장이 완성돼 있어야 한다
흐름  컷1(기준컷, 긴 프롬프트) → 컷2 이후(짧은 프롬프트) → 흔들리면 기준컷으로 복귀
```

# 컷1 · 기준컷 — 이 프롬프트만 길게 쓴다


# 컷2 이후 · 이것만 쓴다

**같은 세션에서** 짧게 이어갑니다. 길게 쓰면 오히려 인물과 워싱이 흔들립니다.

```
포즈2. 모든 LOCK 유지.
인물·얼굴·헤어·체형·데님 색·워싱 위치·상의·신발·배경·조명·접지 그림자 동일.
워싱은 원단에 물들어 있는 것이라 포즈가 바뀌어도 이동하지 않는다.
노출과 배경 밝기는 기준컷과 동일. 소품이나 포즈 때문에 밝게 보정하지 마라.
포즈만 교체 : 3/4 측면 45도로 몸을 돌리고 시선은 렌즈로.
한 손은 허리, 반대 팔은 내려 손을 노출.
```

마지막 줄의 포즈만 바꿔가며 재사용합니다.

## 포즈 목록

```
포즈2  3/4 측면 45도, 한 손 허리, 시선 렌즈로       → 옆선, 허리선
포즈3  완전 측면 90도, 양팔 내림                    → 총장, 퍼짐 라인
포즈4  후면, 고개만 살짝 돌림                       → 뒷주머니, 요크 절개선
포즈5  한쪽 다리 앞으로, 체중은 뒤쪽 다리에          → 밑단, 신발 연결
포즈6  걷는 한 순간, 앞발이 바닥에 닿는 순간         → 밑단 관성
```

# 흔들렸을 때 복귀

기준컷 이미지를 첨부하고 아래를 씁니다.

```
첨부 이미지가 기준이다. 직전 생성물은 버리고 이 인물과 이 데님으로 복귀.
얼굴, 체형, 데님 색, 세로 페이딩 위치, 상의, 신발, 배경, 조명 모두 동일.
포즈만 교체 : [포즈 지시]
```

## 증상별 대처

| 증상 | 추가할 문장 |
|---|---|
| 데님 색이 진해짐 | `연청 라이트 블루 유지. 진하게 만들지 마라` |
| 세로 페이딩 이동·소실 | `허벅지 위쪽부터 밑단까지 이어지는 세로 그라데이션 유지` |
| 원형 얼룩 워싱 생김 | `경계가 있는 원형 패치를 만들지 마라` |
| 신발이 바뀜 | 신발 LOCK 문장 재투입 |
| 얼굴이 다른 사람 | Temperature 0.4 확인 + 기준컷 첨부 |
| 발밑 그림자 소실 | `신발 접지 지점에 코어 섀도우 유지` |
| 다리가 과하게 길어짐 | `카메라 높이 100cm, 150mm 렌즈 유지` |
| 손이 뭉개짐 | 옷 잡는 포즈를 쓰지 않는다 |

3회 이상 실패하면 새 세션을 열고 기준컷을 첨부해 다시 시작합니다.

# 포토샵 후처리

원본이 후처리본보다 좋았던 사례가 있으므로 최소한만 한다.

```
하지 말 것
✗ 전체 밝기·노출 올리기     → 접지 그림자가 사라진다
✗ 콘트라스트 낮추기          → 원단 결과 워싱 대비가 뭉개진다
✗ 채도 낮추기                → 연청이 회색으로 변한다
✗ 접지 그림자 그려 넣기      → 이미 있다

할 것
1. 피부 영역만 마스크 → Noise → Soft Light 6~8% (옷에는 미적용)
2. 머리카락 몇 가닥을 얼굴 쪽으로 빼기
3. Camera Raw → 비네팅 -8
4. 전체에 동일 강도 그레인 (마지막 단계)
```

# 참고

- 상의와 신발을 LOCK에 넣은 이유는 이전 테스트에서 컷마다 신발이 바뀌었기 때문이다.
- 스타일링을 바꾸려면 상의 LOCK과 신발 LOCK만 교체하고 나머지는 그대로 둔다.
- 다크 인디고·빈티지 미디엄 컬러웨이는 **세션을 분리**한다. 한 세션에서 섞으면 색이 서로 끌려간다.
