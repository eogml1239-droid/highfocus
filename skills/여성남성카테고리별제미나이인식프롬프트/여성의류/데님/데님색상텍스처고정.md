```
확인된 것
✅ 인물 동일성 유지는 성공한다
❌ 워싱 페이딩 위치가 컷마다 이동한다      ← 이것만 해결하면 됨
❌ 신발이 컷마다 바뀐다
❌ 손으로 옷을 잡는 포즈는 손가락이 뭉개진다
❌ 포토샵 톤 보정이 접지 그림자와 데님 색을 죽인다
```

# 2단계 · 나머지 포즈 (기준컷을 첨부)

**기준컷 이미지를 `+`로 첨부하고** 아래를 쓰세요. 텍스트만으로는 워싱이 이동합니다.

```
첨부한 이미지가 기준이다.
데님 색, 밝기, 워싱 위치, 원단 결, 박음질 실 색을 그대로 복제해라.
인물, 얼굴, 헤어, 체형, 신발, 상의, 배경, 조명, 발밑 그림자도 똑같이.

워싱은 원단에 물들어 있는 것이다. 포즈가 바뀌어도 움직이지 않는다.
새로 생긴 주름 그림자를 워싱으로 만들지 마라.

포즈만 바꿔줘 : [아래에서 하나 고르기]
```

### 포즈 목록

```
3/4 측면 45도로 몸을 돌리고 시선은 렌즈로
완전 측면 90도, 양팔은 자연스럽게 내림
후면, 고개만 살짝 돌림 (뒷주머니와 밑단 보이게)
한쪽 다리 앞으로 내밀고 체중은 뒤쪽 다리에
걷는 한 순간, 앞발이 바닥에 닿는 순간
```

### 후면컷에만 추가

```
엉덩이 워싱은 좌우 대칭으로, 세기는 허벅지보다 약하게.
```

# 문제 해결

| 이런 증상 | 이 문장 추가 |
|---|---|
| 워싱이 다른 곳으로 이동 | `워싱은 허벅지 앞면 중앙과 무릎 위에만 있다` |
| 힙 옆에 밝은 얼룩 생김 | `엉덩이 옆면에 사각형 밝은 패치를 만들지 마라` |
| 색이 밝아짐 | `조명이 같으니 색도 같다. 색 보정 금지` |
| 원단 결이 사라짐 | `원단 사선 결이 표면에서 보일 것` |
| 신발이 바뀜 | 신발 문장을 다시 붙여넣기 |
| 손이 뭉개짐 | 옷 잡는 포즈를 쓰지 않는다 |
| 얼굴이 흐림 | `얼굴은 초점이 맞을 것` 추가 |

3번 이상 실패하면 새 세션을 열고 기준컷을 첨부해 다시 시작하세요.

# 포토샵 (중요 — 지금 방식이 품질을 떨어뜨립니다)

테스트에서 확인된 것: **원본이 후처리본보다 좋았습니다.**

```
절대 하지 말 것
✗ 전체 밝기·노출 올리기     → 접지 그림자가 사라진다
✗ 콘트라스트 낮추기          → 원단 결이 뭉개진다
✗ 채도 낮추기                → 데님이 그레이로 변한다 (상품 색상 왜곡)
✗ 접지 그림자 그려 넣기      → 이미 있다. 건드리지 말 것

할 것 (이것만)
1. 피부 영역만 마스크 → Noise 추가 → Soft Light 6~8%
   ※ 옷에는 절대 적용하지 않는다
2. 머리카락 몇 가닥을 얼굴 쪽으로 빼기
3. Camera Raw → 비네팅 -8
4. 전체에 동일 강도 그레인 (마지막 단계)
```

데님 색은 원본 기준으로 잠그세요. 스포이드로 허벅지 같은 지점의 RGB를 원본과 비교하면 눈으로 놓치는 차이가 잡힙니다.
