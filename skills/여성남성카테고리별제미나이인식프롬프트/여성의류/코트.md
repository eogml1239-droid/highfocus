# 여성 코트

**본질** — 총장과 여밈 구조. 그리고 어깨에서 밑단으로 떨어지는 라인이 실루엣 전부를 만든다.

## 추출 프롬프트

```
첨부한 여성 코트 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 종류: 싱글/더블/트렌치/발마칸/체스터필드/랩/핸드메이드 중 판단되는 것
2. 총장: 숏/미들/롱/맥시 + 밑단이 닿는 신체 위치
3. 실루엣: H라인/A라인/코쿤/오버 박시 + 허리 절개 유무
4. 어깨: 정위치/드롭/래글런 + 패드감
5. 칼라: 테일러드/노치드/피크드/스탠드/후드 + 라펠 폭
6. 여밈: 단추 개수·배열 + 히든 플라켓 여부 + 벨트 유무
7. 소재 인상: 표면 결(울·모직·캐시미어 느낌) + 기모 유무 + 두께
8. 드레이프: 형태 유지 / 흐름 + 걸을 때 벌어지는 정도
9. 포켓: 형태와 위치
10. 밑단·소매: 마감 방식 + 뒤 트임(센터/사이드) 유무
11. 안감: 판단 가능 여부 명시 후 가능하면 유무
12. 컬러: 색명 + 톤 + 채도 + 패턴(헤링본·체크는 간격까지)
13. 판정: 계절(초겨울/한겨울) / 어울리는 상황 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 소재를 "캐시미어"로 단정한다. 7번을 인상으로 제한한다.
- **뒤 트임을 놓친다.** 롱코트는 트임 유무가 활동성 정보다.
- 싱글과 더블을 단추 개수만으로 판단해 틀린다. 배열(좌우 대칭 여부)을 함께 묻는다.
- 한겨울용과 간절기용을 구분하지 않는다. 13번에서 계절을 두 단계로 받는다.
