# 여성 트레이닝 · 세트업

**본질** — 상하의 연결감과 조임 위치. 세트로 보이느냐 따로 입을 수 있느냐가 상품 가치다.

## 추출 프롬프트

```
첨부한 여성 트레이닝/세트업 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
상의와 하의를 나눠서 답하고, 마지막에 세트 판정을 붙여.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

[상의]
1. 종류: 집업/후디/크루넥/스탠드칼라 + 크롭 여부
2. 기장: 밑단이 닿는 신체 위치
3. 핏: 오버/레귤러/슬림 + 어깨 솔기 위치
4. 조임: 목·밑단·소매 밴드 유무와 폭
5. 포켓: 위치와 형태(플랩/지퍼/사이드)

[하의]
6. 종류: 조거/와이드/스트레이트/카고
7. 허리: 밴딩 + 드로스트링 유무
8. 밑단: 발목 밴딩/스트링/오픈 + 기장
9. 포켓: 사이드·카고 포켓 형태와 크기

[공통]
10. 원단 인상: 광택 + 두께 + 표면(나일론·코튼·기모 느낌)
11. 컬러: 상하의 색이 동일한지 + 색명 + 톤
12. 세트 판정: 세트 전용 / 따로 입기 가능 + 근거 한 줄
13. 판정: 계절 / 어울리는 상황(운동·데일리·여행) / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 상하의를 하나로 뭉쳐 답한다. 위처럼 섹션을 나눠야 항목이 안 빠진다.
- **기능성을 임의로 붙인다.** "땀 배출", "방수" 같은 표현은 사진으로 확인 불가다. 10번을 인상으로 제한한다.
- 카고 포켓의 크기를 빼먹는다. 대형 플랩과 작은 지퍼 포켓은 다른 인상이다.
- 고프코어로 뭉뚱그려 분류한다. 아웃도어 기능성 장비감이 없으면 애슬레저·유틸리티로 받는 게 정확하다.
