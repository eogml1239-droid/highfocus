# 여성 슬랙스

**본질** — 밑위 길이와 밑단 폭. 여기서 비율이 결정되고, 원단 경직도가 오피스냐 데일리냐를 가른다.

## 추출 프롬프트

```
첨부한 여성 슬랙스 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 허리 높이: 하이/미드 + 허리선이 배꼽 기준 어디인지
2. 실루엣: 스트레이트/와이드/테이퍼드/부츠컷/조거
3. 밑단 폭: 좁음/보통/넓음 + 발등을 덮는 정도
4. 기장: 크롭/복사뼈/신발 등에 고임 + 고임 주름 개수
5. 턱·플리츠: 없음/원턱/투턱 + 위치
6. 허리 처리: 밴드 없음/부분 밴딩/전체 밴딩 + 벨트 루프
7. 프레스 라인: 센터 크리스 유무
8. 원단 인상: 광택 + 두께 + 형태 유지력(빳빳/드레이프)
9. 포켓: 사이드·백 포켓 형태
10. 주름 방식: 앉거나 움직였을 때 생기는 주름 결
11. 컬러: 색명 + 톤 + 채도 + 패턴(체크는 간격까지)
12. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 와이드와 스트레이트를 같은 말로 쓴다. 3번 밑단 폭을 따로 물어 구분한다.
- **센터 크리스(프레스 라인)를 놓친다.** 이 선 하나로 오피스 슬랙스와 캐주얼 팬츠가 갈린다.
- 전체 밴딩을 "편한 핏"으로만 답한다. 6번에서 밴딩 범위를 명시하게 한다.
- 소재를 "울"로 단정한다. 8번처럼 인상으로만 받는다.
