# 여성 패딩

**본질** — 누빔(퀼팅) 간격과 볼륨감. 충전재는 사진으로 알 수 없으므로 절대 추측시키지 않는다.

## 추출 프롬프트

```
첨부한 여성 패딩 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
특히 충전재 종류(구스·덕·솜)와 충전량은 사진으로 판별 불가이므로 반드시 "불명"으로 쓴다.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 총장: 숏/힙/미들/롱/벤치 + 밑단이 닿는 신체 위치
2. 실루엣: 박시/A라인/허리 조임 + 볼륨 정도(슬림/미디엄/헤비)
3. 누빔: 가로/세로/다이아 + 퀼팅 간격(좁음/보통/넓음) + 무봉제(본딩) 여부
4. 여밈: 지퍼 종류 + 스냅 플라켓 유무 + 지퍼 슬라이더 색
5. 후드: 없음/일체형/탈착형 + 퍼 트리밍 유무·탈착 여부
6. 칼라: 스탠드/후드 일체/무스탕 + 높이
7. 소매: 기장 + 소매 끝 처리(리브·밴딩·벨크로)
8. 포켓: 개수 + 형태(지퍼/스냅/웰트) + 위치
9. 표면: 광택(무광/은광/유광) + 원단 인상(나일론·폴리 느낌) + 발수 코팅 여부는 불명 처리
10. 조임: 허리·밑단 스트링 유무
11. 충전재·충전량: 불명 (사진 판별 불가)
12. 컬러: 색명 + 톤 + 채도
13. 판정: 계절(초겨울/한겨울/혹한) / 어울리는 상황 / 무드 각 한 줄

출력은 1~13 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- **충전재를 "구스다운"으로 단정한다.** 패딩에서 가장 위험한 환각이다. 11번을 고정 항목으로 박아둔 이유다.
- 보온성을 임의로 판단해 "혹한기용"이라고 쓴다. 볼륨과 총장에서 오는 인상까지만 받는다.
- 퍼 트리밍의 탈착 여부를 놓친다. 구매 문의가 잦은 항목이다.
- 무봉제(본딩) 패딩을 일반 퀼팅으로 답한다. 3번에서 따로 묻는다.
