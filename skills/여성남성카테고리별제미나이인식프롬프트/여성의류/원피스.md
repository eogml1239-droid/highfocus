# 여성 원피스

**본질** — 허리선 위치와 총장. 이 두 개가 체형 보정과 착용 상황을 동시에 결정한다.

## 추출 프롬프트

```
첨부한 여성 원피스 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 총장: 미니/미디/맥시 + 밑단이 닿는 신체 위치(무릎 위 몇 cm 등)
2. 실루엣: A라인/H라인/플레어/머메이드/셔츠/슬립/티어드
3. 허리선: 하이웨이스트/내추럴/드롭/무절개 + 조임 방식(절개·밴딩·스트링·벨트)
4. 넥라인: 라운드/브이/스퀘어/홀터/오프숄더/셔츠칼라 + 깊이
5. 소매: 민소매/반팔/긴팔/퍼프/케이프 + 기장
6. 등·뒤 처리: 지퍼/단추/트임/오픈백 여부
7. 원단 인상: 광택 + 두께 + 구김감
8. 드레이프: 흐르는지 / 형태를 유지하는지 + 주름 방식
9. 안감·비침: 판단 가능 여부 명시 후 가능하면 정도
10. 패턴: 무지/플로럴/도트/체크 + 모티프 크기
11. 컬러: 색명 + 톤 + 채도
12. 판정: 계절 / 어울리는 상황(하객·데일리·오피스·바캉스) / 무드 각 한 줄

출력은 1~12 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 미디와 맥시 경계를 임의로 잡는다. 무릎·종아리·발목 기준으로 1번에서 고정한다.
- 허리 절개선을 놓쳐 실루엣을 잘못 답한다. 3번을 4번보다 앞에 두는 이유다.
- 안감 유무를 추측한다. 9번에서 판단 가능 여부부터 답하게 한다.
- 플로럴 패턴의 **모티프 크기**를 빼먹는다. 큰 꽃과 잔꽃은 다른 상품이다.
