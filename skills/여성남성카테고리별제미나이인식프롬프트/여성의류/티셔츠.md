# 여성 티셔츠

**본질** — 목 리브와 어깨선, 그리고 비침. 단순한 옷일수록 이 세 개로 갈린다.

## 추출 프롬프트

```
첨부한 여성 티셔츠 사진에서 아래만 추출해. 확인 불가하면 "불명"으로 쓰고 추측하지 마.
각 항목 한 줄, 판단 근거를 괄호로 짧게.

1. 기장: 크롭/레귤러/롱 + 밑단이 닿는 신체 위치
2. 핏: 오버핏/레귤러/슬림/타이트 + 몸선이 드러나는 정도
3. 넥라인: 라운드/브이/보트/헨리/모크 + 깊이 + 리브 폭
4. 소매: 반팔/긴팔/7부 + 셋인/드롭 + 소매통
5. 어깨: 솔기가 어깨끝점 기준 어디에 오는지
6. 조직: 싱글/쭈리/립/슬럽 + 결 방향
7. 비침: 판단 가능 여부 명시 후 가능하면 정도
8. 프린트·레터링: 위치 + 크기 + 색 (없으면 "무지")
9. 컬러: 색명 + 톤 + 채도
10. 밑단·소매 마감: 정단/롤업/절단
11. 판정: 계절 / 어울리는 상황 / 무드 각 한 줄

출력은 1~11 번호 리스트만.
```

## Gemini가 자주 틀리는 것

- 무지 티셔츠에서 "심플한 디자인" 같은 무의미한 답을 낸다. 리브 폭과 조직을 강제하면 실질 정보가 나온다.
- 비침을 근거 없이 "비침 없음"으로 단정한다. 흰색 반팔은 특히 위험하다. 7번으로 차단한다.
- 슬럽(불규칙 실) 조직을 놓친다. 표면 결을 따로 묻는다.
