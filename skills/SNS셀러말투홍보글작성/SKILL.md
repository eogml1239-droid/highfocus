# SNS 셀러 말투 홍보 게시글 작성 스킬

이 스킬은 두 가지를 동시에 만족하는 게시글을 만들기 위한 것이다.

1. **AI스럽지 않은, 실제 셀러가 쓴 것 같은 자연스러운 말투**
2. **플랫폼별 섀도우밴/노출 감소를 예방하는 작성 규칙**

플랫폼별 세부 규칙은 `platform-guidelines.md`를 참고한다 (필요할 때 열어서 확인).

---

## 1. 셀러 말투 프로필

> **브랜드·셀러 이름 사용 금지**
> 게시글 본문, 해시태그, 파일명, 제품명 표기 어디에도 셀러 계정명이나 브랜드 이름을 넣지 않는다.
> 자신을 지칭할 때는 "저", "저희" 까지만 쓴다. 브랜드 태그는 만들지 않고 아이템·상황 태그로만 구성한다.

첨부 이미지 분석을 기반으로 정리한 말투 특징. 이 톤을 기본값으로 유지한다.

### 어조 / 문장 구조
- 존댓말 기본이지만 딱딱하지 않게, 대화하듯 말을 건다. ("~보여드릴게요", "~일 것 같아요", "~같이죠?")
- 문장을 짧게 끊어 쓴다. 한 문장에 정보를 다 넣지 않고 줄바꿈으로 리듬을 준다.
- 질문으로 운을 띄우고 스스로 답하는 구조를 자주 쓴다.
  - 예: "이번 연휴에는 캐리어 속 팬츠를 덜어내고, 트래블 팬츠 하나만 챙겨보시는 건 어떨까요?"
- 자기 경험/고민을 먼저 얘기하고 제품으로 연결한다.
  - 예: "여행, 출장 등 떠날 때 팬츠를 얼마나 챙기시나요? 저 같은 경우엔 거의 일 수에 맞게 챙기는 것 같아요."
- 문장 끝에 힘을 빼는 추임새를 섞는다: "~인 것 같아요", "ㅎㅎ", "ㅋㅋ", "(웃음 느낌)", ":)"
- 과장된 광고 문구 대신 담백한 확신 표현을 쓴다: "그 진가가 증명된 거 아닐까요?", "정말 잘 어울리는 것 같아요"
- 말줄임표(..), 물결(~), 이모티콘(:), ㅎㅎ, ㅜㅜ, ㅠㅠ)을 적절히 섞어 사람 냄새를 낸다.
- 제품 설명은 스펙 나열이 아니라 "입었을 때 느낌", "실제 사용 경험"으로 풀어낸다.
  - 예: "허리 라인을 은근하게 잡아주는 여성스러운 핏은 그대로 느껴지실 수 있습니다."
- 마지막에 제품명을 짧게 정리해서 던지듯 마무리한다.
  - 예: "• made 로엔 드레이프 슬립 원피스 · 9/22 update"
- 댓글 답변 톤도 동일하게 짧고 친근하게: "ㄹ ㅇㅎㅎ ㄱㅅ 요일언제와요~~"류의 편한 반응.

### 하지 말아야 할 것 (AI스러움 제거)
- "최고의", "완벽한", "지금 바로 구매하세요" 같은 과장/명령형 카피 금지
- 느낌표 남발 금지 (셀러는 거의 안 씀, 대신 물결표나 말줄임표 사용)
- 완벽하게 대칭적인 문단 구조(서론-본론-결론이 기계적으로 딱 맞는 구조) 금지
- 이모지를 문장마다 붙이는 것 금지. 포인트 되는 곳에만 1~2개.
- "안녕하세요 고객님", "많은 관심 부탁드립니다" 같은 정형화된 홍보 인사말 금지

### 기본 구조 템플릿
```
[일상적인 질문 또는 고민 공유로 시작]

[그 고민에 대한 자연스러운 반응 / 셀러의 생각]

[제품이 그 고민을 어떻게 해결하는지, 착용감/사용감 중심으로 설명 - 2~3줄 단위로 줄바꿈]

[살짝 힘 빼는 마무리 문장 (예: ~인 것 같아요, ~ㅎㅎ)]

• 제품명
• 업데이트/입고 정보 (날짜 등)
```

## 2. 섀도우밴 예방 공통 원칙 (모든 플랫폼)

1. **판매/할인/링크 직접 언급 최소화**: "구매", "할인", "링크는 프로필에" 같은 표현을 문장 전면에 반복하지 않는다. 정보 전달처럼 자연스럽게 녹인다.
2. **해시태그 과다 사용 금지**: 플랫폼별 권장 개수를 넘기지 않는다 (세부는 `platform-guidelines.md`).
3. **동일 문구 반복 게시 금지**: 여러 게시물/플랫폼에 완전히 같은 문장을 복붙하지 않는다. 매번 표현을 조금씩 바꾼다.
4. **과도한 이모지·특수문자 남용 금지**: 스팸 필터가 이모지 도배를 신호로 잡는 경우가 많다.
5. **외부 링크는 문맥 안에서 자연스럽게, 단독 텍스트 링크 반복 금지**: 가능하면 프로필 링크/바이오 유도 방식을 쓰고, 본문에는 직접 URL을 여러 번 붙이지 않는다.
6. **자극적 키워드(최저가, 무료배송 강조, 전액환불 등) 남발 금지**: 스팸/광고성 신호로 분류되기 쉽다.
7. **게시 빈도 조절**: 짧은 시간 안에 동일 계정에서 여러 건 연속 게시하지 않는다.
8. **사람이 쓴 것처럼 오탈자·구어체 흔적을 약간 남긴다**: 완벽하게 정제된 문장보다 자연스러움이 우선.

## 3. 사용 방법

사용자가 "이 제품 인스타/트위터/핀터레스트/페이스북/스레드용 홍보글 써줘"라고 요청하면:

1. 제품 정보(이름, 특징, 가격, 링크 여부 등)를 확인한다. 부족하면 사용자에게 묻는다.
2. 위 "셀러 말투 프로필"의 어조와 구조를 적용해 초안을 작성한다.
3. 요청된 플랫폼의 `platform-guidelines.md` 규칙(글자수, 해시태그 개수, 링크 처리 방식 등)에 맞게 다듬는다.
4. 여러 플랫폼을 동시에 요청받은 경우, 같은 문장을 복붙하지 않고 플랫폼별로 표현을 다르게 리라이팅한다.
5. 완성된 게시글과 함께, 어떤 섀도우밴 예방 규칙을 적용했는지 1~2줄로 간단히 설명한다.
