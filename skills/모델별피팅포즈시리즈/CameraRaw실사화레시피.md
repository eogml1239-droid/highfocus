# Camera Raw 실사화 레시피 — AI 이미지를 실제 촬영처럼

Gemini 출력물이 "AI 같아 보이는" 원인을 Camera Raw에서 하나씩 없애는 공정.

```
대상  워터마크를 지운 풀 해상도 이미지 (예 1792 x 2400)
목표  실제 카메라로 찍은 사람처럼. 단 데님 색과 워싱은 절대 건드리지 않는다
```

---

# 0. 먼저 · 방향을 바꿔야 하는 두 가지

## ① 노이즈는 제거가 아니라 추가다

```
AI 이미지가 가짜로 보이는 1순위 원인은 "너무 깨끗해서"다.
실제 카메라는 ISO 100에서도 전체에 고른 미세 그레인이 깔린다.
AI 출력은 그게 없어서 피부가 플라스틱처럼 보인다.

노이즈 감소를 올리면 → 더 매끈해짐 → 더 가짜로 보인다
노이즈(입자)를 추가하면 → 센서 흔적이 생김 → 진짜로 보인다

Camera Raw 세부 패널의 "노이즈 감소"는 0에 둔다.
효과 패널의 "입자"를 올린다. 이게 실사화의 1등 공신이다
```

예외 — 이럴 때만 노이즈 감소를 쓴다.

```
그레이 벽 그라데이션에 얼룩진 색 반점이 보일 때 → "색상 노이즈 감소" 만 5~10
그 외에는 0
```

## ② 채도는 전체가 아니라 피부만 만진다

```
전체 채도를 올리면 데님 색이 같이 변한다.
고객이 받은 실물과 사진 색이 달라지면 CS·반품 사유가 된다.
빈티지 미디엄 블루와 세피아 페이딩은 상품의 정체성이다. 숫자로 잠가야 한다

→ 기본 패널의 "채도"는 0 고정
→ 색상 혼합(HSL) 패널에서 오렌지·빨강 채널만 만진다 (= 피부와 입술)
→ 파랑·아쿠아·노랑 채널은 손대지 않는다 (= 데님과 워싱)
```

# 1. 패치 도구로 워터마크 지우기

## 1-1. 설정

```
키보드 J  (스팟 복구 브러시 계열) → Shift + J 를 눌러 "패치 도구"까지 순환
옵션바
  패치            : 내용 인식
  구조            : 4 ~ 5      (원본 구조를 얼마나 지킬지. 높을수록 원본 유지)
  색상            : 0 ~ 2      (색 혼합. 평평한 배경이면 낮게)
  모든 레이어 샘플링 : 체크
```

## 1-2. 작업

```
1. Ctrl + 1 로 100% 확대, Space 드래그로 ✦ 마크로 이동
2. 마크 주위를 올가미처럼 감싸 선택 (여유 10~15px)
3. 선택 안쪽을 잡고 깨끗한 바닥으로 드래그 → 놓기
4. Ctrl + D
```

## 1-3. 이 이미지에서 중요한 것 — 소스를 좌우에서 가져온다

```
바닥과 벽에는 세로 방향 밝기 그라데이션이 있다.
소스를 위아래로 끌면 밝기가 어긋나 네모난 얼룩이 남는다.
→ 반드시 같은 높이에서 좌우로 끈다
→ 벽과 바닥이 만나는 경계선을 넘기지 않는다
```

한 번에 안 되면 `Ctrl + Z` 후 소스 위치를 바꿔 다시 끕니다. 두세 번 나눠 조금씩 지우는 것도 좋습니다.

## 1-4. 액션 주의 — 패치는 일괄 처리에 안 맞는다

```
브러시 계열 도구(복구 브러시, 스팟 복구, 복제 스탬프)는 액션에 기록되지 않는다.
패치 도구도 같은 계열이라 재생이 보장되지 않는다.
→ 1장으로 녹화·재생 테스트를 먼저 해본다. 안 되면 아래처럼 나눈다

워터마크   : 패치 도구로 손수 (장당 10초, 40장 약 7분)
Camera Raw : 액션으로 일괄  ← 여기서 시간을 번다
```

# 2. Camera Raw 실사화 레시피

## 2-0. 열기 전 준비 (선택이지만 권장)

```
이미지 > 모드 > 16비트/채널
→ 그레이 벽 그라데이션에 밴딩이 생기는 것을 막는다. 저장 직전에 8비트로 되돌린다
```

```
필터 > Camera Raw 필터   (Shift + Ctrl + A)
```

## 2-1. 기본 패널

```
노출          0        ← 건드리지 않는다. 올리면 발밑 접지 그림자가 죽는다
대비          0 ~ +5
하이라이트    -10 ~ -15  ← 화이트 티셔츠에 원단 결을 되살린다
그림자        0        ← 올리지 않는다. 접지 그림자 유지
흰색 계열     -5 ~ -8   ← 티셔츠를 순백(255)에서 내린다. 순백은 AI 티가 난다
검정 계열     -3 ~ -5   ← 그림자 깊이 확보
텍스처        +8 ~ +12  ← 피부 요철과 데님 결을 동시에 살린다
부분 대비     0 ~ +5    ← 과하면 HDR 느낌이 나서 오히려 가짜가 된다
디헤이즈      0        ← 건드리지 않는다
생동감        +3 ~ +5
채도          0        ← 고정. 상품 색 보호
```

## 2-2. 곡선 패널 — "디지털 렌더링" 느낌을 없애는 핵심

포인트 곡선에서 아주 얕은 S자를 만들고, 양 끝점을 안으로 좁힙니다.

```
좌측 하단 끝점을 살짝 위로   → 출력 5 ~ 8
우측 상단 끝점을 살짝 아래로 → 출력 248 ~ 250
```

```
실제 렌즈와 필름은 완전한 검정(0)과 완전한 흰색(255)을 만들지 못한다.
AI 출력은 0과 255를 그대로 쓴다. 이 끝점 처리 하나가 체감 차이가 가장 크다
```

## 2-3. 색상 혼합(HSL) — 채도 보정은 여기서만

```
오렌지 채널 (= 피부)
  채도  +3 ~ +5    피부에 혈색을 준다
  광도  -2 ~ -3    너무 하얗고 균일한 피부를 살짝 누른다

빨강 채널 (= 입술·볼·관절 붉은기)
  채도  +3
  광도  -2

파랑 · 아쿠아 채널 (= 데님)    손대지 않는다
노랑 채널 (= 세피아 페이딩)     손대지 않는다
```

## 2-4. 색상 보정(Color Grading) — 조명의 흔적 만들기

```
어두운 영역   색조 210 ~ 220 (청색),  채도 4 ~ 6
밝은 영역     색조 40 ~ 50   (황색),  채도 3 ~ 5
균형          0
```

```
실제 스튜디오는 키 라이트와 필 라이트의 색온도가 미세하게 다르다.
그래서 그림자에 한기, 하이라이트에 온기가 남는다.
AI 출력은 색이 너무 뉴트럴하다. 이 미세한 분리가 촬영 현장의 증거가 된다
```

## 2-5. 세부 패널

```
선명하게 하기
  양      25 ~ 35
  반경    0.8
  세부    25
  마스킹  40 ~ 60    ← Alt 를 누른 채 드래그하면 마스크가 흑백으로 보인다
                       평평한 벽은 검게, 인물 윤곽만 하얗게 되도록 맞춘다

노이즈 감소        0     ← 올리지 않는다
색상 노이즈 감소   0 ~ 10 ← 벽에 색 반점이 보일 때만
```

## 2-6. 효과 패널 — 실사화 1등 공신

```
입자
  양      12 ~ 18
  크기    20 ~ 25    ← 25를 넘기면 거칠어 보인다
  거칠기  45 ~ 55

비네팅 (자르기 후 비네팅)
  양      -8 ~ -12
  중간점  50
  페더    60
  원형율  0
```

```
그레인은 "카메라로 찍었다"는 가장 직접적인 증거다.
비네팅은 "렌즈가 있었다"는 증거다.
이 둘만 넣어도 AI 느낌이 눈에 띄게 줄어든다
```

## 2-7. 마스킹 패널 — 피부만 골라내는 자동 기능

Camera Raw의 자동 인식을 쓰면 옷에 손대지 않고 피부만 만질 수 있습니다. 기존 포토샵 수동 마스크 작업을 대체합니다.

```
마스킹 > 사람 > (인물 자동 감지) > "얼굴 피부" + "신체 피부" 체크 > 마스크 만들기
  텍스처        +12 ~ +18
  부분 대비     +5
  선명하게 하기 -5
  입자          +10        ← 피부에만 추가 그레인. 가장 효과적인 한 방
  → 데님과 배경에는 적용되지 않는다. 상품 색이 안전하다

마스킹 > 사람 > "머리카락" > 마스크 만들기
  텍스처        +10
  선명하게 하기 +10
  → 긴 머리가 덩어리로 뭉치는 AI 특징을 해소한다

마스킹 > 배경 > 마스크 만들기
  텍스처        -5
  선명하게 하기 -10
  → 배경만 살짝 무르게. 인물이 더 선명해 보여 실제 렌즈의 얕은 심도처럼 읽힌다
```

# 3. 우선순위 — 시간이 없으면 이 셋만

```
1위  효과 > 입자         양 15 / 크기 22 / 거칠기 50
2위  마스킹 > 사람 > 피부  텍스처 +15, 입자 +10
3위  곡선 끝점 좁히기      검정 0→6, 흰색 255→249
```

이 셋이 체감 효과의 대부분을 차지합니다. 나머지는 마무리입니다.

# 4. 40장에 한 번에 적용하기

Camera Raw 필터는 **액션에 기록됩니다.** 패치 도구와 달리 자동화가 됩니다.

## 4-1. 사전 설정으로 저장

Camera Raw 창 오른쪽 사전 설정 패널에서 `사전 설정 만들기`를 누르고 이름을 `실사화_여성A`로 저장합니다. 다음부터 한 번 클릭으로 끝납니다.

## 4-2. 액션 녹화

```
창 > 액션 > 새 액션 "실사화" > 기록
  1. 필터 > Camera Raw 필터 > 사전 설정 "실사화_여성A" 클릭 > 확인
  2. 이미지 > 이미지 크기 > 긴 변 1400px, 다시 샘플링: 바이큐빅 더 뚜렷하게(축소)
  정지
```

**순서가 중요합니다.** Camera Raw를 먼저, 리사이즈를 나중에 하세요. 반대로 하면 그레인이 축소 과정에서 작아져 거의 안 보입니다. 1400px 결과물에서 그레인이 약하면 입자 양을 +3 올려 사전 설정을 갱신합니다.

## 4-3. 일괄 실행

```
파일 > 스크립트 > 이미지 프로세서
  ① 처리할 이미지 : 워터마크 지운 폴더
  ② 저장 위치     : 최종 출력 폴더
  ③ 파일 유형     : JPEG 품질 8   (크기 맞추기는 체크하지 않음 — 액션에서 이미 함)
  ④ 환경 설정     : 액션 실행 → 기본 액션 > 실사화
  실행
```

이미지 프로세서 안에서 액션 실행 순서가 의심되면 **1장으로 먼저 테스트**하세요. 결과 그레인이 또렷하면 순서가 맞습니다.

# 5. 검수 — 이것만 확인

```
□ 100%에서 피부에 미세한 요철과 그레인이 보이는가
□ 티셔츠가 순백으로 날아가지 않고 원단 결이 남아 있는가
□ 발밑 접지 그림자가 옅어지지 않았는가
□ 데님 색이 원본과 같은가  ← 스포이드로 허벅지 페이딩 중심과 무릎 아래 두 지점
□ 세피아 페이딩의 따뜻한 톤이 살아 있는가
□ 그레이 벽에 밴딩 띠가 생기지 않았는가
□ 머리카락이 덩어리로 뭉치지 않았는가
```

데님 색 확인은 두 지점을 같이 봐야 합니다. 한 지점만 보면 HSL 보정이 번진 걸 놓칩니다.

# 6. 하지 말 것

```
✗ 기본 패널의 채도를 올리거나 내리기     → 데님 색 왜곡. 실물과 달라진다
✗ 노이즈 감소를 올리기                  → 더 매끈해져서 더 가짜로 보인다
✗ 노출·그림자를 올리기                  → 접지 그림자가 죽고 인물이 공중에 뜬다
✗ 부분 대비를 +15 이상                  → HDR 느낌. AI 티가 더 난다
✗ 디헤이즈 사용                        → 색이 탁해지고 데님 톤이 변한다
✗ 파랑·아쿠아·노랑 HSL 채널 건드리기      → 상품 색과 워싱이 변한다
✗ 얼굴 보정 도구로 눈·턱 형태 수정       → 40장의 인물 동일성이 깨진다
✗ 그레인을 리사이즈 전에만 넣고 확인 안 함 → 축소되면서 사라진다
```

특히 마지막 항목은 놓치기 쉽습니다. 항상 **최종 출력 크기에서** 그레인을 확인하세요.
