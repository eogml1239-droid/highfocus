# 피팅 포즈 시리즈 프롬프트

포즈 번호가 올라간다 = 이전 이미지가 만족스럽다 = **인물·의상·배경·조명을 절대 바꾸지 않는다.**

## 폴더

```
실사감강화-공통레이어.md      AI 느낌 제거 (전 품목 필수)
실측사이즈-착장변환.md        실측 치수 → 착장 문장 (전 품목 필수)

여성A-168cm-48kg/포즈시리즈.md     스펙 LOCK + 포즈1 + 포즈 카탈로그
여성B-162cm-50kg/포즈시리즈.md
남성A-182cm-80kg/포즈시리즈.md
남성B-178cm-70kg/포즈시리즈.md

다음포즈이어생성/
├─ 다음포즈프롬프트.md       포즈2 이후 프롬프트 (기본형·강화형·새 세션)
├─ 인물흔들림복구.md         증상별 원인과 복구 프롬프트

```

**데님은 전용 폴더 한 곳에 전부 모여 있다.** 데님 작업이면 이 폴더만 열면 된다.

```
여성남성카테고리별제미나이인식프롬프트/여성의류/데님/
├─ 데님1.md ~ 데님5.md        컬러웨이별 룩북 생성 프롬프트
├─ 데님색상텍스처고정.md      워싱·색 이동 방지
└─ 데님무드포즈카탈로그.md    포즈7~26 바디라인 강조 포즈 20종
```

포즈2 이후 프롬프트는 `다음포즈이어생성/다음포즈프롬프트.md` 를 쓴다. 스펙별 파일의 `[포즈N]` 블록은 그 기본형을 요약한 것이다.

## 작동 원리

동일 인물 유지는 두 개로 만든다.

1. **LOCK 블록** — 신체·얼굴·헤어를 문장으로 고정. 세션이 끊겨도 재현되는 텍스트 시드.
2. **같은 세션 연속 생성** — 포즈2 이후는 짧은 지시만. 긴 프롬프트를 다시 쓰면 오히려 인물이 바뀐다.

## 순서

```
1. 여성남성카테고리별제미나이인식프롬프트 스킬로 의상 속성 추출
2. 실측사이즈-착장변환.md 으로 지그재그 실측을 착장 문장으로 변환
3. 해당 스펙 폴더의 [포즈1] 프롬프트 + 사이즈 착장 LOCK + 실사감 레이어  ← 여기서만 긴 프롬프트
4. 기준컷에서 사이즈와 AI 느낌을 검수한다  ← 통과 못하면 여기서 다시
5. 통과하면 [포즈N] 프롬프트 실행  ← 3줄 + 유지 문장 2줄
6. 세션을 닫지 않는다
```

2번과 3번의 공통 레이어는 **전 품목에 빠짐없이 넣는다.** 품목별 프롬프트만으로는 AI 느낌과 사이즈 오차가 잡히지 않는다. 기준컷에서 두 검수를 통과시키는 것이 전체 작업의 관문이다.

## 절대 규칙

- 포즈2 이후에 의상·배경·조명·카메라 서술을 다시 쓰지 않는다. 재서술은 변형을 유발한다.
- 새 세션에서 이어가려면 포즈1 프롬프트의 LOCK 블록을 그대로 다시 넣고 "이 인물 유지, 포즈N"으로 시작한다.
- 원단 텍스처가 컷마다 달라지면 세션이 끊긴 것이다. 새로 시작한다.
