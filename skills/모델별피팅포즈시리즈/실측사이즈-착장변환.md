# 실측 사이즈 → 착장 변환 (전 품목 공통)

지그재그 상세페이지의 실측 치수를 프롬프트 문장으로 바꾸는 규칙.

---

## 왜 지금 사이즈가 안 맞는가

기존 프롬프트의 LOCK 블록에는 **모델 신체 치수만** 있다. 옷 치수가 없다.

```
현재  : 어깨 37 · 가슴 80 · 허리 60 · 엉덩이 86 · 팔길이 56 · 인심 78
없음  : 그 몸에 입힐 옷의 실측
```

그래서 AI는 옷 크기를 스스로 정한다. 그리고 AI가 정하는 기본값은 항상 **"예쁘게 맞는 핏"**이다. 오버사이즈를 주문해도 적당히 예쁜 루즈핏으로 그린다.

고쳐야 할 지점은 옷 치수를 넣는 게 아니다. **치수를 그대로 넣어도 AI는 이해하지 못한다.** "가슴 단면 52cm"는 AI에게 의미 없는 숫자다. 치수를 **몸의 어느 지점에 무엇이 보이는지**로 번역해야 한다.

```
❌ 총장 62cm            → AI가 무시한다
✅ 밑단이 힙을 완전히 덮고 허벅지 시작 지점에서 끝난다  → AI가 그린다
```

---

## 0단계 — 단면을 둘레로 바꾼다

지그재그 실측은 대부분 **단면(한 쪽 폭)** 표기다. 이걸 그대로 쓰면 절반 크기로 계산된다.

```
가슴단면 52  →  가슴둘레 104
허리단면 34  →  허리둘레 68
밑단단면 26  →  밑단둘레 52
```

총장, 어깨, 소매길이는 단면이 아니므로 그대로 쓴다.

**여유량 = 옷 둘레 − 모델 치수.** 이 값이 모든 판정의 기준이다.

---

## 모델별 기준 좌표

여성A(168cm/48kg) 기준이다. 다른 모델은 해당 `포즈시리즈.md`의 수치로 같은 방식으로 계산한다.

### 상의 기준 — 목옆점(SNP)에서 아래로

| 지점 | 거리 |
|---|---|
| 가슴 최대 | 25cm |
| 허리 (가장 가는 곳) | 38cm |
| 골반 위 | 44cm |
| 힙 최대 | 50cm |
| 가랑이 | 56cm |
| 허벅지 중간 | 64cm |
| 무릎 | 82cm |

### 하의 기준 — 허리 밴드에서 아래로

| 지점 | 거리 |
|---|---|
| 가랑이 (밑위) | 26cm (하이웨이스트 28) |
| 허벅지 중간 | 42cm |
| 무릎 | 58cm |
| 종아리 중간 | 76cm |
| 복사뼈 | 96cm |
| 바닥 | 104cm |

### 모델 둘레 (여성A)

```
가슴 80 · 허리 60 · 엉덩이 86 · 허벅지 45 · 팔둘레 24
어깨너비 37 · 팔길이 56 (어깨끝~손목) · 인심 78
```

허벅지와 팔둘레는 체형에서 산출한 근사값이다. ±2cm 개인차를 감안한다.

# 상의 · 아우터 변환표

## 가슴 여유량 → 시각 현상

| 여유량 | 핏 | 프롬프트에 쓸 문장 |
|---|---|---|
| 0~6 | 타이트 | `가슴과 등 라인이 천 위로 드러난다. 가슴 끝에서 옆구리 쪽으로 당김 주름이 사선으로 뻗는다. 여유 주름이 없다` |
| 7~14 | 슬림 | `몸통 실루엣이 보인다. 옆구리에 수직 주름 1~2개. 밑단이 몸에 거의 붙어 떨어진다` |
| 15~24 | 레귤러 | `몸에서 살짝 떨어진다. 겨드랑이에서 사선 주름 2~3개. 밑단이 몸에서 3~4cm 떨어져 완만하게 벌어진다` |
| 25~38 | 루즈 | `몸통 실루엣이 보이지 않는다. 겨드랑이 아래 전체에 큰 사선 주름. 밑단이 몸에서 6~8cm 벌어진다. 천의 무게로 앞면 중앙이 아래로 처진다` |
| 39 이상 | 오버사이즈 | `몸통이 천 안에서 떠 있다. 밑단이 박스처럼 각지게 벌어진다. 겨드랑이 위치가 실제 겨드랑이보다 5cm 이상 아래에 있다. 어디에도 몸에 붙는 지점이 없다` |

## 어깨 실측 → 드롭

모델 어깨 37 기준.

| 어깨 실측 | 드롭 | 프롬프트에 쓸 문장 |
|---|---|---|
| 36~38 | 0 | `어깨 봉제선이 어깨뼈 끝에 정확히 놓인다. 소매산이 어깨 끝에서 꺾인다` |
| 39~41 | 2~4cm | `어깨 봉제선이 어깨뼈 끝을 2~4cm 넘어 팔 위쪽에 놓인다. 어깨에서 팔로 완만하게 흐른다` |
| 42~46 | 5~9cm | `어깨 봉제선이 팔 위쪽 절반 지점에 놓인다. 어깨 끝에서 천이 아래로 흘러내려 어깨선이 둥글게 무너진다. 소매산 주름이 팔 중간에 생긴다` |
| 47 이상 | 10cm+ | `어깨 구조가 사라진다. 봉제선이 팔꿈치 방향으로 한참 내려와 있고, 어깨에서 천이 크게 처져 겨드랑이까지 늘어진다` |

## 소매길이 → 손목 도달 지점

**드롭숄더면 유효 길이가 줄어든다.** 먼저 보정한다.

```
유효 소매길이 = 실측 소매길이 − (어깨 실측 − 37) ÷ 2
```

| 유효 길이 | 프롬프트에 쓸 문장 |
|---|---|
| 58 이상 | `소매 끝이 손등 절반을 덮는다. 손가락 관절 근처까지 내려온다` |
| 56~57 | `소매 끝이 손목뼈에 정확히 닿는다` |
| 52~55 | `소매 끝이 손목뼈보다 2~4cm 위에서 멈춘다. 손목이 완전히 드러난다` |
| 45~50 | `소매 끝이 팔꿈치와 손목 중간에 온다. 팔 아래쪽 절반이 드러난다` |
| 32~36 | `소매 끝이 팔꿈치보다 조금 아래에서 멈춘다` |
| 18~24 | `반팔. 소매 끝이 팔꿈치보다 위, 팔 중간에서 멈춘다` |

# 프롬프트 삽입 양식

기준컷 프롬프트의 의상 LOCK 블록 **안에** 넣는다. 위 표에서 고른 문장을 그대로 붙인다.

```
■ 사이즈 착장 LOCK (이 옷의 실제 치수다. 예쁘게 맞추지 마라)
이 옷은 특정 실측 치수를 가진 실제 제품이다.
모델 몸에 맞춰 크기를 조정하지 마라. 치수대로 입혀라.
맞지 않는 부분이 있으면 그대로 맞지 않게 그려라.

어깨   : (어깨 드롭 문장)
가슴   : (가슴 여유량 문장)
소매   : (소매길이 문장)
총장   : (총장 문장)

밑단과 소매 끝이 몸의 어느 지점에서 멈추는지가 이 옷의 정체성이다.
그 지점을 바꾸지 마라.
```

하의는 `어깨/가슴/소매/총장` 자리에 `허리/허벅지/총장/밑단폭`을 넣는다.

## 실측 입력 양식

지그재그 상세페이지에서 복사해 채운다. 이 표만 채우면 위 문장이 결정된다.

```
[품목]
[사이즈]

상의·아우터
  총장        cm
  어깨너비     cm
  가슴단면     cm  → 둘레      cm  → 여유      cm
  소매길이     cm  → 유효      cm

하의
  총장        cm
  밑위        cm  → 유효 인심   cm
  허리단면     cm  → 둘레      cm  → 여유      cm
  허벅지단면   cm  → 둘레      cm  → 여유      cm
  밑단단면     cm  → 둘레      cm
```

## 검수 — 사이즈 판정

기준컷에서 **이것만 먼저 확인한다.** 여기서 틀리면 나머지 컷을 뽑을 의미가 없다.

```
□ 밑단이 표에서 정한 신체 지점에서 끝나는가
□ 소매 끝이 표에서 정한 지점에서 끝나는가
□ 어깨 봉제선이 표에서 정한 위치에 있는가
□ 여유량에 맞는 주름이 있는가      (오버사이즈인데 몸에 붙으면 실패)
□ 허리 밴드가 표에서 정한 상태인가  (하의)
```

전신컷에서 가장 눈에 띄는 오류는 **밑단 위치**다. 이것 하나만으로도 고객이 사이즈를 오해한다. 반품의 주원인이므로 여기서 타협하지 않는다.

---

## 주의

- **실측을 반올림하지 않는다.** 62cm와 65cm는 착장 지점이 다르다.
- **한 품목의 여러 색상은 같은 실측을 쓴다.** 컬러웨이가 달라도 패턴은 같다.
- **AI가 치수를 지키지 못하는 경우**가 있다. 이때는 숫자를 빼고 착장 문장만 남긴다. AI는 숫자보다 위치 서술에 반응한다.
- 표에 없는 중간값은 인접한 두 구간의 문장을 섞지 말고, **가까운 쪽 하나를 고른다.** 섞으면 AI가 혼동한다.
