# 워터마크 제거와 용량 축소 — 40장 일괄 처리

Gemini로 출력한 룩북·홍보 이미지를 쇼핑몰과 SNS에 올릴 수 있는 상태로 만드는 후처리 공정.

```
대상  Gemini 출력 원본 (우하단 ✦ 스파클 워터마크, 고용량)
목표  워터마크 제거 + 용량 대폭 축소, 단 워싱·원단 디테일은 지키기
```

---

# 0. 먼저 · 워터마크는 "지우는 것"보다 "끄는 것"이 정답

2026년 8월부터 Google이 **보이는 워터마크를 선택 사항으로 바꿨습니다.** Gemini와 Flow의 `설정 > Media Watermark`(미디어 워터마크)에서 끌 수 있습니다. Nano Banana · Omni · Lyria 모델에 적용됩니다.

**단, 한국은 조건이 다릅니다.**

```
한국·인도·베트남  → 이 토글은 Google AI Ultra 유료 구독자 전용.
                   그 외 사용자는 보이는 워터마크가 자동으로 유지된다
직장·학교 계정     → 토글 제공되지 않음
```

즉 한국에서 워터마크 없는 출력을 정식으로 받으려면 **AI Ultra 구독**이 필요합니다. 앞으로 상품 촬영을 계속할 거라면 40장을 손으로 지우는 것보다 구독이 싸게 끝날 수 있으니 한 번 계산해 보세요.

## 판단에 필요한 사실

```
보이는 스파클 마크를 끄거나 지워도
SynthID(눈에 안 보이는 픽셀 워터마크)와 C2PA 메타데이터는 파일에 그대로 남는다.
Google도 이 둘을 남기는 조건으로 보이는 마크를 선택 사항으로 풀었다.
→ AI 생성물이라는 출처 표시 자체가 사라지는 것은 아니다
→ 다만 한국에서 토글이 Ultra 전용인 상태에서 수동 제거는
   약관상 회색지대다. 상업 사용 규모가 커지면 구독으로 정리하는 게 안전하다
```

SynthID는 크롭·압축·스크린샷에도 살아남습니다. 지우려는 시도는 화질만 떨어뜨립니다. 건드리지 마세요.

# 1. 이미 출력된 40장 처리 순서

순서를 지켜야 합니다. 바꾸면 결과가 나빠집니다.

```
① 원본 아카이브     원본은 절대 덮어쓰지 않는다. 별도 폴더에 보관
② 워터마크 제거      최대 해상도 상태에서 한다. 축소 후에 하면 자연스럽게 안 메워진다
③ 리사이즈          용도별 긴 변 픽셀로 축소
④ 압축·내보내기      포맷과 품질 결정
⑤ 검수             워싱·원단 디테일 확인
```

폴더 구조 예시

```
images/
├─ 00_원본/            Gemini 출력 그대로. 손대지 않음
├─ 01_워터마크제거/     풀 해상도, 마크만 제거
├─ 02_상세페이지/       1400px WebP
├─ 03_썸네일/          600px WebP
└─ 04_SNS/            1080x1350 JPEG
```

# 2. 워터마크 제거 · 액션 + 일괄 처리 (40장을 한 번에)

40장을 하나씩 지우지 않습니다. 마크 위치가 모든 컷에서 같으므로 **액션 한 번 녹화 후 일괄 처리**로 끝냅니다.

## 2-1. 사전 설정

```
편집 > 환경 설정 > 단위와 눈금자 > 눈금자 : 픽셀
※ 픽셀이 아니면 액션의 선택 영역 좌표가 재생 때 어긋난다
```

## 2-2. 액션 녹화 (1장만 작업)

```
1. 40장 중 아무 컷이나 열기
2. 창 > 액션 (Alt+F9) > 새 액션 만들기 > 이름 "워터마크제거" > 기록
3. 사각형 선택 도구로 ✦ 마크 주위를 여유 있게 드래그 선택
   (마크 바깥으로 15~20px 정도 넉넉하게)
4. 편집 > 칠 > 내용 : 내용 인식, 색상 적응 체크 > 확인
5. 선택 > 선택 해제 (Ctrl+D)
6. 액션 패널 정지 버튼
```

배경이 평평한 그레이 그라데이션이라 **내용 인식 채우기가 거의 완벽하게 메웁니다.** 결과를 100% 확대해서 얼룩이 없는지 한 번만 확인하세요.

## 2-3. 일괄 처리

```
파일 > 자동화 > 일괄 처리
  액션          : 워터마크제거
  소스          : 00_원본 폴더
  대상          : 01_워터마크제거 폴더
  체크          : "다른 이름으로 저장 명령 무시"
  파일 이름 지정 : 문서 이름 + 확장자
```

## 2-4. 주의

```
해상도가 다른 컷은 그룹을 나눈다
  액션은 절대 좌표로 재생된다. 4:5와 9:16을 한 번에 돌리면 엉뚱한 곳을 지운다
  → 크기별로 폴더를 나누고 액션도 따로 녹화한다

마크가 인물이나 바닥 경계선에 걸친 컷은 일괄 처리에서 빼고 수동 처리한다
  그 컷만 생성형 채우기(Generative Fill)로 프롬프트 없이 실행하면 깔끔하다

크롭으로 해결하려는 유혹은 참는다
  ✦가 발 옆에 있어서 잘라내면 접지 그림자와 하단 여백이 함께 날아간다.
  공들여 만든 접지감이 사라진다
```

# 3. 용량 축소 · 실제 도구 세 가지

## 먼저 정정 — Adobe에 "스마트 필름"은 없습니다

아마 **스마트 오브젝트** 또는 **스마트 필터**를 말씀하신 것 같은데, 이 둘은 용량 축소 기능이 아닙니다. 오히려 반대입니다.

```
스마트 오브젝트로 변환해 축소하면
  → 비파괴 편집은 되지만 PSD 안에 원본 픽셀이 그대로 들어가 파일이 더 커진다
스마트 필터
  → 필터를 나중에 수정할 수 있게 하는 기능. 용량과 무관
```

용량을 줄이는 실제 도구는 아래 셋입니다.

## 3-1. Lightroom Classic 내보내기 (용량 목표가 정해졌을 때 최선)

**`파일 크기 제한` 기능이 핵심입니다.** 목표 용량을 숫자로 넣으면 품질을 자동으로 맞춰줍니다. 쇼핑몰이 업로드 용량을 제한할 때 이게 가장 빠릅니다.

```
파일 > 내보내기
  파일 설정
    이미지 형식        : JPEG
    파일 크기 제한      : 체크 후 목표값 입력 (예 300 K)
  이미지 크기 조절
    다음에 맞추기       : 긴 변, 1400 픽셀
    해상도             : 72 ppi (웹)
  출력 선명하게 하기
    대상               : 화면
    양                 : 표준
```

## 3-2. Photoshop 이미지 프로세서 (폴더 단위 일괄, 가장 간단)

```
파일 > 스크립트 > 이미지 프로세서
  ① 처리할 이미지 선택  : 01_워터마크제거 폴더
  ② 저장 위치          : 02_상세페이지 폴더
  ③ 파일 유형
     JPEG로 저장       : 체크, 품질 8
     크기 맞추기        : 체크, W 1400 / H 1400
```

**품질은 7 이상으로 두세요.** Photoshop JPEG은 품질 6 이하에서 색상 서브샘플링이 4:2:0으로 떨어지는 것으로 알려져 있습니다. 이 데님의 세피아↔블루 경계가 뭉개지는 지점이 정확히 거기입니다.

## 3-3. 내보내기 형식 (WebP · 용량 대비 화질 최강)

```
파일 > 내보내기 > 내보내기 형식 (Alt+Shift+Ctrl+W)
  형식     : WebP
  품질     : 80
  이미지 크기 : 폭 1400
  → 우측에 예상 용량이 실시간으로 뜬다. 보면서 품질을 조절한다
```

WebP는 같은 체감 화질에서 JPEG보다 **25~35% 작습니다.** 다만 쇼핑몰 솔루션이 WebP 업로드를 받는지 먼저 확인하세요. 안 받으면 JPEG으로 병행 출력합니다.

# 4. 이 데님 이미지의 압축 취약점

공들여 살린 요소가 하필 압축에 가장 약한 것들입니다. 여기만 조심하면 됩니다.

| 요소 | 왜 약한가 | 대응 |
|---|---|---|
| 세피아 페이딩의 부드러운 경계 | 완만한 그라데이션은 JPEG가 밴딩·블록으로 뭉갠다 | 품질 8 이상 또는 WebP |
| 크로스해치 슬럽 결 | 미세 고주파 디테일이 가장 먼저 날아간다 | 긴 변 1200px 이하로 내리지 않는다 |
| 발밑 접지 그림자 | 어두운 영역의 완만한 톤은 블록 노이즈가 눈에 잘 띈다 | 품질을 낮출 때 여기를 100%로 확인 |
| 그레이 벽 배경 | 평평한 면에 밴딩이 생기면 바로 보인다 | 마지막에 넣은 그레인이 밴딩을 덮어준다. 그레인을 빼지 말 것 |

리샘플링 방식은 **바이큐빅 더 뚜렷하게(축소에 적합)** 를 쓰세요. 자동으로 두면 컷마다 다르게 적용될 수 있습니다.

# 5. 용도별 출력 규격

```
상품 상세페이지 메인    긴 변 1400px   WebP 품질 80    목표 250~350KB
상세 디테일 확대컷      긴 변 2000px   WebP 품질 82    목표 400~600KB
목록·썸네일            긴 변 600px    WebP 품질 75    목표 40~60KB
인스타그램 피드         1080 x 1350    JPEG 품질 9     목표 300~500KB
인스타그램 스토리       1080 x 1920    JPEG 품질 9     목표 400~600KB
페이스북·X             1200 x 1500    JPEG 품질 8     목표 250~400KB
핀터레스트             1000 x 1500    JPEG 품질 9     목표 300~500KB
원본 아카이브          손대지 않음     PNG/원본 그대로  용량 무시
```

SNS 플랫폼은 업로드 후 자체 재압축을 한 번 더 합니다. 그래서 SNS용은 상세페이지용보다 **품질을 한 단계 높게** 내보내는 게 유리합니다. 이미 압축된 걸 다시 압축하면 손상이 누적됩니다.

# 6. 검수 체크리스트

40장을 다 돌린 뒤 **무작위 5장**만 이렇게 봅니다.

```
□ 워터마크 자리에 얼룩·번짐이 없는가 (100% 확대)
□ 허벅지 세피아 페이딩의 경계에 밴딩 띠가 생기지 않았는가
□ 크로스해치 결이 남아 있는가 (100% 확대)
□ 발밑 접지 그림자에 사각형 블록 노이즈가 없는가
□ 데님 색이 원본과 같은가 (스포이드로 허벅지·무릎 아래 두 지점 RGB 비교)
□ 목표 용량 안에 들어왔는가
```

색 비교는 두 지점을 같이 보세요. 한 지점만 보면 압축으로 생긴 톤 변화를 놓칩니다.

# 7. 다음 상품부터는 이렇게

```
1. AI Ultra 구독 여부를 먼저 결정한다
   → 구독하면 설정 > Media Watermark 끄고 생성. 후처리 공정에서 2번 단계가 사라진다
2. 생성 단계에서 해상도를 용도에 맞게 받는다
   → 상세페이지가 1400px면 4K로 뽑을 필요가 없다. 축소 과정에서 디테일이 손실된다
3. 액션과 이미지 프로세서 설정은 한 번 만들면 계속 쓴다
   → 액션 패널에서 "워터마크제거" 액션을 .atn으로 내보내 보관한다
```
