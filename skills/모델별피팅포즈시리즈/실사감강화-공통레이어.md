# 실사감 강화 공통 레이어 (전 품목 공통)

AI 느낌을 지우는 블록. **품목·카테고리·모델과 무관하게 기준컷(포즈1) 프롬프트 뒤에 그대로 붙인다.**

---

## 왜 지금 AI 느낌이 나는가

기존 프롬프트는 장비와 조명을 **완벽하게** 서술한다. Hasselblad, 3점 조명, 뮤트 그레이 호리존. 문제는 여기다.

```
AI에게 "완벽함"을 주문하면 → 렌더링을 그린다
AI에게 "결함"을 주문하면   → 사진을 그린다
```

실제 사진이 사진처럼 보이는 이유는 광량이 미묘하게 어긋나고, 피부 톤이 부위마다 다르고, 옷이 몸에 걸려 주름지고, 수직선이 0.5도 기울어져 있기 때문이다. 이걸 명시하지 않으면 AI는 전부 균일하게 만든다.

두 번째 원인은 **옷의 착장 물리 부재**다. 지금 프롬프트에는 옷의 색·워싱·실루엣만 있고, 그 옷이 몸에 **걸리는 방식**이 없다. 그래서 AI가 옷을 몸 표면에 프린트한다. 사람이 무의식적으로 "이상하다"고 느끼는 지점이 대부분 여기다.

# 붙여넣을 블록

기준컷 프롬프트의 `■ 금지` 바로 앞에 삽입한다.

```
■ 사진 성격 (가장 중요 — 먼저 적용)
이것은 보정을 거치지 않은 촬영 원본 파일이다.
리터칭 전 상태이며, 상업용으로 다듬기 전의 결과물이다.
완벽하게 만들지 마라. 깨끗하게 정리하지 마라.
CG, 3D 렌더, 일러스트, AI 생성물처럼 보이면 실패다.

■ 착장 물리 (옷이 몸에 걸리는 방식 — 두 번째로 중요)
옷은 몸에 인쇄된 무늬가 아니다. 천이 몸에 걸쳐져 중력으로 끌려 내려간다.
접촉하는 곳에서 눌리고, 떨어지는 곳에서 뜨고, 꺾이는 곳에서 주름진다.

어깨    : 어깨뼈 끝에서 천이 걸려 멈추고, 그 아래로 늘어진다
겨드랑이 : 팔과 몸통이 만나는 지점에서 사선 주름이 2~4개 뻗어 나온다
허리    : 밴드나 밑단이 몸에 닿는 선에서 천이 살짝 눌려 단이 생긴다
팔꿈치  : 굽힌 쪽 안쪽에 가로 주름이 겹쳐 쌓인다
무릎    : 굽힌 쪽 무릎 위에 가로 주름, 무릎 뒤에 접힘
밑단    : 신발이나 몸에 닿는 지점에서 천이 쌓이고 한쪽으로 기운다
솔기    : 봉제선을 따라 천이 미세하게 당겨져 주변에 잔주름이 생긴다

주름은 좌우 대칭이 아니다. 체중을 실은 쪽이 더 많이 눌린다.

■ 불균일 (결함을 넣는다)
조명  : 키 라이트 반대쪽 광량을 1/3스톱 낮춰 좌우 밝기를 미세하게 다르게 한다
        벽면 밝기가 완전히 균일하지 않고 완만한 얼룩이 있다
피부  : 부위마다 톤과 질감이 다르다
        무릎과 팔꿈치는 주변보다 어둡고 건조하다
        정강이 앞면은 살짝 각질감이 있다
        손등에 힘줄과 옅은 혈관이 보인다
        팔 안쪽은 밝고 바깥쪽은 어둡다
        목과 턱 경계에 톤 차이가 있다
        솜털이 광선 방향에서 역광으로 비친다
얼굴  : 좌우가 완전히 같지 않다. 한쪽 눈이 아주 조금 크고,
        입꼬리 한쪽이 약간 높고, 콧대가 미세하게 치우쳐 있다
헤어  : 가르마 경계에 두피가 조금 보인다
        정수리와 관자놀이에 짧은 잔머리가 삐져나와 빛을 받는다
        어깨에 걸친 머리끝이 뭉치지 않고 갈라져 흩어진다
자세  : 한쪽 어깨가 반대쪽보다 1cm 정도 높다
        목이 수직에서 2~3도 기울어져 있다
        손가락은 힘을 뺀 상태로 각각 다르게 반쯤 굽어 있다
        손가락을 가지런히 펴지 마라
접지  : 신발 밑창이 체중으로 눌려 바닥에 압착된다
        발목에 체중 이동이 보인다. 발이 바닥 위에 떠 있으면 실패다
프레임 : 벽의 수직선이 0.5도 정도 기울어져 있다
        인물이 프레임 정중앙에서 아주 조금 벗어나 있다
경계  : 머리카락 외곽에 배경색이 섞여 들어간다
        인물과 배경이 칼로 자른 듯 분리되면 실패다

■ 질감 (광택을 죽인다)
원단은 매트하다. 하이라이트는 넓고 약하게 퍼진다.
좁고 밝은 반사점을 만들지 마라. 천이 젖은 듯 광나면 실패다.
이미지 전체에 촬영 센서 노이즈가 균일한 강도로 얇게 깔려 있다.
```

## 프롬프트에서 빼야 할 단어

이 단어들이 AI 렌더링 룩을 직접 유발한다. 기존 프롬프트에 있으면 지운다.

```
✗ perfect, flawless, ideal, symmetrical, clean, pristine
✗ stunning, beautiful, gorgeous, elegant
✗ masterpiece, best quality, high quality
✗ 8k, 4k, ultra detailed, hyperrealistic, photorealistic
✗ professional, studio quality, magazine quality
✗ smooth, polished, refined
```

`hyperrealistic`과 `photorealistic`이 특히 역효과다. 이 단어는 "사진처럼"이 아니라 "사진처럼 보이는 CG"를 만든다.

대신 쓴다.

```
✓ 보정 전 촬영 원본
✓ 리터칭 하지 않은 상태
✓ 실제 촬영된 사진
✓ 필름 스캔본
```


## 검수 — AI 느낌 판정 10항목

100%로 확대해서 본다. **3개 이상 걸리면 다시 뽑는다.**

```
□ 겨드랑이와 팔꿈치에 주름이 있는가          (없으면 옷이 프린트된 것)
□ 밑단이 신발이나 몸에 닿아 쌓였는가
□ 좌우 주름 개수와 위치가 다른가
□ 무릎·팔꿈치가 주변보다 어두운가
□ 손가락이 각각 다르게 굽어 있는가
□ 잔머리가 삐져나와 있는가
□ 신발 밑창이 바닥에 눌려 있는가            (떠 있으면 실패)
□ 머리카락 경계에 배경색이 섞였는가          (칼로 자른 듯하면 실패)
□ 좌우 밝기가 미세하게 다른가
□ 천에 좁고 밝은 광택점이 없는가
```

가장 빨리 판정하는 방법은 **겨드랑이와 밑단** 두 곳만 먼저 보는 것이다. 이 두 곳이 매끈하면 나머지는 볼 필요 없이 실패다.

## 후처리 주의

`작업순서-체크리스트.md`의 Camera Raw 설정 중 아래 두 개가 이 레이어와 충돌한다.

```
텍스처 +10, 선명하게 하기 30  →  착장 주름은 살지만 피부 불균일이 뭉개질 수 있다
```

실사감 레이어를 적용한 컷은 **텍스처 +5, 선명하게 하기 20**으로 낮춘다. 원본이 이미 질감을 갖고 있으므로 더 올릴 필요가 없다.
