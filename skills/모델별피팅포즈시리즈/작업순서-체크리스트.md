# 포토샵 작업 순서 체크리스트

```
□ 원본 40장을 00_원본 폴더에 모으기
□ 01_워터마크, 02_최종 빈 폴더 만들기
□ 포토샵 실행, 열린 탭 전부 닫기
```

## 0. 색 기준 정하고 분류하기 (먼저 할 것)

```
□ 색이 가장 잘 나온 컷 1장을 기준으로 정한다 (예 1.jpg)
□ 기준컷 열기 → F8 (정보 패널)
□ Shift + I → 색상 견본 도구
□ 3점 찍고 RGB 적어두기
     ① 배경 벽 중간      R___ G___ B___
     ② 허벅지 페이딩 중심  R___ G___ B___
     ③ 무릎 아래 진한 면   R___ G___ B___
□ 40장을 눈으로 훑어 두 폴더로 분류
     01A_색정상   기준컷과 밝기·채도가 비슷한 컷
     01B_색빠짐   밝고 뿌옇고 청색기·노랑기가 약한 컷
```

---

## 1. 준비

```
□ 편집 > 환경 설정 > 단위와 눈금자 > 눈금자 : 픽셀
```

---

## 2. 워터마크 제거 (40장 손수, 장당 10초)

```
□ 파일 > 열기 > 00_원본 에서 1장
□ Ctrl + 1        (100%)
□ Space 드래그    (우하단 ✦ 로 이동)
□ J → Shift + J   (패치 도구)
□ 옵션바  패치: 내용 인식 / 구조 5 / 색상 1 / 모든 레이어 샘플링 체크
□ ✦ 주위를 감싸 선택 (여유 10~15px)
□ 같은 높이에서 좌우로 드래그 → 놓기
     · 위아래로 끌지 않는다
     · 벽·바닥 경계선을 넘기지 않는다
□ Ctrl + D
□ 결과 확인 → 얼룩 있으면 Ctrl + Z 후 소스 위치 바꿔 재시도
□ Shift + Ctrl + S → 01A_색정상 또는 01B_색빠짐 폴더에 PNG로 저장
□ Ctrl + W
□ 40장 반복
```

---

## 3. Camera Raw 사전 설정 만들기 (1장만)

```
□ 01_워터마크 에서 1장 열기
□ 이미지 > 모드 > 16비트/채널
□ Shift + Ctrl + A   (Camera Raw 필터)
```

### 기본

```
□ 노출          0
□ 대비          +3
□ 하이라이트    -12
□ 그림자        0
□ 흰색 계열     -6
□ 검정 계열     -4
□ 텍스처        +10
□ 부분 대비     +3
□ 디헤이즈      0
□ 생동감        +4
□ 채도          0
```

### 곡선 (포인트 곡선)

```
□ 좌측 하단 끝점 → 출력 6
□ 우측 상단 끝점 → 출력 249
```

### 색상 혼합 (HSL)

```
□ 오렌지  채도 +4   광도 -2
□ 빨강    채도 +3   광도 -2
□ 파랑 · 아쿠아 · 노랑 → 건드리지 않음
```

### 색상 보정

```
□ 어두운 영역  색조 215   채도 5
□ 밝은 영역    색조 45    채도 4
□ 균형        0
```

### 세부

```
□ 선명하게 하기 양     30
□ 반경               0.8
□ 세부               25
□ 마스킹             50    (Alt 드래그로 확인: 벽은 검정, 인물 윤곽만 흰색)
□ 노이즈 감소         0
□ 색상 노이즈 감소     0    (벽에 색 반점 보일 때만 8)
```

### 효과

```
□ 입자  양 15 / 크기 22 / 거칠기 50
□ 비네팅  양 -10 / 중간점 50 / 페더 60 / 원형율 0
```

### 마스킹

```
□ 마스킹 > 사람 > 얼굴 피부 + 신체 피부 체크 > 마스크 만들기
     텍스처 +15 / 부분 대비 +5 / 선명하게 하기 -5 / 입자 +10
□ 마스킹 > 사람 > 머리카락 > 마스크 만들기
     텍스처 +10 / 선명하게 하기 +10
□ 마스킹 > 배경 > 마스크 만들기
     텍스처 -5 / 선명하게 하기 -10
```

### 저장

```
□ 우측 사전 설정 패널 > 사전 설정 만들기 > 이름 "실사화_A" > 확인
□ 확인 눌러 Camera Raw 닫기
□ Ctrl + W → 저장 안 함
```

## 3-B. 색 빠진 컷용 사전 설정 (01B 폴더가 있으면)

```
□ 01B_색빠짐 에서 1장 열기
□ Shift + Ctrl + A
□ 사전 설정 "실사화_A" 클릭해 불러오기
```

### A에서 이 값만 덮어쓰기

```
□ 색온도        -4
□ 노출          -0.25
□ 대비          +10
□ 하이라이트    -18
□ 검정 계열     -15
□ HSL 파랑     채도 +12   광도 -5
□ HSL 아쿠아   채도 +8    광도 -3
□ HSL 노랑     채도 +15
```

### 기준컷과 대조

```
□ Shift + I 로 3점 찍고 0단계에 적은 RGB와 비교
     ① 배경 벽        ±3 안으로
     ② 페이딩 중심     ±5 안으로
     ③ 무릎 아래       ±5 안으로
□ 벽이 먼저 맞도록 색온도·색조로 조정한다. 벽이 맞으면 나머지가 따라온다
□ 어긋나면 노출과 검정 계열을 먼저 만진다. HSL은 마지막에
□ 사전 설정 만들기 > 이름 "실사화_B" > 확인
□ Ctrl + W → 저장 안 함
```

---

## 4. 액션 녹화 (A·B 각각 1개)

```
□ 01A_색정상 에서 1장 열기
□ Alt + F9   (액션 패널)
□ 새 액션 만들기 > 이름 "실사화A" > 기록
□ 필터 > Camera Raw 필터 > 사전 설정 "실사화_A" 클릭 > 확인
□ 이미지 > 이미지 크기
     다시 샘플링 : 바이큐빅 더 뚜렷하게(축소)
     높이 1400 픽셀 (가로 컷은 폭 1400)
□ 이미지 > 모드 > 8비트/채널
□ 액션 패널 정지(■)
□ Ctrl + W → 저장 안 함

□ 같은 방식으로 "실사화B" 액션 녹화 (사전 설정만 "실사화_B"로)
```

---

## 5. 일괄 실행 (2회)

```
□ 파일 > 스크립트 > 이미지 프로세서
     ① 처리할 이미지 : 01A_색정상
     ② 저장 위치     : 02_최종
     ③ 파일 유형     : JPEG 체크, 품질 8
                      크기 맞추기 → 체크 안 함
     ④ 환경 설정     : 액션 실행 → 기본 액션 > 실사화A
□ 1장만 넣은 테스트 폴더로 먼저 확인
□ 통과하면 실행

□ 같은 절차로 01B_색빠짐 → 실사화B 액션으로 실행
```

## 6. 검수 (무작위 5장, 100%)

```
□ 피부에 미세 그레인이 보인다
□ 티셔츠에 원단 결이 남아 있다 (순백으로 날아가지 않음)
□ 발밑 접지 그림자가 옅어지지 않았다
□ 세피아 페이딩의 따뜻한 톤이 살아 있다
□ RGB 비교 : 배경 벽 — 기준컷과 ±3
□ RGB 비교 : 허벅지 페이딩 중심 — 기준컷과 ±5
□ RGB 비교 : 무릎 아래 진한 면 — 기준컷과 ±5
□ A 폴더 컷과 B 폴더 컷을 나란히 놓고 색이 같아 보인다
□ 그레이 벽에 밴딩 띠가 없다
□ 머리카락이 덩어리로 뭉치지 않았다
□ 워터마크 자리에 얼룩이 없다
□ 용량이 250~350KB 안에 들어왔다
```

```
✗ 00_원본 폴더 덮어쓰기
✗ 기본 패널 채도 조절
✗ 노이즈 감소 올리기
✗ 노출 · 그림자 올리기
✗ 파랑 · 아쿠아 · 노랑 HSL 채널 조절
     예외 — 3-B 에서만. 기준컷 RGB에 맞추는 목적일 때
✗ 눈대중으로 색 맞추기. 항상 RGB 수치로 확인
✗ A 와 B 를 한 액션으로 처리하기
✗ 얼굴 보정 도구로 눈 · 턱 형태 수정
✗ 리사이즈를 Camera Raw보다 먼저 하기
```
