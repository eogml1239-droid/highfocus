# 인물 흔들림 복구

포즈를 올리다가 다른 사람처럼 나왔을 때. **프롬프트를 고치려 하지 말고 마음에 든 컷으로 되돌린다.**

## 복구 프롬프트

마음에 들었던 이미지를 `+`로 첨부하고 아래를 쓴다.

```
첨부 이미지의 인물이 기준이다. 직전 생성물은 버리고 이 얼굴·체형으로 복귀.
같은 의상, 같은 배경, 같은 조명, 같은 원단 텍스처.
포즈2: 3/4 측면 45도, 시선은 렌즈로.
```

## 증상별 원인과 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| 얼굴이 다른 사람 | Temperature 높음 / 시선 미지정 | 0.6으로 내리고 시선을 문장에 넣는다 |
| 체형이 마르거나 두꺼워짐 | 체형 서술이 희석됨 | LOCK의 체형 줄을 다시 한 번 붙인다 |
| 원단 짜임이 달라짐 | 세션이 끊겼거나 의상을 재첨부함 | 강화형(직전 이미지 첨부)으로 전환 |
| 발밑 그림자가 사라짐 | 접지 항목이 지시에서 빠짐 | 포즈 문장에 `발밑 코어 섀도우 유지` 추가 |
| 배경 톤이 달라짐 | 배경을 재서술했거나 새 세션 | LOCK 배경 줄만 다시 붙인다 |
| 다리가 과하게 길어짐 | 카메라 높이·초점거리 무시 | `카메라 높이 [스펙값]cm, 150mm 유지` 추가 |
| 얼굴이 프레임 밖으로 잘림 | 프레이밍 지시 누락 | `머리 정수리부터 발끝까지 프레임 안` 추가 |

## 세 번 이상 실패하면

같은 세션에서 계속 시도하지 않는다. 대화가 길어질수록 초기 LOCK이 희석된다.

```
1. 새 세션을 연다
2. System instructions에 v3.0 문서 + 해당 스펙 LOCK을 다시 넣는다
3. 마음에 들었던 컷을 첨부하고 강화형 프롬프트로 시작한다
```

## 예방

- 포즈 1~2컷마다 결과가 유지되는지 눈으로 확인한다. 흔들린 걸 모르고 5컷을 더 뽑으면 전부 버려야 한다.
- 마음에 든 컷은 즉시 따로 저장한다. 복구 기준 이미지로 쓴다.
- 한 턴에 한 포즈만 요구한다. 두 개를 동시에 요구하면 두 컷의 인물이 서로 달라진다.
