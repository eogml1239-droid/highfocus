# 인물 유지 · 의상 교체 — 컬러웨이 갈아입히기

마음에 든 모델을 그대로 두고 데님만 다른 컬러웨이로 바꿔 포즈를 이어가는 방법.

```
예시 상황  데님4(다크 인디고) 컷의 모델 외모가 마음에 든다
          → 그 모델에게 데님5(빈티지 미디엄 블루)를 입혀 포즈를 계속 뽑고 싶다
```

## 먼저 알아야 할 것 — 같은 세션에서 갈아입히면 실패한다

```
데님4·5 파일의 "컬러웨이별 세션 분리" 규칙은 그대로 유효하다.
인디고 세션에서 "옷만 바꿔줘"라고 하면
새 데님이 두 색의 평균으로 나온다. 빈티지 블루가 어둡고 탁해진다.
세피아 페이딩은 인디고 톤에 눌려 거의 사라진다.

→ 반드시 새 세션을 연다. 인물은 이미지로, 의상은 행거샷으로 따로 공급한다.
→ 이 문서의 핵심은 "첨부 이미지마다 역할을 지정하는 것"이다.
```

# 방법A · 얼굴 크롭 레퍼런스 (권장 · 색 간섭 0)

가장 확실합니다. **레퍼런스 이미지에서 데님을 아예 잘라냅니다.** 참조 이미지에 인디고가 없으면 색이 섞일 수 없습니다.


# 방법B · 전신 컷 그대로 첨부 (간편 · 인디고 잔상 위험)

크롭이 귀찮을 때. 체형과 조명이 더 잘 따라오지만 **색 간섭이 실제로 발생합니다.**

방법A의 프롬프트에서 `[이미지1] = 인물 소스` 블록만 아래로 교체하세요.

```
■ [이미지1] = 인물 소스 (전신 컷)
가져올 것 : 얼굴, 헤어, 체형과 비율, 피부 톤, 표정, 포즈 기준,
           배경 톤, 조명 방향, 발밑 그림자 형태
가져오지 말 것 : 하의 전체.
              이 이미지의 진한 인디고 데님은 폐기되었다. 존재하지 않는다.
              그 색, 그 밝기, 그 워싱을 새 데님에 1%도 반영하지 마라.
              새 데님은 [이미지2·3]의 밝고 탁한 빈티지 블루다.
              [이미지1]의 데님보다 훨씬 밝다. 이 밝기 차이를 반드시 유지하라
```

`훨씬 밝다`라는 상대 비교 문장이 핵심입니다. 절대색 지시만으로는 잔상이 남습니다.

# 교체 검수 — 3초 체크

교체 첫 컷에서 이 네 가지를 봅니다. 하나라도 틀리면 다음 포즈로 넘어가지 말고 그 컷부터 고칩니다.

```
① 얼굴이 [이미지1]과 같은 사람인가
② 데님 베이스 색이 [이미지2]와 같은 밝기인가   ← 어두우면 인디고 잔상
③ 허벅지 세피아 페이딩이 남아 있고 색감이 따뜻한가
④ 무릎 아래가 페이딩 없이 베이스 색으로 진한가
```

②가 가장 자주 틀립니다. 눈으로는 애매하니 **스포이드로 허벅지 페이딩 중심과 무릎 아래 두 지점**의 RGB를 행거샷과 비교하세요. 한 지점만 보면 놓칩니다.

# 교체 성공 후 · 포즈 이어가기

교체 첫 컷이 통과하면 **같은 세션에서** 짧게 이어갑니다. 여기서부터는 평소와 같습니다.

```
포즈2. 모든 LOCK 유지.
인물·얼굴·헤어·체형·데님 색·워싱 위치·상의·신발·배경·조명·접지 그림자 동일.
세피아 페이딩은 원단에 물들어 있는 가공이라 포즈가 바뀌어도 이동하거나 옅어지지 않는다.
이전 인디고 데님은 존재하지 않는다.
포즈만 교체 : [여성의류/데님/데님무드포즈카탈로그.md 에서 하나 고르기]
```

`이전 인디고 데님은 존재하지 않는다` 한 줄을 **처음 3컷까지는 유지**하세요. 교체 직후에는 잔상이 되살아나기 쉽습니다. 4컷째부터 빼도 됩니다.

## 포즈 순서 팁

```
교체 첫 컷은 레퍼런스와 같은 포즈로 만든다.
포즈까지 동시에 바꾸면 변수가 둘이 되어 무엇이 틀렸는지 알 수 없다.
색이 잡힌 걸 확인한 다음에 포즈를 움직인다.
```

# 증상별 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| 새 데님이 어둡고 탁하다 | 인디고 잔상 | 방법A(얼굴 크롭)로 전환. 이게 가장 확실하다 |
| 색이 인디고와 빈티지 중간 | 두 색 평균 | `두 색을 평균 내지 마라. [이미지1]의 데님은 폐기되었다` 재투입 |
| 세피아 페이딩이 사라짐 | 인디고 톤에 눌림 | `머스터드·베이지 기운 세피아 페이딩은 의도된 가공이다` 재투입 |
| 얼굴이 미묘하게 다른 사람 | 이미지·텍스트 충돌 | 인물 텍스트 LOCK의 얼굴 문장을 이미지 기준으로 수정 |
| 얼굴은 같은데 체형이 다름 | 크롭 참조의 한계 | 방법A의 부작용. 체형 수치 LOCK을 다시 붙여넣는다 |
| 상의·신발이 바뀜 | 교체 턴에서 우선순위 밀림 | 상의·신발 문장만 재투입 |
| 배경이 오프화이트 | 행거샷 배경 복제 | `배경은 뮤트 그레이. 행거샷 배경을 복제하지 마라` 재투입 |
| 데님이 행거에 걸린 듯 납작 | 의상 소스 과참조 | `옷이 납작하게 걸린 형태를 가져오지 마라. 사람이 입은 입체 형태다` |

**3회 시도해도 색이 안 잡히면 인물 교체를 포기하지 말고 방향을 바꿉니다.** 데님5 기준컷을 인물 텍스트 LOCK만으로 새로 만들고(데님5.md 컷1 그대로), 거기서 나온 얼굴을 쓰세요. 텍스트 LOCK은 원래 같은 얼굴을 재현하도록 설계된 것이라 결과가 거의 같습니다.

# 재사용 · 인물 카드 만들어두기

이 작업을 한 번 하면 다음부터 훨씬 빨라집니다.

```
1. 마음에 든 컷에서 얼굴 크롭을 하나 만들어 파일로 보관한다
   파일명 예 : 여성A-168-48_얼굴레퍼런스.png

2. 이 크롭 + 인물 텍스트 LOCK 두 개를 "인물 카드"로 묶어둔다

3. 이후 어떤 컬러웨이든 [인물 카드] + [행거샷]으로 시작한다
   컬러웨이마다 세션은 분리하되 인물은 계속 같다
```

이렇게 하면 컬러웨이 간 색 간섭이 구조적으로 발생하지 않습니다. 인물 레퍼런스에 데님이 없으니까요.
