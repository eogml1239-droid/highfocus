# 검증과 주의

## 원본 대조 체크리스트

생성된 컷을 원본과 나란히 놓고 확인한다. 하나라도 어긋나면 버리고 다시 생성한다.

```
[ ] 색이 같은가 — 화면에서 두 이미지를 나란히 놓고 비교
[ ] 원단 짜임 구조가 같은가 — 조직 종류가 바뀌지 않았는지
[ ] 단추 개수가 같은가
[ ] 봉제선 위치와 스티치 색이 같은가
[ ] 라벨 위치가 같은가
[ ] 프린트·자수의 위치·크기·색이 같은가
[ ] 디테일이 추가되거나 삭제되지 않았는가
[ ] 기장과 어깨너비 비율이 같은가
[ ] 이미지에 텍스트·숫자·워터마크가 생기지 않았는가
```

## 창작이 일어나기 쉬운 지점

아래는 모델이 "그럴듯하게" 지어내는 항목이다. 원본에서 확인되지 않으면 그 컷 자체를 만들지 않는다.

| 항목 | 위험 |
|---|---|
| 안감 | 원본에 안쪽이 안 보이면 색·소재를 창작한다 |
| 라벨 내용 | 글자를 그럴듯하게 만들어낸다. 실제와 다른 문구가 생긴다 |
| 원단 접사 | 원본이 저해상도면 짜임을 지어낸다 |
| 뒷면 | 원본에 뒷면이 없으면 봉제 구조를 창작한다 |
| 착용 실루엣 | 누끼 상품컷만 있으면 고스트 입체를 창작한다 |
| 워싱 페이딩 | 데님 워싱 위치가 원본과 달라진다 |

**라벨은 특히 주의한다.** 소재 혼용률이나 원산지가 적힌 라벨을 AI가 재생성하면 실제와 다른 정보가 이미지에 박힌다. 라벨 접사는 실사로 촬영한다.

## 색 검증 방법

눈으로만 비교하면 놓친다. 포토샵에서 두 이미지를 레이어로 겹치고 스포이드로 같은 지점의 RGB 값을 비교한다. 차이가 크면 재생성하거나 원본 색으로 보정한다.

베이지·카키·아이보리 계열은 미세한 톤 차이가 다른 상품처럼 보이므로 특히 엄격하게 본다.

## 하지 말아야 할 것

- **소재 혼용률·원산지가 적힌 라벨 접사를 생성하는 것.** 실사로 촬영한다.
- **원본에 없는 컬러 변형을 만드는 것.** 블랙 원본으로 네이비를 생성하면 실제 네이비 제품과 색이 다르다. 각 색상은 각 실물 사진으로 재구성한다.
- **디테일컷 전부를 AI로 채우는 것.** 최소 2~3장은 실사를 넣는다. 원단 접사와 라벨이 우선순위다.

## 권리 확인

원본 이미지가 아래 중 하나에 해당해야 한다.

```
1. 직접 촬영한 이미지
2. 공급처·제조사에서 사용 허락을 받은 이미지
3. 사용권이 포함된 구매 이미지
```

타 셀러가 촬영한 이미지는 각도를 바꿔도 2차적 저작물로 볼 여지가 있어 분쟁 소지가 남는다. 판단이 애매하면 쓰지 않는 쪽이 안전하다.

## 상세페이지 표기 권장

AI로 재구성한 컷을 쓴다면 아래 정도를 명시하는 것이 분쟁 예방에 유리하다.

```
일부 이미지는 연출 컷이며, 실제 색상과 질감은 원단 상세 사진을 참고해 주세요.
```
